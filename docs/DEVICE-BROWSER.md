# 设备组文件浏览与接口

电脑端的设备组位置使用普通文件标签页，不映射 Windows 网络盘、不依赖 SMB。侧栏只读取本机已接受的成员；打开目录时才按需连接，不对空闲标签页每两秒发起轮询。

## 当前已验收的范围

- `devices.list`、`devices.refresh`：本地成员清单，不扫描网络。
- `devices.settings`、`devices.open`：与侧栏/组管理中的浏览按钮使用同一处理程序，支持普通新标签页及左右窗格。
- `devices.entries`、`devices.stat`、`devices.capabilities`：结构化目录、文件及权限信息。
- `devices.search`：显式递归搜索，最多 15 秒、500 个目录和 500 个结果；不会退回本机 Everything 或在后台无限遍历。
- `devices.preview`、`devices.thumbnail`、`devices.resource`：有界文本、PNG 缩略图及可撤销的本机媒体地址。

所有操作都在 `RHFilesAPI.list` 中提供参数定义和风险标记，与已有命令行脚本入口共用。`devices.open` 传入 `group`、`peer` 和可选共享路径 `path`，其余文件查询传入完整的 `path`。

位置格式为 `rhfiles-device://<group-id>/<device-id>/<shared-path>`；两段 ID 都是 64 位十六进制标识，共享路径逐段进行百分号编码，大小写保持不变。地址不包含 IP、密码或会话凭据，网络变化由身份绑定的连接恢复处理。

## 边界与验证

底层连接复用已验证的短期组会话。网络请求不走系统代理、不跟随重定向，并验证签名与证书。已提交的写请求不自动重放。撤销本机成员授权会使旧文件句柄与媒体通道失效，重新加入也不能复活旧句柄。

单目录最多十万项，分页必须具有稳定版本、总数、偏移和不重复的直接子项；超过限制报错，不静默截断。文本只读取前 128 KiB；媒体流支持 Range，最多八条并发流，20 秒无数据即终止。媒体 URL 仅在 `127.0.0.1` 上监听并使用随机能力标识，验证 Host，绝不向网页交出远端认证凭据。

真实双实例验收脚本为 `scripts/e2e/device-browser.test.mjs`：只共享临时夹具，覆盖 2011 项分页、中文/%/# 路径、普通标签页、搜索、实际图片/文本、Range、无空闲轮询及撤销授权。两个实例位于同一台主机，测试显式使用正常连接 API 的本机转发地址；这不等于跨设备自动发现已通过实测。

手机已接入同一个设备组服务端。电脑端远端文件写入/传输入口仍未开放；不能把浏览/预览测试说成全部双向文件管理已完成。

## 手机服务端的共享内核

`Groups::with_server_backend` 允许 HTTPS/WebDAV 服务使用 Android Keystore 和应用现有的组成员存储，不导出私钥、不创建第二个身份或 `groups.json`。操作系统适配层只提供签名、成员校验、权限及公开证明，不能绕过路径沙箱或把新授权写到另一份记录里。进程内组实例标识必须在删除/重新加入后改变，旧会话不能因重新加入而恢复。

该适配边界已有真实 TLS/文件读取与撤销/重新加入测试。Android 发行 APK 的 JNI、Keystore、前台服务及电脑浏览手机链路另由 `scripts/testing/phone-server-android.mjs` 在专用模拟器验收：目录、中文/%/# 路径、图片实际解码、文本、Range 和手机端撤权。测试使用保留签名端口的本机 ADB 转发，不削弱正式端点校验；它不是跨局域网发现或所有手机厂商省电策略的验证。

手机在“从电脑访问”中明确选择本地共享目录并启动；系统通知显示服务且可以停止。服务使用 `connectedDevice` 前台生命周期，无空闲 CPU 唤醒锁，不自动重启。应用的旧独立 HTTP 密码服务已从可调用的 IPC 入口移除，传统 FTP 则仍需用户另行显式启动。

手机 API：`fileServer.state`、`fileServer.start`（`roots: [{name, path}], port`）、`fileServer.stop`、`fileServer.roots`。UI 和命令行调用相同处理程序，启动时保留共享范围的确认；读写、删除权限通过现有 `groups.configure` 管理。新建或加入组后会发布现有服务地址；地址发布失败单独显示，不把已成功入组误报为失败。

禁用共享、收回写入/删除权限或本机移除成员时，手机会更换对应的内存授权实例；快速重新开放也不能复活旧会话。权限拒绝与网络不可达分开报告。电脑媒体代理和本机 ADB 调试端口避开浏览器禁用的端口，所有分配都有上限，不更改系统网络配置。
