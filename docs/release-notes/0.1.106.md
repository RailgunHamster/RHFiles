# RHFiles Windows 0.1.106
1. 支持为 RHFiles 设备设置**自定义显示名称（描述）**：可在左侧边栏设备右键菜单、主页设备分组标题旁编辑按钮或“管理设备组”中设置/恢复原机器名，该描述会随 WebDAV 配置同步（v2 `deviceAliases`）自动同步到所有设备（Windows 与 Android）。
2. 主页（`home://`）的 **RHFiles 设备** 分区按不同机器进行了轻量分组，每台设备上方显示紧凑的机器名标题（含原机器名标识与设备组名），方便直观区分不同机器共享的驱动器（如多台机器各自的 `C:`、`D:` 盘）。
## English
1. Added support for setting **custom display names (aliases)** for RHFiles devices via the sidebar device context menu, the Home page machine header edit button, or Manage Device Groups. Custom aliases are purely descriptive and automatically sync across all devices (Windows and Android) via WebDAV settings sync (v2 `deviceAliases`).
2. Subtly grouped shared drives under **RHFiles Devices** on the Home page (`home://`) by machine with a compact machine header (showing custom alias, original hostname badge, and group name) so drives from different computers are easy to distinguish at a glance.
