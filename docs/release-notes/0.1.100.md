# RHFiles Windows 0.1.100

1. 下载、校验和退出安装共用独立更新窗口，显示真实下载百分比、大小和速度，不再放入会被设置窗口遮住的文件任务面板。设置页同时保留当前下载或校验状态。
2. 修复下载后报“没有待安装更新”的处理链路。下载成功必须通过大小、SHA-256、包内版本和程序身份校验，并保存明确的安装目标；支持含 `[]` 的安装路径，不再依赖通配符扫描。
3. 同名旧缓存也需要校验；损坏缓存保留为隔离文件后重新下载。下载失败、清单不符或安装程序启动失败显示具体原因，不把失败当作就绪，不自动重放安装。
4. 安装前重新验证已下载文件，并绑定本次确认的版本，避免其他窗口下载不同版本后安装到错误目标。更新窗口与设置页显示同一进度，下载窗口关闭或启动失败不会阻断文件校验；安装阶段仍保留原生提示回退。

## English

1. Downloading, verification and installation now share the independent update window, with actual percentage, bytes and speed. Updates no longer use the file-task panel behind Settings; Settings also retains live update status.
2. Fixed the downloaded-to-install handoff. A successful download must pass size, SHA-256, embedded version and application-identity checks before committing an explicit install target. Installation paths containing literal brackets no longer depend on wildcard scans.
3. Existing cached packages are verified too. Invalid caches are quarantined before a fresh download. Download, manifest and installer-launch failures retain their causes instead of becoming a false ready state; installation is not automatically replayed.
4. Installation revalidates the committed file and checks the confirmed version against concurrent windows. The update window and Settings share progress. Closing or failing to launch the download window does not bypass verification; native installation progress remains the fallback.
