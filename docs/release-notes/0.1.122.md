# RHFiles Windows 0.1.122

发布日期 / Release date: 2026-11-10

## 中文

1. 图片另存为、RHVideo 配置导出和 ZIP 导出统一使用 RHFiles 自己的保存窗口，沿用应用的语言与主题。
2. 保存窗口提供地址栏、前进后退、上一级、收藏、已打开位置、最近保存位置、磁盘和 RHFiles 设备，支持文件筛选、隐藏项目、文件类型和新建文件夹。
3. 支持保存到本地、SMB 共享和 RHFiles 设备；远端只读位置明确提示，保存和新建文件夹由后端再次检查权限。
4. 同名文件需明确确认替换，确认期间文件变化会重新核对；使用版本校验和原子提交，取消保存不创建目标文件，关闭来源窗口会结束保存选择。
5. 大文件夹列表使用虚拟滚动，迟到的目录响应不会覆盖新的导航；目录加载失败时停止向旧位置保存。
6. 保存窗口所有操作提供自动化接口，确认和取消具有窗口关闭后仍可读取的完成回执；补充真实本地、SMB、设备、配置、ZIP 和键盘交互测试。

## English

1. Use one RHFiles-owned save window for image Save As, RHVideo configuration exports and ZIP exports, following the application's language and theme.
2. Provide address navigation, history, parent folders, favorites, open locations, recent save locations, drives, devices, filtering, hidden files, file types and folder creation.
3. Save to local filesystems, SMB shares and RHFiles devices, with read-only indicators and backend permission checks.
4. Require explicit replacement confirmation and recheck changed targets. Revision checks and atomic commits preserve existing data; cancellation creates no target, and closing the source window ends selection.
5. Virtualize large directories, ignore stale navigation responses, and prevent saving to an old location after a navigation error.
6. Expose all picker actions through automation APIs, with process-owned completion receipts that survive the picker closing. Cover actual local, SMB, device, JSON, ZIP and keyboard workflows.
