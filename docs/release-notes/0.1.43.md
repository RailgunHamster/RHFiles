# RHFiles 0.1.43

## 中文

- 移除选中行图标左侧那六个点：它是上一版加的"可拖动提示"手柄，实际只造成困惑，现已删除。
- 选中时线左侧改为明显的光效：整个名字栏（拖动区）从左向右渐强地铺一层强调色，右边缘再压一条实心强调色竖条并带柔光。连续选中的多行会连成一条完整的高亮，非选中行完全不受影响。
- 修复边界线与拖动区错位：之前连续线按表头列边界定位，实测在某些窗口尺寸 / DPI 下与文件行的名字栏边缘相差 19 像素。现在改为以真实渲染出来的行为准，并反向微调表头列轨道直到两者对齐。
- 用真实窗口截图逐像素验证：强调色竖条与连续线落在同一列上，渐变从 (212,228,255) 平滑过渡到线前的 (172,204,253)。

## English

- Removed the six dots left of the icon on selected rows: they were the previous "drag here" handle and only caused confusion.
- Selected rows now light up the zone left of the line: the whole name column gains an accent gradient that strengthens toward the line, capped by a solid accent bar with a soft glow sitting exactly on the line. Consecutive selected rows form one continuous highlight; unselected rows are untouched.
- Fixed the boundary line drifting from the drag zone: the line was positioned from the header column edge and could sit 19 pixels away from the file rows' name-column edge at some window sizes and DPI settings. It is now anchored to a rendered row, and the header column track is nudged until both agree.
- Verified pixel by pixel in a real window capture: the accent bar and the continuous line share the same column, and the gradient runs smoothly from (212,228,255) to (172,204,253) next to the line.
