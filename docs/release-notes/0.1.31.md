# RHFiles 0.1.31

## 中文

- 修复升级后、远程桌面分辨率变化或外接显示器断开后，RHFiles 只在任务栏显示缩略图但主窗口无法打开的问题。窗口位置与大小现在统一按物理像素保存和恢复，并会在启动时检查标题栏是否仍位于任一可用显示器内。
- 当已保存的窗口落在屏幕外、尺寸超过当前工作区，或点击任务栏/托盘恢复窗口时，RHFiles 会自动将窗口拉回主显示器；额外打开的 RHFiles 窗口也使用相同的安全恢复逻辑。
- 更新提示中的更新日志现在按 Markdown 的标题、段落、列表和换行显示，并使用独立的可滚动区域；同时提高了提示窗口中可读取的日志长度，不再把多行内容挤成一段。
- 新增窗口断屏、负坐标多显示器、分辨率缩小、超大窗口以及更新日志结构的回归测试，并通过真实的跨进程坏坐标恢复测试。

## English

- Fixed RHFiles appearing only as a taskbar thumbnail after an update, Remote Desktop resolution change, or disconnected monitor. Window bounds are now saved and restored consistently in physical pixels, and startup verifies that the title bar remains reachable on an available display.
- Saved windows that are off-screen or larger than the current work area are recovered onto the primary display. The same safety check runs when restoring the main window from the taskbar or tray and now also covers additional RHFiles windows.
- Update notifications now render release notes with Markdown headings, paragraphs, lists, and line breaks inside a dedicated scrollable area. The readable note limit was also raised so multi-line release notes are no longer compressed into one block.
- Added regressions for disconnected displays, negative-coordinate monitors, smaller resolutions, oversized windows, and structured update notes, plus a real cross-process recovery smoke test with persisted off-screen coordinates.
