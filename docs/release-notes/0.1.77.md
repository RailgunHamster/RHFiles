# RHFiles Windows 0.1.77

## 中文

1. 新增无中心服务器的设备组。每台设备独立使用 P-256 私钥，通过签名入组请求/批准交换公开证明；普通成员默认没有邀请权。
2. 本机移除按公钥身份记录，适用于本机所有设备组。重启、更新、更晚的成员证明、改名/换地址和组信息交换均不能自动加回；必须在本机点“手动恢复”并确认。移除邀请者会阻止其后续介绍，不撤销已独立接受的成员。
3. 设备组短期会话使用随机挑战、防重放和固定 HTTPS 证书；JSON API、WebDAV、下载和上传共用实时授权检查。本机共享范围和组读写/删除权限不由远端修改。
4. 文件服务可选择全部本机磁盘，并排除 RHFiles 私密配置和内部文件；支持编辑已配对设备权限、保存服务恢复设置及 Windows 登录后托盘自启动。
5. 监听和来源均限制为本机、局域网及 Tailscale 网段；不开放公网地址、不修改防火墙。所有设备组管理操作均提供本机命令行自动化接口。

设备组需要 Android 0.1.26 或更新版本。首次使用见 [设备组说明](https://github.com/RailgunHamster/RHFiles/blob/main/docs/DEVICE-GROUPS.md)。这是登录后托盘服务，不是无人登录也运行的系统服务。

## English

1. Decentralized device groups with independent P-256 device keys and signed request/approval exchange. New members cannot invite others unless explicitly authorized.
2. Persistent local removal across all local groups. Restarts, newer proofs, renames and address changes cannot re-add a removed identity. Restoration requires explicit local confirmation. Removing an introducer stops new introductions, not already accepted peers.
3. Replay-resistant challenges, pinned HTTPS, short-lived in-memory sessions and live authorization across native API/WebDAV/transfers. Remote proofs never change local file grants.
4. Local-drive selection, protected private files, editable paired-device grants and optional service restore / Windows login-to-tray startup.
5. Local/LAN/Tailscale interfaces and source addresses only; no public listener or firewall changes. Local semantic automation APIs cover every group action.
