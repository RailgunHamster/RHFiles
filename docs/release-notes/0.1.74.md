# RHFiles Windows 0.1.74

## 中文

1. 新增专门的回收站界面，可在侧栏查看当前 Windows 账号删除的文件和文件夹，支持搜索、排序、多选及复制原始路径。
2. 支持恢复所选、全部恢复和恢复并保留两者。同名项目默认跳过，不会覆盖已有文件或合并已有文件夹。
3. 支持永久删除所选及清空回收站，均需两次确认。清空只处理确认时的列表，不会删除之后进入回收站的新项目。
4. 恢复、删除接入文件任务面板，可取消并查看逐项结果；关闭回收站界面不影响后台任务。
5. 新增对应命令行自动化接口，并增加真实 Windows 回收站与前端业务回归测试。

## English

1. Added a dedicated Recycle Bin view for the current Windows account, with search, sorting, multi-selection and original-path copying.
2. Restore selected/all items or keep both copies. Existing files and folders are not overwritten or merged.
3. Permanently delete selected items or empty the reviewed snapshot, with two confirmations. Newly arriving items are excluded.
4. Recycle Bin jobs use the file-task panel, support cancellation and per-item results, and continue when the view is closed.
5. Added matching command-line automation actions and native Windows/frontend regression coverage.
