# RHFiles 0.1.48

## 中文

- 修复分卷 ZIP（`name.z01` … `name.zip`）解压失败的问题。之前对这类压缩包右键解压会报 `解压失败：invalid Zip archive: No CDFH found`——内置解压器只会打开最后一个 `.zip` 分卷，而它的条目数据都在前面的分卷里，单卷当然读不出来。
- 压缩包能力整体改为随包 7-Zip：`7z.exe` 与 `7z.dll` 现在和 Everything、dust、FFmpeg 一样随 portable 包一起发布，放在 `RHFiles.exe` 同目录。所有压缩包的解压与浏览（ZIP 含分卷、7z、RAR、cab、ISO 等）都由这份自带的 7-Zip 完成，不再依赖用户机器上装没装 7-Zip；创建 ZIP 压缩包仍是内置实现。
- 7-Zip 的查找顺序：优先用 RHFiles 同目录的自带副本（`7z.exe` 与 `7z.dll` 必须成对），其次是系统安装的 7-Zip（Program Files / PATH）。三者都找不到时才提示保留自带文件或安装 7-Zip。
- 双击压缩包现在可以浏览内容列表（含大小与修改时间，修改时间是新增的，旧版 ZIP 浏览不显示），列表里「全部解压」、以及只解压单个文件都照常可用，进度与取消行为与其它解压一致。
- 传给 7-Zip 的单文件名做了防通配符处理：包含 `*`、`?` 或以 `-`、`@` 开头的条目名会被拒绝，不会被误当成命令行开关或通配符；解压统一带空密码参数，加密压缩包会直接报「密码错误」而不是卡住等待输入。
- 打包新增 `scripts/prepare-7zip.ps1`：从 7-Zip 官方发布固定版本 26.03（SHA256 校验、断线重试、7-zip.org 备用源），用官方 `7zr.exe` 从安装包中解出未修改的 `7z.exe`/`7z.dll` 与 `License.txt`，并验证版本号后放入 `src-tauri\thirdparty\`；`package-velopack.ps1` 会把它们随包发布并附带 `7zip-LICENSE.txt`。
- 新增 8 项后端单元测试：7-Zip 技术列表解析、传给 7-Zip 的条目名过滤、显示名截取，以及三项端到端测试——普通 ZIP 与按真实分卷工具（WinRAR/Bandizip）写法手工拆成的 `.z01` + `.zip` 两卷都能被完整列出（未找到 7-Zip 的机器上自动跳过）。

## English

- Fixed extraction of split ZIP archives (`name.z01` … `name.zip`). They used to fail with `Extract failed: invalid Zip archive: No CDFH found`: the built-in extractor opened only the final `.zip` volume, whose entry data lives in the earlier volumes, so it could never parse alone.
- Archive support now runs on a bundled 7-Zip: `7z.exe` and `7z.dll` ship in the portable package next to `RHFiles.exe`, alongside Everything, dust, and FFmpeg. All extraction and browsing (ZIP including split volumes, 7z, RAR, cab, ISO, …) uses this bundled copy, so nothing has to be installed on the user's machine; creating ZIP archives remains the built-in implementation.
- 7-Zip lookup order: the bundled pair beside RHFiles.exe first (`7z.exe` and `7z.dll` must both exist), then an installed 7-Zip (Program Files / PATH). Only when none is found does RHFiles ask to keep the bundled files or install 7-Zip.
- Double-clicking an archive now browses its entry list with sizes and modification times (timestamps are new; the old ZIP browser never showed them). "Extract all" and single-entry extraction work from that view with the usual progress and cancellation.
- Entry names handed to 7-Zip are wildcard-safe: names containing `*`/`?` or starting with `-`/`@` are rejected instead of being interpreted as switches or wildcards; extraction always passes an empty-password switch so encrypted archives fail with "wrong password" instead of hanging on a prompt.
- Packaging gained `scripts/prepare-7zip.ps1`: it pins official 7-Zip 26.03 (SHA256-verified, retry with a 7-zip.org fallback), uses the official `7zr.exe` to pull the unmodified `7z.exe`/`7z.dll` and `License.txt` out of the installer, verifies the version, and stages everything under `src-tauri\thirdparty\`; `package-velopack.ps1` ships them with `7zip-LICENSE.txt`.
- Added eight backend unit tests: 7-Zip technical-listing parsing, 7-Zip entry-name sanitizing, display-name splitting, plus three end-to-end checks covering both a plain ZIP and a `.z01` + `.zip` split set built exactly the way real splitters (WinRAR/Bandizip) write them (silently skipped when no 7-Zip is found).
