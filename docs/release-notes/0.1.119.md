# RHFiles Windows 0.1.119

发布日期 / Release date: 2026-11-09

## 中文

1. 修复图片查看器误用旧语言设置的问题，文字、提示和无障碍名称跟随主界面语言，并响应语言切换。
2. 图片查看窗口默认最大化，保留标题栏与任务栏；不会自动进入独占全屏。
3. 逐张翻页与连续浏览都支持首尾相接，上一张／下一张和连续自动滚动沿当前文件夹的排序循环，单张图片不重复滚动。
4. 底部新增总进度条：拖动预览序号与文件名，松手快速跳转；提供 Home／End 与对应脚本接口。快速连续跳转按顺序执行，避免丢失最后一次操作。

## English

1. The image viewer now follows the actual main-window language, including text, tooltips, accessibility labels and live language changes.
2. Open maximized with the normal title bar and taskbar; do not automatically enter fullscreen.
3. Paged and continuous images wrap in either direction using the existing queue order. Continuous auto-scroll also wraps; a single image remains stationary.
4. Add an overall progress bar with target preview and release-to-seek, Home/End support and a matching API. Serialize rapid seeks so the final request is retained.
