# RHFiles Windows 0.1.81

## 中文

1. 改进设备组冷启动及闲置后的连接恢复：首选地址最多验证 6 秒，传输故障可在原预算内短暂退避后重试一次。每轮仍限制 15 秒、6 次尝试，不增加持续后台探测。
2. 按当前网络排序候选地址，跳过远端回环地址，独立保存成功地址提示。重新启动后仍会核验设备身份，历史地址不等于授权。
3. 自动请求按需冷却 2、5、15、30 秒；手动连接可受限地越过自动冷却，连续失败的手动点击仍限速。无访问需求时不自动重试。
4. Windows 根据目标地址实际选中的本机路由判断网络变化，避免无关虚拟网卡变化使连接作废。
5. 连接诊断增加尝试次数、剩余预算、冷却剩余时间、受限重试和地址类型。Tailscale 地址不会被误称为已确认的直连或中继。身份不符及授权拒绝停止尝试，不重放结果不明确的写入。

## English

1. Allow up to six seconds for a cold preferred-route handshake and one bounded transport retry with short backoff. Keep the original fifteen-second/six-attempt budget and no continuous background probing.
2. Rank candidates for the current network, skip remote loopback hints, and persist successful address hints separately from sessions. Every new connection still verifies the device identity; address history never grants access.
3. Gate automatic demand with 2/5/15/30-second cooldowns. Explicit manual connection may bypass automatic cooldown with rate limiting; no demand means no automatic retry.
4. Detect local route changes for the actual destination rather than unrelated virtual interfaces.
5. Expand connection diagnostics with attempt counts, remaining budgets, cooldowns, retry reasons and address types. A Tailscale address does not imply an observed direct/relay path. Identity/permission failures stop retries; ambiguous writes are not replayed.
