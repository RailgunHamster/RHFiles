# RHFiles 0.1.54

## 中文

- 修复 0.1.53 漏打包的翻译：设置 → 预览里的「预览音量」标签与说明在 0.1.53 中会显示成原始键名（`settings.previewVolume`），本版本补齐 `settings.previewVolume` 与 `settings.previewVolumeHelp` 的中英文文案。
- 行为与 0.1.53 一致，仅补翻译。0.1.53 的其余改动（预览音量、脚本图标、F5 布局稳定、缩略图按版本缓存、视频缩略图、ESC 取消重命名后重新选中、快速访问/库拖放）都在本版本中同样可用。

## English

- Fixes a packaging omission in 0.1.53: the Preview → "Preview volume" row rendered its raw key (`settings.previewVolume`) because the two i18n entries were not committed with that release. This version ships `settings.previewVolume` and `settings.previewVolumeHelp` in both languages.
- Behavior matches 0.1.53; this is the translation fix only. Every 0.1.53 change (preview volume, console icons for scripts, stable layout on F5, versioned thumbnail cache, video thumbnails, ESC rename re-selection, Quick access/Libraries drag & drop) is included here as well.
