# RHFiles Windows 0.1.90

## 中文

1. RHVideo 单视频与同屏在媒体库内使用原生画布播放，关闭播放返回浏览层。每格直接提供收藏、暂存标记、展开、暂停、进度、静音、音量及六档速度；整体控制可展开，并有对应的公开接口。
2. 修复换组时尚未松开的音量／进度手势误操作新输入，关闭后迟到的准备重新打开同屏，以及加载中打开设置被旧结果覆盖的问题。旧面板、旧输入及旧布局请求不能操作新面板。
3. 包含此前尚未发布的图片工具栏、收藏错误全文、父预览返回、原生窗口生命周期与首个画布显示修复；安装包自带 libVLC 3.0.24，无需另装 VLC。
4. 这是阶段性功能版本，不宣称 RHVideo 完整 1:1 或性能对齐完成。已知待办：播放进度与源码帧时间仍可能相差数百毫秒；小窗口／多格布局及全平台持续播放仍需完善。完整优先级见 `docs/RHVIDEO-TODO.md`。

## English

1. Native single and multi-video playback stays in the media library. Each cell has direct favorite, staging, expand, pause, seek, mute, volume and six-rate controls. Aggregate controls and UI operations expose structured APIs.
2. Fence held gestures, stale decoder/layout/host requests and delayed Grid preparations. Closing Grid or opening Settings cannot be undone by late metadata.
3. Includes previously unreleased preview toolbar, complete favorite-error details, parent-preview return and native host/first-surface fixes. Ships libVLC 3.0.24.
4. Incremental release, not complete functional/performance parity. Known work includes several-hundred-millisecond progress/frame skew, compact multi-cell layout and sustained cross-platform playback. See `docs/RHVIDEO-TODO.md`.
