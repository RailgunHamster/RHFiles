# RHFiles 0.1.49

## 中文

- 解压失败时的报错信息现在会带上 7-Zip 的**退出码**，并且在 stderr 为空时附上 stdout 的最后几行输出。0.1.48 里「7-Zip extraction failed」这种没有任何线索的报错（7z 非零退出、无任何错误文本，通常是 7z.exe 被杀软拦截、DLL 加载失败或崩溃一类"无声死亡"）以后会直接给出可定位的信息，例如 `7-Zip extraction failed (exit code -1073741515)`。
- 浏览压缩包（列表）失败时同样附带退出码与输出尾部。
- 行为无其它变化；如果你在 0.1.48 上遇到「7-Zip extraction failed」，请更新到本版本重试一次，新的报错内容能直接指出原因（请把它发给我们）。

## English

- Extraction failures now include the 7-Zip **exit code**, plus the last stdout lines when stderr is empty. The bare "7-Zip extraction failed" message from 0.1.48 (non-zero exit with no error text at all — typically an AV-blocked, DLL-load-failed, or crashed 7z.exe) now produces actionable output such as `7-Zip extraction failed (exit code -1073741515)`.
- Archive listing failures include the exit code and output tail the same way.
- No other behavior changes; if you hit "7-Zip extraction failed" on 0.1.48, update to this version and retry — the new message identifies the cause directly (please send it to us).
