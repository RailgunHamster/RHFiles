# RHFiles Windows 0.1.88

## 中文

1. 纠正 RHVideo 播放行为：取消自行合并的“播放方式”下拉框，分别提供截图库分段连播、当前列表顺序连播、顺序超压连播和同屏播放。分段队列按截图浏览位置去重取视频；顺序队列保持当前筛选后的完整列表顺序，不用多选替代。
2. 三种连播各自保存位置、速度和循环设置；只有完整视频顺序相同时才恢复位置。随机片段起点、短视频长度和整段进度定位按参考源码处理。
3. 手动上一项、下一项首尾回绕；非循环的最后一项播放完成后关闭连播。循环保持当前片段起点，不重新抽取。整段进度条可跨视频定位，完整播放和每段时长可在播放器调整。
4. 恢复视频与截图的返回栈：截图进入视频后可返回原图，方向键返回父截图队列继续浏览；普通视频卡片保留首张对应截图，准备元数据时不弹出截图库。明确提供普通和超压播放入口。
5. 播放器可收藏、标记暂存；预览标记和列表多选分离，真正关闭预览后才按标记顺序移入 RHVideo 暂存区。逐项结果可查看，失败终止，不会在下一次关闭时重新提交。
6. 修复播放器初始化时立即操作收藏报错、下一项切换丢失速度的问题。连播中的媒体读取失败会有限地向后跳过；不因循环设置而重试损坏媒体，全部失败时结束并提示。
7. 增加直接执行 RHVideo 源码函数的差分测试和真实原生播放器行为回归，纠正此前把错误行为写成通过条件的测试。本版修复列出的播放语义，不宣称全功能 1:1 或所有显卡上的首播流畅度已验收；Android 包本次不变。

## English

1. Restore separate screenshot-gallery segment playback, filtered-list sequential playback, sequential low-bandwidth playback, and multi-video playback instead of a combined mode dropdown. Gallery queues start at the browsed frame and deduplicate videos; sequential playback preserves the full filtered list order, not multiselection.
2. Keep independent cursors, speed and repeat settings per playlist type. Resume only when the complete ordered video IDs match. Match source-sized segment bounds, random start rounding, and whole-queue seeking to the reference implementation.
3. Wrap manual previous/next navigation and close a non-repeating playlist when its last entry finishes. Repeat the same planned segment, rather than selecting a new random one. Add whole-queue seeking and in-player full-length/segment controls.
4. Restore video/screenshot parent navigation, including the exact originating frame and arrow navigation in the parent gallery. A normal video card retains its first matching screenshot without flashing a gallery during preparation. Provide explicit normal and low-bandwidth actions.
5. Add player favorites and deferred preview trash marks, separate from list multiselection. Commit marks in insertion order only when the preview actually closes. Show per-item results; failed writes are terminal and never replayed on the next close.
6. Fix immediate actions during player initialization and speed loss when switching native entries. Failed playlist media skip forward within the finite queue, ignoring repeat for the failed item; all-failed queues terminate visibly.
7. Add differential tests executing actual RHVideo source functions and native behavioral acceptance, correcting old expectations that encoded incorrect behavior. This release does not establish complete functional parity or smooth first-frame performance on every GPU. The Android package is unchanged.
