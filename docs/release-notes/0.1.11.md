# RHFiles 0.1.11

- 修正“浏览器”的含义：右键操作现在明确使用 Windows 资源管理器（Explorer），不再调用 Edge、Chrome 等网页浏览器。
- 对文件夹直接打开对应目录；对普通文件打开其所在目录并选中该文件。
- 本地路径、包含空格的路径及 UNC/SMB 路径均直接按 Windows 路径交给 Explorer，不再转换为 `file://` URL。
- 家庭服务器发布只写入 `RHFiles-Releases` 更新目录，不再在上级 `Software` 目录重复创建 portable 压缩包。
- 键入搜索默认使用 `Alt+[` 切换到上一个匹配项、`Alt+]` 切换到下一个匹配项；仍可在设置中重新绑定，旧版未修改的 F3 默认绑定会自动迁移。
