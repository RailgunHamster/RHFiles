# RHFiles Windows 0.1.107
1. 修复 Windows 文件对话框与资源管理器旁边的 **“RHFiles 已打开位置”** 伴随悬浮窗列表为空白的问题（补齐 `integration-picker.html` 中缺失的 `automation-core.js` 脚本引用，并优化后台窗口标签页路径同步）。
2. 修复 **详细 / 缩略图 / 卡片** 视图在切换文件夹或标签页时乱跳、以及从“缩略图”莫名切换到“卡片”的问题：
   - 将图片文件夹的自适应布局由 `cards`（卡片）修正为 `thumbnails`（缩略图），不再把缩略图强行切成卡片；
   - 进入未单独设置过布局的普通文件夹或切换标签页（`switchTab`）时，自动应用目标文件夹已保存的布局（支持子文件夹继承父文件夹的显式布局）或回退到默认“详细”视图，避免把上一个文件夹的卡片/缩略图状态串台带到所有普通目录。
## English
1. Fixed an issue where the **Open RHFiles locations** companion window beside Windows Open/Save file dialogs and File Explorer appeared blank (added the missing `automation-core.js` script include to `integration-picker.html` and synced tab locations from unfocused windows).
2. Fixed **Details / Thumbnails / Cards** layout jumping across folders and tabs or unexpectedly switching from Thumbnails to Cards:
   - Changed adaptive image-folder detection from `cards` to `thumbnails` so image folders are never forced from Thumbnails into Cards;
   - Restored per-folder layout on both folder navigation and tab switching (`switchTab`), with normalized path keys, parent-folder layout inheritance for subfolders, and clean fallback to the default `details` view for unconfigured folders.
