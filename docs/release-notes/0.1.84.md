# RHFiles Windows 0.1.84

1. RHVideo 视频清单支持 ETag 条件校验：未变化的媒体库不重复下载和解析，短时间内的翻页与搜索复用已有清单。
2. 以共享只读引用复用整库元数据，减少翻页和输入搜索时的内存分配。
3. 收藏只更新对应按钮，不再重建整页卡片、重新加载和解码缩略图。

本版是现有 RHVideo 客户端的局部性能改进；完整功能迁移及最终播放性能优化尚未完成。原生视频播放仍需 64 位 VLC 3.x。

## English

1. Added conditional RHVideo catalog revalidation with ETag support and short-lived in-memory paging/search reuse.
2. Reuse shared read-only catalog metadata instead of deep-copying the library for each request.
3. Favorite changes update only the affected button, retaining decoded cover images and card state.

This is an incremental client optimization, not full RHVideo feature parity or final playback performance. Native video playback still requires 64-bit VLC 3.x.
