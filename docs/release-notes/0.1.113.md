# RHFiles Windows 0.1.113

1. 更新记录仅将最新一条单独展示；其余记录从新到旧统一放入历史记录，每页 10 条，显示页码并支持前后翻页。
2. 翻页保留最新记录的展开状态，不重复联网；补充首条、分页边界和完整历史无遗漏的回归测试。

## English

1. Only the latest release is featured separately. All earlier releases appear in a single history list, newest first, with 10 records per page and previous/next controls.
2. Paging preserves the featured release's expansion without network requests. Regression tests cover the single featured record, page boundaries and complete history coverage.
