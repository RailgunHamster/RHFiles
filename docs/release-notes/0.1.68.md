# RHFiles 0.1.68

## 中文

- 修复分卷压缩包没有右键解压选项的问题。支持 `.7z.001/.002`、`.zip.001/.002`、普通 `.001/.002`、`.z01/.z02`、RAR `.part1/.part01.rar` 和旧式 `.r00/.r01` 等命名。
- 从任意分卷解压、浏览或检查密码时，自动定位正确的入口卷。同一组分卷多选后只解压一次；默认输出目录去掉分卷编号，避免生成 `文件名.7z` 或 `文件名.part01` 等不合适的文件夹名。
- 缺少首卷或 ZIP 目录卷时明确提示缺失路径。整组分卷仍需放在同一文件夹中，不会修改原分卷文件。
- 内置与 Fluent 图标模式将分卷显示为压缩包；补齐已经有压缩包图标的 XZ、Zstandard、CAB、ISO 等格式的右键解压入口。
- 增加分卷识别、整组多选去重、入口卷缺失、加密分卷和真实分卷解压的回归测试。

## English

- Fixed missing extraction actions for split archives, including `.7z.001/.002`, `.zip.001/.002`, generic `.001/.002`, `.z01/.z02`, RAR `.part1/.part01.rar` and older `.r00/.r01` names.
- Extraction, browsing and password checks from any selected part locate the proper entry volume. Selecting multiple parts of one archive extracts it only once. Default output folders omit archive extensions and volume numbers.
- Missing entry volumes now report their expected path. Keep all parts in the same folder; the original volumes are not modified.
- Built-in and Fluent icons recognize split archives. Added extraction actions for formats that already had archive icons, including XZ, Zstandard, CAB and ISO.
- Added regression tests for recognition, selection deduplication, missing entry volumes, encrypted splits and real multi-volume extraction.
