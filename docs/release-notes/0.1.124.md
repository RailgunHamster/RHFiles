# RHFiles Windows 0.1.124

发布日期 / Release date: 2026-11-11

## 中文

1. 优化 RHFiles 设备的普通删除：同设备文件分批提交，由目标电脑直接移入回收站，减少逐项权限、元数据和删除请求的网络往返。
2. 操作完成后立即返回回执；耗时操作等待完成通知，消除固定轮询间隔造成的累积等待。断线只查询原操作回执，不重新发送删除。
3. 批量回收保留文件版本检查、逐项结果、目标回收站恢复和 Ctrl+Z；Shift+Delete 仍为永久删除。
4. 修复连续图片浏览缩小时只改变图片尺寸、未同步调整图片间距而出现黑色空档的问题。
5. 增加批量回收、权限、嵌套路径、文件被替换、回执重复提交及通知等待测试。

## English

1. Batch ordinary RHFiles-device deletions on the hosting computer, preserving its Recycle Bin while reducing per-item network round trips.
2. Return fast mutation results immediately and wait for completion signals for longer operations. A disconnected client reads the original receipt without resubmitting deletion.
3. Preserve revision checks, individual outcomes, server-side restore and Ctrl+Z. Shift+Delete remains permanent deletion.
4. Keep image widths and spacing aligned when zooming out in continuous browsing.
5. Test batch recycling, permissions, nested paths, replaced files, receipt deduplication and completion signalling.
