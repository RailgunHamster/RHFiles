# RHFiles 0.1.9

- 重新设计右侧检查器：预览与空间占用现在是两个互斥状态，打开其中一个会立即替换另一个；关闭或切换时会取消旧的预览 / 分析任务，避免过期结果回写。
- 设置窗口扩大为桌面式工作区，并按常规、外观、文件与布局、预览、搜索、更新与网络、快捷键和数据八类组织。
- 新增纸白、深色、暖沙、薄雾、森林和石板六套内置主题；支持从 `%APPDATA%\RHFiles\themes\*.json` 热加载用户主题，无需重编译或重启。
- 用户主题采用版本化 JSON 格式、亮 / 暗基础层和受控 CSS 变量；高级 CSS 覆盖独立保留，用于布局与组件级实验。
- 设置中新增完整版本记录，可从 GitHub 或家庭服务器读取累计发布日志，并与客户端内置的离线历史合并。
- 发布包与 GitHub Release 现在附带自动生成的 `release-history.json`，构建会校验当前版本及全部版本日志。
- 为 GitHub 项目首页补充中英双语 README、下载说明、搜索 / 预览 / 更新行为与主题包文档。
