# RHFiles Windows 0.1.114

1. “清空回收站”移至回收站顶部工具栏；右键左侧导航的回收站入口也可直接清空，无需先离开当前文件夹。
2. 顶部按钮、右键菜单和 `recycle.empty` 接口统一读取最新列表，经过两次确认后仅删除本次快照中的项目；不会因筛选而漏删，也不会连带删除确认期间新进入回收站的文件。

## English

1. Empty Recycle Bin is now available in the top toolbar and the navigation sidebar's Recycle Bin context menu, without changing the current folder.
2. Both UI entries and the `recycle.empty` API use a fresh snapshot and two confirmations. Filters cannot limit the operation, and newly recycled files remain untouched.
