# RHFiles 0.1.40

## 中文

- 修复名字栏分隔线错位：表头现在动态补偿右侧框选条和实际滚动条宽度，与文件行使用同一个列轨道，边界对齐。
- 重做分隔线视觉：移除选中行里突兀的整块名字栏底色和硬直线，改为常态低对比度的短分段标记，悬停和选中时才稍微加强；卡片、缩略图和列布局不再显示不适用的详情列分隔线。
- tab 悬停预览现在也支持当前 tab；左右窗格的 tab 都统一绑定预览，并按所属窗格读取正确的目录内容。
- 增加表头 / 文件行边界对齐回归测试，确保两者的 x 坐标误差不超过 1.5px。

## English

- Fixed the name-column divider drifting out of alignment: the header now dynamically compensates for the right-side marquee gutter and the actual platform scrollbar, so it shares the same column track as file rows.
- Refined the divider visual: removed the heavy nested selected-row tint and hard full-height line, replacing it with a quiet segmented marker that becomes slightly stronger on hover or selection. The marker is limited to details layout, where the column boundary applies.
- Tab hover previews now include the active tab; left and right pane tabs are bound consistently and load the directory belonging to the hovered pane.
- Added a regression check that keeps the header and row drag-boundary x coordinates within 1.5px.
