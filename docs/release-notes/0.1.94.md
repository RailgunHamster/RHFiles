# RHFiles Windows 0.1.94

1. 补齐 Windows 的 RHFiles 设备路径复制、剪切和粘贴：支持本机与设备之间、设备与设备之间的文件及文件夹流式传输，不再把设备路径交给 Windows 本地文件接口。
2. 同名文件夹使用合并流程；同名文件沿用替换、跳过、保留两者确认。替换、移动源清理使用文件身份与版本条件，不能因路径被重新创建就误覆盖或误删。对方服务也需更新至本版，才能支持远端替换与安全移动；旧服务仍可接收不覆盖的新文件复制。
3. 文件任务显示实际已传字节、百分比、速度和当前文件；分块处理、内存有上限，支持任务独立取消。写入失败不自动重放，目标完整提交后才清理移动源；部分清理失败时保留完整目标副本。
4. 增加中断操作恢复记录。恢复只向空闲路径还原原文件，不覆盖后来出现的文件，也不自动继续旧的移动或删除；无法安全恢复的服务端操作会在文件服务设置中显示提示，不阻断其他目录访问。
5. 新增可选的 Tailscale 可信 HTTPS WebDAV 兼容入口（默认 39129，原设备组端口不变），可为已接受的组成员生成资源管理器兼容凭据。凭据只保存摘要、不参与配置同步，随组或成员移除立即撤销，重新加入不会复活；关闭入口、轮换或撤销凭据也会终止对应授权。提供本机 WebClient 诊断，不关闭证书校验、不启用明文密码、不恢复独立配对。启用前提示证书透明度披露，启动服务时检查证书续期。
6. 包含缺少 Windows 虚拟桌面标识时的安全启动兜底，旧版 0.1.72 用户应升级当前安装目录中的程序，而不只是再次启动旧快捷方式。

注意：远端传输暂不加入撤销历史；符号链接和重解析点不会被跟随，文件夹不会整体替换。本版没有新增 Android APK，Android 稳定渠道保持原版本。

## English

1. Added native copy/cut/paste for RHFiles device paths: stream files and folders between local storage and devices, or between devices, without sending virtual device paths to Windows filesystem APIs.
2. Same-named folders use the merge workflow. File conflicts keep Replace, Skip and Keep both. Identity/revision conditions prevent replacing or deleting a recreated path. Update the remote service too for replacements and safe moves; older services can still receive new files without replacement.
3. Tasks report actual bytes, percentage, speed and current files. Transfers use bounded chunks and scoped cancellation. Failed writes are not automatically replayed. Move sources are removed only after destination publication; completed destinations remain safe after partial source-cleanup failure.
4. Added interruption recovery records. Recovery restores originals only into vacant names and never replays an old move/delete or overwrites newly arriving files. Unresolved server-side records appear in file-service settings without disabling unrelated directory access.
5. Added an optional Tailscale CA-trusted HTTPS WebDAV endpoint (default port 39129, leaving pinned device endpoints unchanged). Generate Explorer-compatible credentials for accepted group members only. Only password digests persist; passwords never synchronize. Group/member removal revokes access immediately, including after rejoining. Disabling the endpoint or rotating/revoking credentials invalidates authorization. Includes WebClient diagnostics without weakening TLS/password safeguards or restoring standalone pairing. Enabling acknowledges public certificate transparency; certificates are checked/renewed when starting the service.
6. Includes safe startup fallback when Windows virtual-desktop identity is unavailable. Users upgrading from 0.1.72 must update the executable behind the original shortcut rather than launch the old copy again.

Limitations: remote transfers do not yet enter undo history. Symbolic links/reparse points are not followed, and directories are never replaced wholesale. This release does not publish a new Android APK.
