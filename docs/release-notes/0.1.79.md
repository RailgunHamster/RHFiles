# RHFiles Windows 0.1.79

## 中文

1. 设备组新增“删除本机设备组”：确认后删除本机整组记录，从界面移除，不再留下恢复入口。不会删除实际文件，也不影响其他客户端、其他组或独立配对账号。
2. 删除后重启、刷新或收到旧证明都不能自动加回；需要重新生成入组请求，由仍保留该组且有邀请权限的客户端批准，再在本机确认。原创建者也可按此流程重新加入。
3. 删除立即阻止该组旧会话及已打开流继续访问；重新入组也不会复活删除前的会话。其他组会话和对其他设备的本机拒绝记录保持不变。
4. 设备名称默认使用本机计算机名，可在创建组或申请入组前修改；不自动重命名已有成员，也不改变公钥身份。
5. 新增本机自动化操作 `groups.forget`，必须指定组 ID 并明确传入 `confirmed: true`。补充删除确认/取消、保存失败、重启持久化、拒绝记录保留和真实界面重新入组测试。

配套 Android 版本为 0.1.27；已有设备组协议兼容。

## English

1. Add “Delete group from this device”: explicit confirmation forgets the entire local group without a restore stub. Files, other clients/groups and independent pairing credentials are unaffected.
2. Restart, refresh and old proofs cannot automatically restore a forgotten group. Generate a fresh request, have a remaining invite-capable member approve it, then explicitly accept it locally—even if this device originally created the group.
3. Forgotten-group credentials and active streams stop working immediately and remain invalid after rejoining. Other groups' sessions and local refusals for other devices remain intact.
4. The editable device-name field defaults to the local computer name, without renaming existing members or changing cryptographic identities.
5. Add the local `groups.forget` automation action with a group ID and `confirmed: true`, plus confirmation/cancellation, persistence failure, relaunch, refusal retention and real-UI rejoin regressions.

Companion Android version: 0.1.27. Existing group protocol compatibility is preserved.
