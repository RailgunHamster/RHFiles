# RHFiles Windows 0.1.123

发布日期 / Release date: 2026-11-10

## 中文

1. 新增内置 PDF 阅读器，默认最大化打开，可在设置中切换使用系统默认应用。
2. 支持本地、SMB 共享和 RHFiles 设备中的 PDF；设备文件直接按需读取，不先创建完整工作副本。
3. 支持连续阅读、页码跳转、缩放、适应宽度/整页、旋转、全文搜索、文本选择、文档目录和密码文档。
4. 另存为接入 RHFiles 保存窗口，支持本地和设备目标、明确覆盖确认、源文件版本检查。
5. 离线附带 Mozilla PDF.js、中文 CMap、标准字体及图片解码器，限制画布大小并按需读取大文档。文档脚本不执行。
6. 全部阅读操作提供自动化接口；补充中文、加密、500 页文档、分段读取、SMB 和设备权限撤销测试。

## English

1. Add a built-in PDF reader that opens maximized, with an optional system-app preference.
2. Read local, SMB and RHFiles-device PDFs. Device files use range access without first creating a complete working copy.
3. Support continuous reading, page jumps, zoom, fit width/page, rotation, full-text search, selectable text, outlines and password-protected documents.
4. Integrate Save As with the RHFiles picker, including local/device targets, explicit replacement confirmation and source revision checks.
5. Bundle Mozilla PDF.js, CMaps, standard fonts and decoders for offline use. Bound canvas sizes and load large documents on demand; document scripts are not executed.
6. Expose reader actions through automation APIs and cover Chinese, encryption, 500-page documents, range access, SMB and revoked device permissions.
