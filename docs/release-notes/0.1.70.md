# RHFiles 0.1.70

## 中文

- Windows 文件右键菜单新增“Markdown 转 PDF”，支持中文、表格、图片和多页排版，全程本地转换。
- 默认使用 WebView2 打印引擎；可通过独立的 `document-converters.json` 配置其他本地转换器，无需编译。设置 → 文件中可打开配置。
- 转换支持任务面板、取消、超时和错误提示，已有 PDF 不会覆盖，原 Markdown 不修改。
- 同步发布 Android 0.1.6：抽屉实时跟手、长列表滚动与误多选修复、原生 Media3 播放器、图片查看器与首页索引卡片改版。

## English

- Windows: local Markdown-to-PDF conversion in the file context menu, with Chinese text, tables, images and pagination.
- Built-in WebView2 printing plus configurable local command providers, without recompilation. Open configuration from Settings → Files.
- Task-panel progress, cancellation, timeout and failure reporting; source and existing PDFs are never overwritten.
- Android 0.1.6 separately adds a finger-tracking drawer, stable virtualized scrolling, a native Media3 player, a refreshed image viewer and a quieter index status card.
