# RHFiles Windows 0.1.118

发布日期 / Release date: 2026-11-09

## 中文

1. 连续图片浏览改为按等比缩放后的实际图片宽度衔接，消除两张图片之间由整屏容器产生的黑色间隔，完整保留图片内容。
2. 连续浏览新增自动滚动，可调节速度、暂停和继续；拖动、缩放、切换模式或离开查看器时暂停，到最后一张停止。
3. 补充图片衔接、不同长宽比及自动滚动的接口和回归测试。

## English

1. Join fitted image edges instead of full-width containers in continuous browsing, removing inter-image letterboxing while preserving complete pictures.
2. Add adjustable automatic scrolling with pause/resume. Manual navigation, zooming, mode changes and leaving the viewer stop it; the final image stops the loop.
3. Add matching automation actions and regression coverage for image geometry and automatic scrolling.
