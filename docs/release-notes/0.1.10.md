# RHFiles 0.1.10

- 新增完全离线的 3D 预览：支持 glTF/GLB、OBJ/MTL、FBX、STL、PLY 和 3MF，并支持 glTF 的 Draco、Meshopt 压缩。
- 3D 查看器提供旋转观察、缩放、平移、视角复位、线框、自动旋转和动画播放，并可沿用检查器的全屏模式。
- 3D 资源仅在选中对应文件时按需加载；切换文件或关闭预览会取消读取并释放模型、纹理、动画和 WebGL 上下文。
- 对自动预览设置 128 MiB 文件上限和三百万三角面上限，避免异常模型长期阻塞或占满内存；CAD 格式暂不纳入本版。
- 文件、文件夹、空白区域、标签页、磁盘、收藏、最近项目、云盘和网络位置的右键菜单新增“用默认浏览器打开文件夹”。选择普通文件时会打开其所在文件夹。
- 本地路径、包含空格的路径和 UNC/SMB 路径会转换为正确的 `file://` URL，再交给 Windows 当前默认浏览器。
