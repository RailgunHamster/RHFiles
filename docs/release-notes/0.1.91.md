# RHFiles Windows 0.1.91

## 中文

1. 修复粘贴 `rhfiles-group-invite:v1:` 设备组邀请时错误地按批准信息解析、提示“设备组信息类型不正确”的问题。Windows 现在也可以直接使用完整邀请文本加入已有组；邀请设备须保持文件服务在线，邀请两分钟内有效且仅可使用一次。
2. 加入按钮与中英文说明明确区分邀请、入组请求和批准信息；入组请求需要交给已有成员批准，不再只返回笼统的类型错误。原有离线请求／批准流程继续可用。
3. 邀请兑换校验证书指纹、组身份、邀请成员签名和本机请求；保留本机移除规则。只在请求尚未送达的连接失败时尝试其他地址，发送后超时或响应中断不会自动重放授权。
4. 保留 0.1.90 的阶段性 RHVideo 改进及已公开的性能／功能待办，不代表完整 1:1 对齐完成。

## English

1. Windows now redeems complete `rhfiles-group-invite:v1:` invitations instead of incorrectly parsing them as approval packets. Keep the inviting device’s file service online; invitations expire after two minutes and are single-use.
2. Join labels distinguish invitations, requests and approvals. Requests explain the required approval workflow; offline request/approval remains supported.
3. Pin TLS and validate group identity, issuer signature and the local request. Local removals remain effective. Only pre-send connection failures may try another address; uncertain authorization outcomes are never replayed automatically.
4. Includes the incremental RHVideo changes and known functional/performance limitations of 0.1.90; complete parity is still outstanding.
