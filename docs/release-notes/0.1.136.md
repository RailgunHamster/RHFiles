# RHFiles Windows 0.1.136

1. 修复新建文件夹后未能跳转并进入内联重命名的问题：创建后自动选中、滚动定位到新文件夹（含虚拟滚动长列表与分组视图），并稳定保持重命名输入框焦点，同时支持详细、卡片、缩略图和分栏全部四种布局以及中文输入法选词。
2. 修复后台目录刷新与点击输入框内部打断内联重命名的问题，新建文件后也会自动选中并跳转到新文件位置。
3. 新建文件夹与新建文件的默认名称支持按当前语言翻译（中文为「新建文件夹」「新建文件」，英文为「New Folder」「New File」，并为常见语言提供默认名称回退），本地目录、设备互联与 FTP 均已适配。

1. Fixed new-folder creation failing to reveal and rename the newly created folder: RHFiles now selects and scrolls directly to the new folder (including virtualized long lists and grouped views), keeps inline rename focus stable across Details, Cards, Thumbnails, and Columns layouts, and respects IME composition.
2. Prevented background folder refreshes and clicks inside the rename input from interrupting inline renaming, and made creating a new file select and scroll to the new file as well.
3. Localized default names for new folders and new files according to the active language (e.g. "新建文件夹" / "新建文件" in Chinese, "New Folder" / "New File" in English, with localized fallbacks for common languages) across local folders, RHFiles devices, and FTP.
