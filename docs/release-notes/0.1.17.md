# RHFiles 0.1.17

- 修复从 Windows Explorer、远程桌面等系统剪贴板粘贴文件时，任务中心只显示“准备中”后直接成功的问题；现在会连续显示已复制大小、总大小、百分比、当前文件、实时速度和预计剩余时间。
- 接入 Windows `IFileOperation` 的原生进度与取消回调，剪贴板复制和移动现在也可以在 RHFiles 任务中心取消。
- 修复前端事件桥未启用导致文件操作、更新下载和目录变更等后端实时事件无法送达界面的问题。
- 修复 portable 自动更新被 RHFiles 启动的外部程序长期阻塞的问题：子进程不再继承版本目录作为工作目录。
- 更新安装改为先让 Tauri 正常关闭窗口和 WebView2 子进程，再由 Velopack 替换当前版本，减少更新后反复提示安装的情况。
