# RHFiles 0.1.53

## 中文

- **设置里可配置预览音量**：设置 → 预览 新增「预览音量」滑块（0–100%）。音频/视频预览打开时按该音量播放；拖动播放器上的音量也会回写这个值，下次预览沿用。
- **批处理脚本图标不再像文件夹**：`.bat` / `.cmd` / `.ps1` / `.vbs` 现在固定使用 RHFiles 自带的「控制台窗口」图标（深色终端 + 提示符，PowerShell 为蓝色底），不再使用 Windows 返回的那个浅色「窗口+齿轮」系统图标——它在列表尺寸下和文件夹几乎无法区分，而 `.cmd` 之前甚至没有内置图标。
- **F5 不再改变视图布局**：之前刷新时总会重跑「每文件夹布局/自适应布局」判断，图片文件夹按下 F5 就会被翻回卡片视图。现在刷新同一文件夹不重新判定布局，且手动保存的文件夹布局优先于自适应检测。
- **图片缩略图会随文件变化刷新**：缩略图缓存改为按「路径 + 修改时间 + 大小」建索引，图片被替换后 F5 就能看到新缩略图，而不是一直显示旧图。
- **视频也有缩略图了**：用随包 FFmpeg 抽帧（缩略图布局对视频同样生效）。为了避开片头黑场，会在 1 秒、3 秒处各取一帧并用同一次调用测量亮度（`signalstats` 的 YAVG），取更亮的一帧；短片自动回退到起始帧。
- **ESC 取消重命名后会重新选中该文件**：之前取消分支引用了一个不存在的变量，抛错后选中就丢了。
- **快速访问与库支持拖放（含悬浮跳转）**：「快速访问」的各项此前只有 `data-nav` 名称、没有真实路径，「库」连路径属性都没设置，所以拖到它们上面没有任何反应。现在两者都带上真实路径；拖拽悬停约 0.7 秒会跳转到该文件夹（与目录树展开对应的"悬浮跳转"），松开即可移动/复制到其中。
- 新增 `scripts/verify-ui-fixes.mjs`：GUI 套件需要可见桌面，在无头会话里拿不到结果，这个脚本用无头 Edge 加载真实的 `icons.js` 校验脚本图标，并对本次各项修复做源码契约断言；`node scripts/verify-ui-fixes.mjs` 即可运行（26 项检查）。

## English

- **Configurable preview volume**: Settings → Preview gained a volume slider (0–100%). Audio/video previews open at that level, and moving the player's own volume writes the value back for later previews.
- **Batch scripts no longer look like folders**: `.bat` / `.cmd` / `.ps1` / `.vbs` now always use RHFiles' console-window icon (dark terminal with a prompt; PowerShell gets a blue window) instead of the pale window-with-gears shell icon that is nearly indistinguishable from a folder at list sizes — and `.cmd` had no builtin icon at all.
- **F5 no longer changes the view layout**: refreshing re-ran the per-folder/adaptive layout detection, so pressing F5 in an image folder flipped it back to cards. A same-folder reload now leaves the layout alone, and an explicitly saved folder layout takes precedence over adaptive detection.
- **Image thumbnails follow the file**: the thumbnail cache is keyed by path + modified time + size, so a replaced image shows its new thumbnail after F5 instead of the stale one.
- **Video thumbnails**: frames are extracted with the bundled FFmpeg (the thumbnail layout now covers videos too). To skip black lead-ins, frames are sampled at 1s and 3s and their average luma is measured in the same pass (`signalstats` YAVG), keeping the brighter one; short clips fall back to the opening frame.
- **ESC cancelling a rename re-selects the file**: the cancel path referenced a variable that did not exist, so the selection was lost after the error.
- **Quick access and Libraries accept drops (including hover spring-loading)**: Quick access rows only carried a `data-nav` name and Libraries had no path attribute at all, so dropping on them did nothing. Both now expose real paths; hovering about 0.7s navigates into the folder (the flat-row counterpart of the tree's expand-on-hover), and releasing moves or copies the files there.
- Added `scripts/verify-ui-fixes.mjs`: the GUI suite needs a visible desktop and yields nothing on a headless session, so this script loads the real `icons.js` into headless Edge for the script-icon checks and asserts the source contracts of the other fixes. Run it with `node scripts/verify-ui-fixes.mjs` (26 checks).
