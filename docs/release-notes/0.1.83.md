# RHFiles Windows 0.1.83

1. 新增 RHVideo 媒体库：连接现有服务器，在 RHFiles 内浏览、搜索视频、图片、小说和收藏，支持文件夹筛选与分页。
2. 视频使用原生播放器，支持播放列表、上一集/下一集、暂停、跳转、速度和全屏；时间轴关键帧可直接定位播放。需要安装 64 位 VLC 3.x。
3. 图片支持前后切换、缩放；小说支持章节阅读和服务端进度回写；收藏与 RHVideo 共用。
4. 登录密码不保存，令牌仅存原生内存；退出登录会撤销本次媒体连接。移除媒体库中多余的宣传文案。

## English

1. Added a built-in RHVideo client with search, folder filters, pagination, and shared favorites for videos, pictures, and novels.
2. Native video playback includes queues, seeking, speed, fullscreen, and timeline frames. Requires 64-bit VLC 3.x.
3. Added image viewing and chapter reading with server-side reading progress.
4. Passwords are not saved; tokens remain in native memory. Removed unnecessary promotional copy.
