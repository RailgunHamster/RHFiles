# RHFiles 0.1.44

## 中文

- 选中样式改为**淡淡的框**：去掉上一版的整片渐变和实心强调色竖条，改成用一圈浅色圆角边框把左半部分（可拖动的名字栏）框起来，内部只留极淡的一层底色。
- 连续选中的多行共用**一个**框，不会变成每行一个圆角小框堆叠；非连续选择则每段各一个框。
- 框的右边缘与那条连续边界线重合，跟着列表滚动和窗口尺寸实时更新。
- 已在真实窗口用截图逐像素确认：框只覆盖名字栏，日期 / 类型 / 大小列完全不受影响。

## English

- The selection style is now a **faint frame**: the full-width gradient and the solid accent bar from the previous build are gone, replaced by a light rounded outline around the left part (the draggable name column) with only a barely visible fill inside.
- Consecutive selected rows share **one** frame instead of stacking a rounded box per row; non-contiguous selections get one frame per run.
- The frame's right edge coincides with the continuous boundary line and follows list scrolling and window resizing.
- Confirmed pixel by pixel in a real window capture: the frame covers the name column only, leaving the date, type and size columns untouched.
