# RHFiles 0.1.24

## 中文

- 重新设计实验性 Windows 集成：标准打开 / 保存对话框或 Windows 资源管理器激活时，会在旁边自动显示 RHFiles 位置列表。列表覆盖所有已打开窗口、标签页和可见双窗格，标出活动/固定标签，长路径优先显示后半部分；单击后只让当前这个精确 Windows 窗口跳转。原快捷键保留为可选的“唤出列表”，不会再直接导航。
- 侧边列表按需创建，集成关闭时不会额外启动 WebView；定位尺寸会跟随目标显示器 DPI，关闭最后一个 RHFiles 窗口时也会一并退出。原生文件对话框与 Explorer 的跳转仍不占用剪贴板，并继续由真实 Windows 端到端测试覆盖。
- 新增右键“转换格式”：支持常见视频、音频和图片输入，提供输出格式、质量、视频编码与速度、分辨率、音频码率/采样率/声道、图片最大宽度等相关配置。转换进入可收起的文件任务面板，显示进度、输出大小和速度，可取消，并在失败时展示 FFmpeg 的具体错误。
- portable 包现在直接附带经过 SHA-256 校验的 FFmpeg 9.0.1 Essentials `ffmpeg.exe` 及许可证/源码说明；设置中仍可指定其他版本。转换始终先写同目录临时文件，失败或取消不会破坏已有目标，成功后才安全替换。
- 地址栏现在接受 `file:///D:/...` 与 `file://server/share/...` 地址，并会解码空格、中文等转义字符。地址指向文件时，RHFiles 会进入其所在文件夹并选中该文件，而不是把文件当作文件夹打开。

## English

- Redesigned the experimental Windows integration: activating a standard Open/Save dialog or Windows File Explorer now shows an RHFiles location companion beside it. The list includes every open window, tab, and visible dual pane, identifies active/pinned tabs, and reveals the ends of long paths. A click navigates only the exact active Windows target. The old shortcut remains as an optional show-list action and no longer navigates directly.
- The companion is created lazily, so a disabled integration does not start another WebView. Placement is DPI-aware and the picker exits with the final RHFiles window. Native dialog and Explorer navigation still leave the clipboard untouched and remain covered by real Windows end-to-end tests.
- Added **Convert format** to the file context menu for common video, audio, and image inputs. Relevant controls cover output format, quality, video codec/preset/resolution, audio bitrate/sample rate/channels, and maximum image width. Conversions run in the collapsible File operations panel with progress, output size, speed, cancellation, and actionable FFmpeg errors.
- Portable packages now include a SHA-256-verified FFmpeg 9.0.1 Essentials `ffmpeg.exe` plus its license and source notice; Settings can still select another build. Conversion writes to a same-folder temporary file first, so failure or cancellation cannot damage an existing target and replacement happens only after success.
- The address bar now accepts `file:///D:/...` and `file://server/share/...` URLs and decodes escaped spaces or Unicode characters. If an address points to a file, RHFiles opens its parent folder and selects that file instead of trying to enumerate it as a directory.
