# RHFiles Windows 0.1.103
1. 修复未选中任何文件时，顶部命令栏“新建”与“剪切”之间出现空白椭圆胶囊的问题（`.cmd-selection-pill` 的 `display: inline-flex` 覆盖了原生 `hidden` 属性，现已为 `[hidden]` 显式添加 `display: none !important`）。
2. 将 Verso 联动入口提升至一级界面：进入任何 `.git` 或 `.verso` 仓库目录时，顶部工具栏直接显示 `Verso · <当前分支>` 按钮，底部状态栏显示 `Verso 审阅` 按钮，文件与文件夹空白处右键菜单一级直接提供“在 Verso 中定位 / 审阅差异 / 查看历史”。
3. 修复异步获取 Git / Verso 状态完成后未实时回填当前列表行状态角标的问题，无需再次滚动或手动刷新即可看到修改标记。
## English
1. Fixed an empty oval pill appearing between New and Cut in the command bar when no items are selected (`.cmd-selection-pill` now explicitly honors `[hidden]`).
2. Promoted Verso integration to primary UI surfaces: when browsing inside a `.git` or `.verso` repository, the command bar displays a `Verso · <branch>` button, the status bar displays a `Verso Review` button, and the primary context menu includes direct `Open in Verso`, `Review Diff in Verso`, and `View History in Verso` actions.
3. Fixed asynchronous Git / Verso status loading so visible file rows update their status badges immediately upon completion without requiring a manual refresh.
