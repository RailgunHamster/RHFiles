# RHFiles 0.1.42

## 中文

- 按实际视觉重新实现拖动区边界：删除每行各自绘制的伪元素，改为每个 pane 只绘制一条连续的竖线，从表头顶部贯穿文件行，到状态栏前结束。
- 连续线的位置由真实表头列边界计算，并包含滚动条与右侧框选条的宽度补偿，不再错位或断成点/短线。
- 使用实际项目 CSS 和 DOM 结构生成视觉检查截图，并保留 228 项 GUI 回归测试。

## English

- Reimplemented the drag-zone boundary from the actual visual requirement: per-row pseudo-elements are gone; each pane now has one continuous vertical line from the header top through the file rows, ending before the status bar.
- The line is positioned from the real header column boundary and accounts for both scrollbar and right-side marquee-gutter widths, so it does not drift or break into dots/segments.
- Added a visual fixture check using the project's actual CSS and DOM structure, while retaining the 228-case GUI regression suite.
