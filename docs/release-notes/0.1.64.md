# RHFiles 0.1.64

## 中文

### 多选也能解压、也能看属性

右键菜单里"解压"和"属性"从来只按**单选**实现：解压两项的条件是 `singleFile && isArchive`，多选时整项被隐藏；属性是 `disabled: !singleSelection`，多选时只有一块灰。单包解压、单项属性一直正常，多选这条路当时没接。

现在：

- **解压**：选中一个压缩包（哪怕同时还选了别的文件）保持原样——解压到当前文件夹 / 解压到「包名」文件夹。选中**两个以上**压缩包时换成两项：**解压到当前文件夹**（合并）和**解压各压缩包到各自的文件夹**。逐个顺序执行，每个包保留自己的进度任务和密码提示，**一个失败不会中断其余的**，失败最后汇总成一条「N/M 个压缩包解压失败」而不是弹 N 个框。合并那条路要注意：后端解压带 `-y`，同名文件会被直接覆盖，在意就用"各自文件夹"。
- **属性**：任何非空选择都能打开。单选仍走 Windows 外壳属性表；多选给出资源管理器式的汇总——选中的项目数、位置（跨文件夹时显示"多个位置"）、类型（N 个文件，M 个文件夹）、大小（文件合计，含文件夹时异步补上文件夹大小）、修改时间（最新）。`Alt+Enter` 和命令面板走同一条路径。

GUI 测试套件新增两条用例覆盖多选菜单与汇总计算（234 项全过）。

## English

### Multi-selection can extract and show properties

The context menu's Extract and Properties entries were only ever wired for a **single** selection: the extract actions required `singleFile && isArchive`, so a multi-selection hid them outright, and Properties was `disabled: !singleSelection`, which left it greyed out. Single-archive extraction and single-item properties always worked; the multi-selection path simply did not exist.

Now:

- **Extract**: one selected archive (even alongside other files) keeps the original pair — extract into the current folder, or into the "«archive name»" folder. With **two or more** archives the entries become **extract into the current folder** (merged) and **extract each archive into its own folder**. They run one after another, every archive keeps its own progress task and password prompt, **one failure never aborts the rest**, and failures are reported once as "N of M archives failed" instead of a stack of dialogs. Note that the merged route extracts with `-y` (7-Zip assumes yes), so same-named files are overwritten — use the per-archive option when that matters.
- **Properties**: available for any non-empty selection. A single item still opens the Windows shell property sheet; a multi-selection is summarized in-app like Explorer does — item count, location ("Multiple locations" when the selection spans folders), breakdown (N files, M folders), combined size (file total, with folder sizes added asynchronously), and the newest modification time. `Alt+Enter` and the command palette take the same path.

The GUI suite gained two cases covering the multi-select menu and the summary computation (234 passed).
