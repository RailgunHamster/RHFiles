# RHFiles 0.1.116

发布日期 / Release date: 2026-11-09

## 中文

1. Windows 新增独立图片查看器，支持按当前文件列表顺序前后切换、缩放、旋转和全屏。
2. 图片可切换逐张翻页与横向连续滚动；连续模式松手保留当前位置，不强制吸附，界面仅保留当前及相邻图片。
3. Windows 新增独立内置视频播放器，复用 libVLC 内核，支持上一段／下一段、暂停、进度、音量、倍速和全屏，不需要连接 RHVideo 媒体库。
4. 在设置 → 预览中，图片和视频可以分别选择 RHFiles 或 Windows 默认应用；查看器中也保留使用系统应用打开的按钮。偏好立即保存并进入完整配置备份。
5. 本地、SMB 路径与 RHFiles 设备媒体均可使用内置查看器；RHFiles 设备按需流式读取。新增对应的设置、查看器、图片及视频控制自动化接口。

## English

1. Add a standalone Windows image viewer with directory-order navigation, zoom, rotation and fullscreen.
2. Switch between paged images and a continuous horizontal canvas that stays between images after release, rendering only the current image and its neighbors.
3. Add a standalone Windows video player using the existing libVLC engine, with previous/next, pause, seeking, volume, speed and fullscreen. No RHVideo library connection is required.
4. Choose RHFiles or the Windows default app separately for images and videos in Settings → Preview. The viewer retains an Open in system app button; preferences save immediately and are included in full backups.
5. View local files, SMB paths and streaming RHFiles-device media, with corresponding automation APIs for preferences, viewing and playback controls.
