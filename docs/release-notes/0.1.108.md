# RHFiles Windows 0.1.108
1. 支持在导航栏中直接通过 Windows 本机盘符路径格式访问远端 RHFiles 电脑设备的共享磁盘（例如输入 `rh://Winserver/C:\Users\40608\Documents\A\B\C` 或 `rh://Winserver/C:/Users/40608/Documents/A/B/C`，自动校验该设备是否共享了对应的 `C` 盘并跳转到 `rh://Winserver/C/Users/40608/Documents/A/B/C`）。
## English
1. Added support for navigating to a remote RHFiles PC's shared drive using Windows drive paths in the address bar (e.g., `rh://Winserver/C:\Users\40608\Documents\A\B\C` or `rh://Winserver/C:/Users/40608/Documents/A/B/C`), verifying that the target device shares the corresponding drive (`C`) before jumping to `rh://Winserver/C/Users/40608/Documents/A/B/C`.
