# RHFiles Windows 0.1.117

发布日期 / Release date: 2026-11-09

1. 修复独立图片查看器中的大图被裁切：图片原始尺寸不再撑大内部布局，适应窗口时完整显示图片。
2. 旋转 90°／270° 后重新计算适应尺寸；缩放后点击“适应窗口”保留旋转方向，并在调整窗口尺寸时重新适应。
3. 补充大横图、竖图、超宽长图，以及逐张／连续模式和旋转后的可视区域回归测试。

## English

1. Fix large images being clipped in the standalone viewer. Intrinsic image dimensions no longer expand the internal layout; Fit window shows the entire image.
2. Recompute fitted dimensions after 90°/270° rotation and window resizing. Fit window resets zoom/panning while preserving orientation.
3. Add visible-bounds regressions for large landscape, portrait and panoramic images, in paged/continuous modes and after rotation.
