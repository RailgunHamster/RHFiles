# RHFiles Windows 0.1.82

## 中文

1. RHFiles 设备连接统一使用设备组，移除独立配对、专用密码账号及对应脚本接口。升级后清除旧独立授权，旧凭据不能继续访问 JSON API、WebDAV 或上传接口。
2. 设备组新增“邀请新设备（扫码加入）”：先启动文件服务，再生成两分钟内有效的一次性邀请。手机明确确认后直接加入此组，后续访问统一服从设备组权限；删组或移除设备即时生效。
3. 保留组公开信息和离线请求/批准流程，区分组信息与对新设备的入组邀请。普通 SMB、FTP、WebDAV 网络位置不受影响。

## English

1. RHFiles device connections now use device groups exclusively. Independent pairing, app-password credentials and their automation actions are removed. Upgrades clear old grants; retired credentials cannot access JSON, WebDAV or uploads.
2. Add one-use group invitation QR codes, valid for two minutes after file service starts. A phone explicitly confirms and joins the group; access remains governed by live group membership and permissions.
3. Keep public group information and offline request/approval exchange. Ordinary SMB, FTP and WebDAV connections remain available.
