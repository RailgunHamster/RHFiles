# RHFiles Windows 0.1.133

- 修复通过可信 HTTPS WebDAV 打开远端文件时，VS Code 因启动目录包含 `@SSL@端口` 而报 `Invalid URL` 的问题。双击打开和「用 VS Code 打开」都会传入远端文件原路径。
- 修复 Windows WebClient 保存时未发送版本条件而导致写入被拒绝的问题。可信 HTTPS 兼容入口会校验保存请求开始时的文件版本，避免覆盖传输期间发生的修改。

- Fixed a VS Code startup error when opening files through trusted HTTPS WebDAV. Both default opening and Open with VS Code pass the original remote file path to the editor.
- Allowed Windows WebClient saves without version headers on the trusted HTTPS compatibility endpoint, with a server-side revision check to protect changes made during the upload.
