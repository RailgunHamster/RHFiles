# RHFiles Windows 0.1.120

发布日期 / Release date: 2026-11-09

## 中文

1. 自动更新会等待本机复制、移动等文件任务，以及 WebDAV、RHFiles 设备的上传、下载和后台文件变更结束，再持续空闲 30 秒后安装、重启。分块传输的短暂停顿不会触发更新，已完成的上传回执不会永久阻止更新。
2. 安装前由后端原子预留服务器请求入口，防止检查之后又有传输开始。更新交接失败会恢复请求接收；忙碌时显示等待，不误报更新失败。
3. 延后期间复用已检查版本和已校验的下载，只检查本机活动状态，不重复访问更新源；关闭自动更新会清除等待计时器。提供对应的更新就绪状态脚本接口。
4. 修复兼容视频渲染在暂停、旋转和调整窗口后偶发清黑未重绘的问题，并增加原生画面回归检查，覆盖之前的 GitHub CI 偶发失败场景。

## English

1. Defer automatic installation and restart until local file tasks, WebDAV/device transfers and detached mutations finish, followed by 30 idle seconds. Chunk gaps do not trigger updates; completed upload receipts do not block updates forever.
2. Atomically reserve server request admission before installation. A failed updater handoff restores admission; busy work is shown as waiting rather than an update failure.
3. Deferred updates reuse their checked version and verified package, checking only local activity. Disabling automatic updates clears the deferred timer. Expose readiness through the action API.
4. Repaint retained compatibility-renderer video after paused rotation and resizing, covering the real-pixel regression behind an intermittent GitHub CI failure.
