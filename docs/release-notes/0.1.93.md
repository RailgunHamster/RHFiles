# RHFiles Windows 0.1.93

1. 网络代理改为协议（HTTP / HTTPS）、IP / 主机名、端口三栏，勾选后默认使用 `http://127.0.0.1:7890`，不再把提示文字当作实际配置。
2. 保留已有代理配置，支持 IPv6；清空单栏恢复该栏默认值。非法地址或端口不会覆盖已保存的有效配置。
3. 补充代理开关、默认值、旧配置兼容、三栏保存和自动化接口的回归测试。
4. 更新日志显示发布时间，已知历史版本按正式发布记录补齐；没有记录的旧版本不编造日期。更新弹窗也会显示本版的发布日。
5. Windows 新增 WebDAV 配置同步，与 Android 使用相同的同步文件：同步网络位置、网络收藏、名称和顺序；密码、设备组、本地路径和设备专属设置留在本机。条件写入防止并发覆盖，冲突需要确认，失败不会循环重放。
6. 收藏夹新增“重命名收藏”，只改显示名称、不修改实际路径，并提供可脚本调用的收藏与配置同步接口。

## English

1. Proxy settings now have separate protocol (HTTP / HTTPS), IP / hostname, and port fields. Enabling the proxy uses `http://127.0.0.1:7890` without requiring any input.
2. Existing proxy addresses are preserved, including IPv6. Clearing a field restores its default. Invalid hosts or ports do not replace a saved valid configuration.
3. Added regression coverage for defaults, toggles, compatibility, field persistence, and the UI automation interface.
4. Release history now shows publication dates from known published records. Missing dates are not fabricated; update prompts also show the release day.
5. Added Windows WebDAV settings sync compatible with Android: network locations and network favorites, labels and order. Passwords, device groups, local paths and device-specific settings stay local. Conditional writes and explicit conflicts prevent silent overwrites and repeated failed writes.
6. Favorites can be renamed without changing their actual paths. Favorites and settings sync also expose scriptable actions.
