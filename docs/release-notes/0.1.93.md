# RHFiles Windows 0.1.93

1. 网络代理改为协议（HTTP / HTTPS）、IP / 主机名、端口三栏，勾选后默认使用 `http://127.0.0.1:7890`，不再把提示文字当作实际配置。
2. 保留已有代理配置，支持 IPv6；清空单栏恢复该栏默认值。非法地址或端口不会覆盖已保存的有效配置。
3. 补充代理开关、默认值、旧配置兼容、三栏保存和自动化接口的回归测试。

## English

1. Proxy settings now have separate protocol (HTTP / HTTPS), IP / hostname, and port fields. Enabling the proxy uses `http://127.0.0.1:7890` without requiring any input.
2. Existing proxy addresses are preserved, including IPv6. Clearing a field restores its default. Invalid hosts or ports do not replace a saved valid configuration.
3. Added regression coverage for defaults, toggles, compatibility, field persistence, and the UI automation interface.
