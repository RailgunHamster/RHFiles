# RHFiles Windows 0.1.130

- 在文件夹内键入时，优先选中完整名称匹配的文件或文件夹，之后依次匹配文件主名、名称前缀、名称中间和拼音。用 `Alt+[` / `Alt+]` 按匹配优先级切换，文件列表的排序保持原样。
- 内置视频播放器支持用 `+` / `-` 调整倍速，兼容主键盘和数字小键盘，倍速菜单会同步显示当前速度。

- Typing in a folder selects exact names first, followed by file stems, name prefixes, substrings, and Pinyin. `Alt+[` / `Alt+]` cycle through matches by priority while preserving the file list's sort order.
- Use `+` / `-` on the main keyboard or numeric keypad to adjust playback speed in the built-in video player. The speed menu reflects the active rate.
