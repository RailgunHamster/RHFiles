# RHFiles 0.1.28

## 中文

- 重做 Windows 文件窗口伴随栏与 Explorer 标签页联动。选择 RHFiles 位置时只会修改资源管理器当前激活的标签页，不再误改第一个标签；伴随栏新增“在 RHFiles 里打开”，已打开的同一路径会切换到对应窗口、窗格和标签页，否则在主窗口新建标签页。
- 伴随栏新增紧凑 / 展开模式、暂时隐藏和电源关闭按钮；紧凑模式只保留路径及必要操作，状态会被记住。功能开关与全部提示现已完整中英双语化，关闭后可从设置重新启用。
- 修复 Edge 等 Chromium 程序的 Windows 文件选择框逐字输入路径且偶发不跳转的问题。路径现在一次性写入，并在输入和确认前重新核对目标窗口，避免浏览器提示或通知抢走焦点；临时使用的 Windows 剪贴板会在操作后还原，也不会覆盖操作期间出现的更新剪贴板内容。
- 为文件、文件夹空白处、标签页、搜索框、地址栏、侧边栏、磁盘占用结果及各级子菜单加入统一的 16px 语义图标。复制、粘贴、终端、压缩、解压、收藏、属性等操作更容易扫视，删除和永久删除使用不同的红色图标，权限操作使用独立安全色；同时移除了菜单获得键盘焦点时的浏览器原生蓝色外框。
- 新增并强化真实 Windows 回归测试，覆盖 Explorer 双标签连续跳转、读取当前标签路径、Notepad 原生打开框和 Edge 原生文件选择框；GUI 回归也会检查右键菜单图标槽和关键图标是否完整渲染。

## English

- Reworked the Windows file-window companion and its Explorer tab integration. Choosing an RHFiles location now changes only File Explorer's active tab instead of the first tab. A new **Open in RHFiles** action activates the matching RHFiles window, pane, and tab when one already exists, or creates a tab in the main window otherwise.
- Added compact / expanded companion modes, hide-for-now, and power-off controls. Compact mode keeps only paths and essential actions, and its state is remembered. The feature toggle and all companion text are now fully localized in Chinese and English; a disabled companion can be re-enabled in Settings.
- Fixed path navigation in native Windows file pickers opened by Edge and other Chromium apps. Paths are now inserted in one operation rather than visibly typed character by character, and the target window is revalidated before both insertion and confirmation so browser prompts or notifications cannot steal the input. RHFiles restores the temporary Windows clipboard afterward and never overwrites newer clipboard content created during the operation.
- Added a consistent set of 16px semantic icons to file, folder-background, tab, search, address, sidebar, disk-usage, and nested context menus. Copy, paste, terminals, archives, favorites, properties, and other actions are easier to scan; Delete and Permanently Delete use distinct red icons, while permission actions have a separate security tone. The browser's native blue focus outline around keyboard-opened menus was also removed.
- Added and strengthened real Windows regressions for repeated two-tab Explorer navigation, reading the active tab path, the native Notepad Open dialog, and Edge's native file picker. GUI coverage now also verifies aligned icon slots and key semantic icons in context menus.
