# RHFiles Windows 0.1.80

## 中文

1. 文件服务在本机网卡/IP 变化后自动更新受限私网监听、mDNS 广播和签名地址；保留已有身份、设备授权与上传任务，不需要停止再启动服务。只枚举本机接口，不进行持续网络探测，不监听公网接口。
2. 设备组增加按需连接、手动私网恢复地址和连接诊断。依次尝试最近成功/已知签名地址、Tailscale 地址、现存在线组会话的签名信息和短时 mDNS 发现；通过固定 TLS 证书及组公钥验证后才接受新地址。
3. 每轮发现/连接总预算 15 秒、最多 6 次连接尝试，地址去重、失败冷却、支持取消。网络变化最多短暂等待一次，不重置预算；不扫描整个子网，不递归寻找组成员，也不在后台持续寻找手机。
4. 诊断保留最近 20 轮，展示每步耗时、失败/跳过原因及最终成功路径；读取、展开、刷新或复制诊断都不会触发探测。超时显示当前不可达，不武断认定对端关机；授权拒绝不会触发换路。
5. 增加真实 HTTPS 换址、错误证书、权限拒绝、取消、凭据脱敏和热重绑定上传所有权回归测试。配套 Android 0.1.28。

边界：本次恢复适用于 RHFiles 设备组协议，不会修改 Windows SMB/DNS 服务，也不会自动重放移动、删除或结果不明的写入。额外自定义 UDP 广播未启用；所有路径失效且 mDNS 被限制时，仍需手动私网地址或交换新的组公开信息。

## English

1. Refresh private interface listeners, mDNS advertisements and signed endpoints after local address changes without resetting identity, grants or upload ownership. This enumerates local interfaces only, not continuous network probes; public interfaces stay unbound.
2. Add on-demand group connections, manual private recovery hints and diagnostics. Try recent/signed/Tailscale addresses, existing authenticated peer sessions and short mDNS discovery; accept address changes only after pinned TLS and group-key verification.
3. Bound each resolution to 15 seconds and six connection attempts, with deduplication, cooldown and cancellation. One brief network-stabilization wait never renews budgets. No subnet sweep, recursive peer search or continuous phone discovery.
4. Retain 20 diagnostic runs with timing, outcomes and skipped-step reasons. Reading/copying diagnostics never probes. Timeouts mean unreachable, not confirmed power-off; authorization failures stop route retries.
5. Add real HTTPS recovery, wrong-certificate, permission, cancellation, redaction and hot-rebinding/upload-ownership regressions. Companion Android: 0.1.28.

Scope: RHFiles device-group protocol, not Windows SMB/DNS repair. No automatic replay of ambiguous writes or destructive operations. Additional custom UDP broadcast is disabled; if known routes and mDNS fail, enter a private endpoint or exchange fresh public group data.
