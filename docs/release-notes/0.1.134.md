# RHFiles Windows 0.1.134

- 修复通过 RHFiles 远端设备打开并修改文本文件（如 `.txt`）的问题：WebDAV 锁校验新增支持 RFC 4918 带资源标签的 `If` 请求头及大小写/NFC 归一化锁版本追踪；未使用 WebDAV 兼容入口时，双击或用外部编辑器打开的远端工作副本支持自动监听保存并按版本校验安全回传至远端设备。
- 修复在 Windows 共享目录删除带有只读属性（`FILE_ATTRIBUTE_READONLY`）的文件夹或只读文件时返回 HTTP 403 的问题。
- 修复 RHFiles 远端设备上的压缩文件右键菜单报错无法弹出的问题。
- 优化加密压缩包解压体验：多选解压时密码框支持勾选「全部使用同一个密码」一次解锁；密码输入框改为非模态悬浮窗口，触发多个解压时并行弹出多个输入框并直接并行解压，不再排队阻塞。

- Fixed opening and editing remote `.txt` and other files on RHFiles devices: WebDAV lock validation now accepts RFC 4918 tagged-list `If` headers with case/NFC-normalized lock tracking, and non-WebDAV working copies opened for editing automatically sync local saves back to the remote device with revision checks.
- Fixed HTTP 403 errors when deleting Windows folders or files carrying `FILE_ATTRIBUTE_READONLY` over RHFiles or WebDAV.
- Fixed right-clicking archive files on RHFiles remote devices failing before opening the context menu.
- Improved multi-archive extraction: added a "Use the same password for all" option in batch password prompts, switched password prompts to non-modal floating dialogs, and enabled parallel extraction without queueing.
