# RHFiles Windows 0.1.127

- 后台预读常用的内置 VLC 插件文件，缩短新安装或解压后首次播放的等待。
- MP4 等常见格式优先尝试对应的解封装和解码模块，保留格式识别和解码回退。
- 分开记录视频解码器和视频输出的初始化耗时，首帧等待超时时显示当时的阶段。
- 播放窗口创建后再获取焦点，避免 WebView2 焦点错误中断窗口创建。新窗口句柄暂不可用时会重新创建视频画布。

- Read common bundled VLC plugin files in the background to speed up the first playback after installation or extraction.
- Prefer the corresponding demuxer and decoder for MP4-family files, with VLC's format detection and decoder fallback.
- Report video decoder and video output initialization separately, with the current stage shown if the first frame takes too long.
- Focus the viewer after WebView2 creates it and retry canvas creation if the new window handle is temporarily unavailable.
