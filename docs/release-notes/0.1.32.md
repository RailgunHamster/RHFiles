# RHFiles 0.1.32

## 中文

- 修复在 Windows 上拖动文件或文件夹时，所有位置都显示禁止放置光标的问题。RHFiles 主窗口、额外窗口及恢复创建的窗口现在统一关闭会抢占 WebView2 拖放目标的 Tauri 原生处理器，改由 RHFiles 的前端拖放逻辑接管。
- 修复把文件悬停到尚未加载的标签页后，虽然标签页成功切换，但拖拽源被“正在加载”或错误界面删除，导致松开鼠标没有反应的问题。加载期间会保留原始拖拽节点，直到放置或取消完成。
- 加强跨标签页拖放回归测试，覆盖未加载标签页、悬停切换、拖拽源存活、目标路径选择以及复制/移动确认。

## English

- Fixed every destination showing the forbidden cursor when dragging files or folders on Windows. RHFiles now disables Tauri's native handler—which otherwise owns the WebView2 drop target—for the main, additional, restored, and tray-recreated windows so the RHFiles HTML drag-and-drop flow can handle the gesture.
- Fixed a drag being cancelled after hovering over an unloaded tab. Loading and error states now keep the original drag-source subtree connected until the drop or cancellation completes.
- Expanded cross-tab drag-and-drop regressions to cover unloaded tabs, hover activation, source-node lifetime, destination routing, and the copy/move confirmation.
