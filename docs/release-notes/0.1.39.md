# RHFiles 0.1.39

## 中文

- 详情布局新增名字栏分隔线：在名字栏右边缘绘制一条极淡的竖线（与表头对齐、每行位置完全相同），把"可拖动区"和"框选区"一眼分开。分隔线在平常状态就可见，悬停时加深，选中行变为强调色并给整个名字栏加一层淡底色。
- 拖动区长度因此完全统一：所有行的名字栏宽度一致（列宽固定，名字栏按剩余空间等分），不再需要凭感觉判断能拖到哪里；图标左侧的抓手提示继续保留，作为"从这里拖"的额外指引。

## English

- The details layout now draws a faint vertical divider at the right edge of the name column (aligned with the header and identical on every row), separating the draggable zone from the rubber-band columns at a glance. It is visible in the normal state, darkens on hover, and turns into the accent colour with a soft tint over the whole name column on selected rows.
- The drag zone is therefore uniform: every row's name column is the same width (fixed columns, the name column takes the remaining space evenly), so there is nothing left to guess, while the grip hint beside the icon stays as a "drag from here" cue.
