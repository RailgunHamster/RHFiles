# RHFiles Windows 0.1.76

## 中文

1. 新增可选的局域网 HTTPS 文件服务，不依赖 Windows SMB。设置中明确添加本机共享目录并手动启动；默认只读，写入和永久删除分别授权。
2. 专用 JSON 接口与兼容 WebDAV 接口共用文件和权限核心；支持目录分页、图片缩略图、视频分段读取与 tus 分块续传。所有入口均不覆盖已有目标。
3. 手机可扫描电脑二维码配对，也可通过 mDNS 发现电脑、核对身份并输入短期配对码。配对码两分钟内有效、单次使用；设备独立授权，可随时撤销。
4. 新增共享根目录保护、路径隔离、WebDAV 锁、崩溃后上传偏移恢复及 Windows/Android 实际传输回归测试。服务管理操作均有命令行自动化接口。

需要 Android 0.1.25 或更新版本。第三方 WebDAV 客户端需信任导出的 HTTPS 公共证书；不会修改防火墙、自动开机共享或暴露整个磁盘。使用方法见 docs/LAN-SERVICE.md。

## English

1. Add an opt-in LAN HTTPS file service independent of SMB. Explicit local share roots, manual start, read-only default and separate write/delete grants.
2. Native JSON and compatible WebDAV interfaces share one confined file/authorization core, with paginated browsing, image thumbnails, video ranges and resumable tus uploads. Existing destinations are never overwritten.
3. Pair Android by offline QR scanning or mDNS discovery with explicit identity verification and a short-lived single-use code. Device credentials are individually revocable.
4. Add shared-root protections, path confinement, common WebDAV locks, durable upload offsets and real Windows/Android transfer regressions. Local service management also has command-line automation APIs.

Requires Android 0.1.25+. Third-party WebDAV clients must trust the exported public certificate. No automatic firewall changes, boot daemon or whole-disk sharing.
