# RHFiles Windows 0.1.73

## 中文

1. Windows 新增 Gitee 更新源及仓库地址设置，默认使用 Gitee。旧版自带的默认 GitHub 地址会迁移一次，自定义仓库和家庭服务器配置保持不变；手动切回 GitHub 后会记住选择。
2. Gitee 更新检查、下载和累计更新日志共用现有代理、超时和校验机制。安装包按不可变的 Windows 版本标签下载，不会误取 Android 的 APK；发布流程同时保留另一平台的更新清单。
3. 修复部分 Windows 环境无法识别虚拟桌面时直接拒绝启动。单桌面注册信息可作为明确的识别来源；仍无法识别时使用当前账号、登录会话的独立备用配置，不占用或修改原有桌面的数据。
4. 备用配置会在界面说明，不启用可能跳转错误桌面的 Explorer / 原生选文件窗口联动。正常虚拟桌面隔离、已有更新开关和文件任务安全机制保持不变。

## English

1. Adds Gitee update settings to Windows and makes Gitee the default. The old bundled GitHub default migrates once; custom repositories and home-server choices are preserved. Explicit later GitHub choices remain saved.
2. Gitee checking, downloads and cumulative notes use existing proxy, timeout and verification support. Windows packages resolve to immutable Windows version tags, never Android APKs. Publishing preserves both platforms' indexes.
3. Fixes startup failure when Windows cannot identify a virtual desktop. An unambiguous single-desktop registration is accepted; otherwise an isolated account/session fallback profile starts without claiming or changing existing desktop data.
4. The UI identifies fallback profiles and disables potentially ambiguous Explorer / file-dialog integration there. Normal desktop isolation, update-check preferences and safe file operations remain unchanged.
