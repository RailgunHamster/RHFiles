# RHFiles Windows 0.1.75

## 中文

1. 回收站改为普通标签页中的虚拟位置 `recycle://`，不再使用独立弹窗。可在地址栏输入，也可通过侧栏进入；Ctrl/鼠标中键点击侧栏可新建标签页。
2. 支持标签页复制、前进/后退、左右窗格；每个回收站标签页分别记住自己的筛选、排序和选择。
3. 回收站沿用普通列表的单选、多选、Shift 范围选择和键盘导航；搜索、恢复、保留两者、永久删除和清空操作继续保留。永久删除仍需两次确认。
4. 防止回收站虚拟路径进入普通文件操作、终端、预览或拖拽流程；离开回收站后，迟到的读取结果不能覆盖新文件夹。
5. 为大回收站限制同时渲染的行数，新增双窗格、标签页隔离、异步竞态和真实 Windows 回收站回归测试。

## English

1. Recycle Bin is now a regular tabbed virtual location, `recycle://`, instead of a separate modal. Open it from the address bar or sidebar; Ctrl/middle-click the sidebar entry to open a new tab.
2. Supports duplicated tabs, back/forward navigation and dual panes, with independent filters, sorting and selections in each tab.
3. Uses ordinary list selection, Shift ranges and keyboard navigation. Restore, keep both, permanent deletion and empty-bin actions remain available; permanent deletion still requires two confirmations.
4. Virtual paths cannot enter ordinary filesystem, terminal, preview or drop operations. Late reads cannot replace a newly navigated folder.
5. Bounds rendered rows for large bins and adds dual-pane, tab-isolation, async-race and native Windows regression coverage.
