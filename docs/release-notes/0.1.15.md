# RHFiles 0.1.15

- 接入 Windows 原生文件剪贴板：现在可以把远程桌面、Windows Explorer 以及其他 Shell 程序复制的文件直接粘贴到 RHFiles。
- 支持远程桌面的 `FileGroupDescriptorW/FileContents` 虚拟文件流；粘贴由 Windows OLE 与 `IFileOperation` 执行，并保留冲突、权限提升和取消处理。
- RHFiles 内的复制与剪切也会写入系统文件剪贴板，可直接粘贴到 Windows Explorer；剪贴板被其他程序更新后，不会误用 RHFiles 中过期的文件列表。
- 标签页右键菜单新增“复制标签页”，在原标签旁创建并切换到路径、历史、排序、选择和滚动位置一致的新标签。
- 标签页支持拖动排序，落点前后有清晰提示；左、右窗格分别排序并立即持久化。
