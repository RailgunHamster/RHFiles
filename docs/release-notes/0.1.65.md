# RHFiles 0.1.65

## 中文

- ZIP 保留选中文件夹的完整层级。一起选中父文件夹和其中的子文件/子目录时，子项仅通过父文件夹加入，不再重复出现在压缩包根目录。
- 压缩包浏览改为分层显示：根目录只显示直接子项，支持进入子目录和返回上一层；多级目录中的同名文件分别保留各自的路径。
- 同名文件夹复制、粘贴和拖拽默认递归合并，保留目标文件夹独有的内容。同名文件或文件/文件夹类型冲突时，仍可选择替换、跳过、同时保留或取消。
- Windows Explorer 的普通文件剪贴板使用同一套合并、冲突提示、进度和撤销流程。
- 合并中的取消与失败保留已完成的文件；撤销只处理本次新增且未覆盖的项目，不删除原有目标目录。剪切合并遇到跳过项时，源文件及剪切状态保留，成功移完才清理空源目录。
- 新增多层 ZIP、重叠选择、隐藏文件、目录合并、文件冲突、取消、失败、剪切和撤销/重做的回归测试，以及真实界面的合并和压缩包导航测试。

## English

- ZIP archives preserve selected folder hierarchies. Selecting a folder together with its descendants includes those descendants only under their parent, without extra copies at the archive root.
- Archive browsing shows direct children at each level and supports entering folders and going up. Identically named files retain their distinct member paths.
- Copy, paste and drag operations recursively merge same-named folders, preserving destination-only content. File and file/folder conflicts still offer Replace, Skip, Keep Both and Cancel.
- Physical file paths copied from Windows Explorer use the same merge, conflict, progress and undo workflow.
- Cancellation and failures retain completed transfers. Merge undo affects only newly added, non-overwritten entries and preserves existing destination directories. Skipped move conflicts stay in the source and cut clipboard; empty source directories are removed after completed moves.
- Added filesystem, frontend and real application regression coverage for ZIP hierarchies, overlapping selections, hidden files, folder merges, conflicts, cancellation, failures, cut operations and undo/redo.
