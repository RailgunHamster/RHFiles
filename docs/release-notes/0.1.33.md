# RHFiles 0.1.33

## 中文

- 地址栏改为文件管理器式的路径推荐：关闭网页式自动填充，输入时下拉显示最近访问路径与当前输入目录的子文件夹补全，支持方向键、Tab 补全和回车跳转。
- Windows 文件窗口伴随栏支持分类开关：资源管理器与文件对话框可在设置中分别启用，伴随栏电源按钮只关闭当前这类目标。
- 浏览器 / 软件弹出的打开文件（非选文件夹）对话框旁，伴随栏会预览左侧选中的文件（缩略图与大小），并支持"在 RHFiles 里打开"：已有位置直接切换并选中该文件，否则新建标签。
- 关闭系统分享面板（Windows 分享取消）不再弹出错误提示。
- 新增 Ctrl+Shift+T 恢复最近关闭的标签页（标签右键菜单也可用），按关闭顺序依次恢复。
- 修复缩略图布局下方出现的细线：卡片改为按内容自适应高度，空的大小信息不再渲染。
- 修复在同一目录内 Ctrl+C / Ctrl+V 报"源和目标相同"的问题：复制到原位置自动保留两者（自动命名"名称 (1)"），剪切到原位置静默跳过。
- 重命名遇到同名冲突时弹出确认：可覆盖、跳过或自动保留两者（自动编号），不再直接报错。
- 设置新增"删除到回收站前先确认"开关：关闭后按 Delete 直接删除；彻底删除（Shift+Delete）始终需要两次确认，不受该开关影响。
- 修复偶现的点击 D 盘无法显示的问题：裸盘符（如 D:）会被 Windows 按驱动器相对路径解析到别处，现在统一规范为 D:\。
- 修复后台文件监视与导航的竞态：监视轮询不再用旧路径覆盖正在进行的跳转，导航期间也会显示加载状态而不是停留在旧目录。

## English

- The address bar now behaves like a file manager: web-style autocomplete is off, and typing shows recent paths plus child-folder completions of the typed directory, with arrow keys, Tab completion, and Enter to navigate.
- The Windows file-window companion can be toggled per target: File Explorer and Windows file dialogs are enabled separately in Settings, and the companion's power button turns off only the current target kind.
- Beside browser/app file-open dialogs (not folder pickers), the companion previews the file selected in the dialog (thumbnail and size) and can open it in RHFiles — activating an existing tab and selecting the file, or creating a new tab.
- Dismissing the Windows share panel (share cancel) no longer raises an error.
- Added Ctrl+Shift+T to reopen the last closed tab (also in the tab context menu), restoring closed tabs in order.
- Fixed stray lines under thumbnails: cards now size to their content and empty size metadata is not rendered.
- Fixed Ctrl+C / Ctrl+V in the same folder reporting "source and destination are the same": copying onto itself now keeps both (auto "name (1)"), and cutting onto itself is skipped silently.
- Renaming onto an existing name now asks: replace, skip, or keep both with automatic numbering, instead of failing outright.
- New setting "Confirm before deleting to the Recycle Bin": turn it off to delete immediately with Delete; permanent deletion (Shift+Delete) always requires its two confirmations.
- Fixed D: intermittently failing to open from the address bar: a bare drive letter (D:) is drive-relative on Windows and could resolve elsewhere; it is now normalized to D:\.
- Fixed a race between the background folder watcher and navigation: the watcher no longer restarts navigation to the old path while a user navigation is in flight, and in-flight navigations show a loading state instead of silently staying on the old folder.
