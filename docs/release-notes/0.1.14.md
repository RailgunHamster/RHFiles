# RHFiles 0.1.14

- 新增可收起、展开的文件任务中心：复制、移动、删除和解压任务可以并行显示，不再互相覆盖。
- 文件任务现在显示当前项目、项目与文件数量、已处理大小、百分比、实时速度和预计剩余时间，并保留失败项目供检查。
- 强化异常与崩溃保护：复制和跨卷移动先写入临时目标再提交；启动时会清理残片、恢复旧目标，并对中断的移动或删除给出明确提示。
- 将文件拖到未激活标签上并短暂停留即可自动切换，支持在左右窗格的目标标签内继续放置。
- 修复多选文件后 Delete 偶尔无响应：文件区会主动接管键盘上下文，同时兼容 Ctrl 尚未松开的情况。
- 修复“用 VS Code 打开”失败：支持发现用户级、系统级、Insiders、注册表及命令行安装位置，并直接启动实际的 Code.exe。
