# RHFiles Windows 0.1.92

## 中文

1. 新增 CNB 更新源并设为默认，GitHub 继续同步发布并保留为可选来源。公开检查和下载不需要发布令牌，更新包固定到对应版本标签，不使用会变化的最新安装包地址。
2. 移除家庭服务器更新选项及旧更新地址；旧 Gitee／家庭更新配置自动迁移到 CNB。保留已明确选择的 GitHub、代理和关闭自动检查的设置，不影响普通 SMB／WebDAV 网络位置、收藏和设备组。
3. Windows 地址栏支持 `rh://设备名/共享名/路径`；同名设备可用 `rh://组名@设备名/…` 区分。RHFiles 设备列表移到收藏夹上方；设备地址仍以组和设备身份保存，不把显示名称当作授权或依赖 SMB。
4. 修复“代码已更新但客户端检查不到”的发布缺口：本版以新版本号提供完整便携包、安装程序、更新包和累计日志，并维护 Windows／Android 各自的更新清单。

本版不宣称 RHVideo 已完成全部功能或性能对齐；相关待办与已知限制继续保留。

## English

1. Add CNB as the default update source while keeping GitHub maintained and selectable. Checks and downloads are anonymous. Packages use immutable version-tagged URLs, not a moving latest-package address.
2. Retire home-server update options and saved update addresses. Migrate legacy Gitee/home-server choices to CNB without enabling disabled automatic checks or changing explicit GitHub/proxy preferences. Ordinary SMB/WebDAV locations, favorites and device groups are unaffected.
3. Accept `rh://device/share/path` in the Windows address bar, or `rh://group@device/…` for duplicate names. Move RHFiles devices above Favorites. Saved locations remain bound to group/device identities rather than display names or SMB.
4. Close the publication gap that left existing clients reporting no newer version: ship a new version with complete portable, installer and update packages plus cumulative release notes, preserving separate desktop/Android update indexes.

Full RHVideo functional/performance parity is still pending; existing limitations and TODOs remain documented.
