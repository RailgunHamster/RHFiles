# RHFiles Windows 0.1.125

- 内置视频播放器提前初始化 VLC，切换视频时复用播放器和画布。首帧就绪后立即更新画面。

- The built-in video viewer initializes VLC while the window opens and reuses the player and video surface across files. The picture appears as soon as the first frame is ready.
- Playback diagnostics show timings for window creation, VLC initialization, source setup, the first byte from an RHFiles device, and the first frame.
