# RHFiles Windows 0.1.128

- 内置图片查看器直接以最大化窗口打开，避免打开时短暂闪出小窗口。
- 修复图片打开后需要先点击才能按 Esc 关闭的问题。
- JSON 预览可在源码和可展开的树状视图之间切换。

- The built-in image viewer opens maximized without briefly flashing a smaller window.
- Press Esc to close the image viewer immediately after opening it.
- JSON preview can switch between source and an expandable tree.
