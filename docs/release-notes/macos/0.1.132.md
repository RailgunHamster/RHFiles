# RHFiles macOS 0.1.132

- 下载、验签、安装及重启共用一个原生更新窗口。关闭主窗口后仍可看到更新进度，直到新版界面就绪。
- 更新窗口跟随当前主题和界面语言，显示实际下载进度、速度和失败原因。

- A single native window shows download, verification, installation and restart. It remains visible when the main window is closed and dismisses when the new interface is ready.
- The update window follows the application's theme and language, and displays measured download progress, speed and errors.
