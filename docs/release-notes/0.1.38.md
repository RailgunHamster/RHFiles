# RHFiles 0.1.38

## 中文

- 重做选中项的拖动提示：不再用色块和抓手盖住文件图标（之前那样看起来像图标坏了）。现在图标本体保持原样，只在图标后面加一层淡色底、并在图标左侧显示一个细长的抓手竖条，悬停时加深，明确指向"这里可以拖动"。
- 拖动区域的口径与提示统一：整个名字栏（图标 + 文件名）都是拖动区，日期 / 类型 / 大小列、行尾空白、卡片间隙和列表右侧窄条仍然是框选区，提示所指的位置与实际能拖的位置完全一致。

## English

- Reworked the selected-row drag hint: the file icon is no longer covered by a plate and grip glyph (which made it look broken). The icon keeps its artwork; it only gains a soft tinted plate behind it and a slim grip bar on its left, darker on hover, pointing at where dragging starts.
- The drag surface and the hint now agree: the whole name cell (icon plus file name) drags, while the date/type/size cells, the blank space at the end of a row, the grid gaps, and the right-edge strip all start a rubber-band selection.
