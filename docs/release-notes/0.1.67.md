# RHFiles 0.1.67

## 中文

- Windows 网络目录读取改为独立无界面辅助进程：目录列表、文件信息、目录树、服务器共享枚举和网络发现默认在 6 秒后超时，避免系统 SMB / DNS 阻塞长期占用 RHFiles 的工作线程。
- 超时后终止辅助进程，同一服务器暂停重试 30 秒，并限制并发网络请求。主程序退出时通过 Windows Job Object 清理辅助进程；不会自动重启系统服务、修改 DNS 或切换服务器地址。
- 家庭服务器更新源的版本清单、更新日志和安装包下载使用相同的隔离机制。下载提供进度，连续 30 秒没有数据即中止；只有下载完成才提交临时文件，失败不会将半成品当成完整更新包。
- 网络超时、短暂退避和请求繁忙提供中英双语提示。检查路径是否存在时，仅“确实不存在”返回否，权限及网络错误不再被误判为不存在。
- 增加辅助进程挂起、父进程异常退出、并发限制、服务器退避、超大响应、中文路径、更新包进度和覆盖保护等回归测试。

本次改动隔离并限制上述网络读取的阻塞，不会自动修复 Windows DNS Client 内部故障；也没有修改普通文件复制、移动和删除任务的超时策略。

## English

- Windows network directory reads now run in isolated, headless helpers. Listings, metadata, directory trees, share enumeration and network discovery time out after 6 seconds instead of leaving RHFiles worker threads indefinitely blocked in SMB / DNS calls.
- Timed-out helpers are terminated, retries to the same host pause for 30 seconds, and concurrent network requests are bounded. Windows Job Objects clean up helpers when the parent exits. RHFiles does not restart system services, change DNS or substitute another server address.
- Home-server update feeds, release history and package downloads use the same isolation. Downloads report progress and stop after 30 seconds without data. Staging files are committed only on success, so incomplete downloads are not treated as complete update packages.
- Added localized timeout, cooldown and busy messages. Path-existence checks now distinguish missing paths from permission and network failures.
- Added regression coverage for hung helpers, unexpected parent exit, concurrency limits, host cooldown, large responses, Unicode paths, package progress and overwrite protection.

This release bounds and isolates the network reads listed above; it does not repair internal Windows DNS Client faults or change timeouts for ordinary file copy, move and delete tasks.
