# RHFiles Windows 0.1.135

1. 在 Git 或 SVN 工作目录中，右键文件、文件夹或空白处即可打开已安装的 TortoiseGit 或 TortoiseSVN。可以直接提交、查看差异和日志，也可以拉取或推送 Git 分支、更新 SVN 工作副本。
2. 多选文件后点「提交」，原生提交窗口会收到所选路径。脚本可用 `vcs.tortoise.actions` 查询当前选择可用的操作，用 `vcs.tortoise.open` 打开对应窗口。
3. HTML 文件预览支持在渲染结果与源码之间切换。渲染使用隔离的预览环境。

1. Right-click a file, a folder, or the background in a Git or SVN working copy to open the installed TortoiseGit or TortoiseSVN client. Commit changes, view diffs and logs, pull or push Git branches, or update an SVN working copy.
2. Selecting several files and choosing Commit passes those paths to the native dialog. Scripts can query available actions with `vcs.tortoise.actions` and launch a dialog with `vcs.tortoise.open`.
3. HTML file previews can switch between a sandboxed rendered view and source code.
