# RHFiles Windows 0.1.126

- 加快内置播放器显示首帧，播放诊断分别记录首次读取、缓冲、解码和画面输出。
- 播放诊断分别显示 VLC DLL 加载、实例创建和播放器创建的耗时。
- 内置播放器在浏览含视频的文件夹时后台加载 VLC DLL，关闭并重新打开播放器时复用已加载的运行库。

- The built-in player displays the first frame sooner. Playback diagnostics show separate timings for the first read, buffering, decoding, and video output.
- Playback diagnostics measure VLC DLL loading, VLC instance creation, and player creation separately.
- RHFiles loads the VLC DLL in the background when browsing a folder containing videos and keeps it loaded when the player is closed and reopened.
