# RHFiles 0.1.8

- 桌面、下载、文档、图片、音乐和视频入口改用 Windows Known Folder 路径，正确跟随 OneDrive、域策略及用户自定义的文件夹重定向。
- 目录枚举遇到单个消失或无权读取的子项时会继续显示其余内容；无法打开根目录时显示分类明确、可重试的中文错误页。
- Everything 增加 IPC 与索引就绪检测并限制等待时间；当前文件夹搜索在 Everything 尚未可用时自动使用内置递归搜索，支持名称中段、通配符、正则及中文拼音/首字母匹配。
- 全局搜索失败时显示可操作的诊断信息，并可直接打开 Everything 完成服务或权限配置。
- 移除缩略图图片框的灰色底板，透明或窄幅图片不再出现额外灰边。
- 换用以 16–32 px 清晰度为优先的新应用图标，减少高饱和蓝色和小尺寸细节堆叠。
