# RHFiles Windows 0.1.86

## 中文

1. 设备组位置进入普通文件标签页：按需连接电脑或已开启文件服务的 Android 手机，支持目录、搜索、文本／图片预览和分段媒体读取，不依赖 SMB 或映射网络盘。当前电脑端设备路径为浏览／预览能力，写入和传输入口尚未开放。
2. 依据 RHVideo 实际源码逐项核对业务入口，补充任意跳页、章节摘录拼音搜索、阅读器目录／收藏、任务图片放大、截图逐张查看与定位、统一音量及停止批量操作的剩余提交。
3. 新增控件均使用可枚举、带参数定义的同一套 UI／脚本 API；补充原生播放、真实服务端和独立账号的回归测试。
4. 撤销组访问后拒绝旧内容通道；授权拒绝不再误显示为网关故障。媒体通道会避开浏览器禁用的本机端口，不修改系统网络配置。

## English

1. Browse accepted group computers and Android phones in ordinary tabs using authenticated HTTPS, without SMB or mapped drives. Includes bounded search, text/image previews and ranged media. Desktop device locations currently expose browsing/preview, not write or transfer actions.
2. Audit the actual RHVideo UI sources and add arbitrary page jumps, pinyin excerpt search, reader TOC/favorites, enlarged task images, screenshot inspection/reveal, master volume and stopping remaining batch submissions.
3. UI and scripts use the same enumerable, schema-defined actions, with real native-player, server and account-isolation regression coverage.
4. Revoked access invalidates content; authorization failures are no longer reported as gateway faults. Local media brokers avoid browser-restricted ports without changing host network settings.
