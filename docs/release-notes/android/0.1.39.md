# RHFiles Android 0.1.39

## 中文

1. 图片预览常用工具改为统一图形按钮，保留完整无障碍标签；窄屏可直接使用适应、缩放及收藏，不再被长文字挤出屏幕。
2. 原生视频收藏失败可查看完整、可滚动和可复制的错误原因，不再只显示被截断的菜单文字；失败请求不会自动重放。
3. 包含父预览返回、独立播放准备、账号／输入切换和共享媒体库控件的生命周期修复；关闭操作等待实际结果，失败保留原因。
4. 这是阶段性版本。Android 持续同屏性能、长流程稳定性和全部 RHVideo 功能的原生交互仍未完成验收；不要把本版视为完整 1:1 对齐。详见 `docs/RHVIDEO-TODO.md`。
5. 设备组界面明确支持粘贴邀请或批准信息；误贴入组请求时说明如何批准。邀请二维码与完整可复制文本同时保留，并说明电脑也可粘贴邀请加入。

## English

1. Compact, consistent image-preview tools keep fit, zoom and favorite controls reachable on narrow screens, with full accessible labels.
2. Native favorite failures open complete, scrollable/selectable details instead of truncated menu text. Failed writes are never replayed automatically.
3. Includes parent-preview, preparation, account/input and shared-library lifecycle fixes. Closing waits for the actual outcome and retains failures.
4. Incremental release. Sustained Android Grid performance, long-flow stability and complete native functional parity remain outstanding; see `docs/RHVIDEO-TODO.md`.
5. Group UI distinguishes invitation, request and approval text, explains request approval, and keeps QR plus complete copyable text together. Computers can also join with invitation text.
