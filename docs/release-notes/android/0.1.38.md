# RHFiles Android 0.1.38

## 中文

1. 设备组设置的入组请求、批准及公开信息同时展示二维码和可选中的完整文本，并提供对应的一键复制按钮；复制完整内容，不重新生成请求。宽屏并排、窄屏上下排列。修复手机 WebView 拒绝剪贴板写入时无法复制的问题。
2. RHVideo 媒体库的排序、搜索字段和批量替换顺序继续对齐参考项目；新的选择、面板或账户使旧的确认准备失效，不重放已经提交的服务器操作。
3. 调整窄屏媒体库工具栏，保留可滑动的筛选和操作入口。RHVideo 的完整功能、同屏播放及性能对齐仍在继续，本版不宣称全部 1:1 验收完成。

## English

1. Show a QR code and complete selectable text together for group requests, approvals and public data, with dedicated copy buttons. Copy the entire payload without generating a new request. Use side-by-side or stacked layout according to screen width. Handle Android WebView clipboard-write denial through the platform's existing text-copy adapter.
2. Continue aligning RHVideo catalog sorting, searchable fields and selected-replacement ordering with the reference. Newer selections, panels or accounts invalidate stale confirmation preparation without replaying submitted server operations.
3. Keep catalog filters and actions accessible in a horizontally scrollable narrow-screen toolbar. Full RHVideo parity, multi-video playback and performance acceptance remain in progress; this release does not claim complete 1:1 acceptance.
