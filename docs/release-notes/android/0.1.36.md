# RHFiles Android 0.1.36

## 中文

1. 扩展 RHVideo 视频、图片、截图、小说和收藏功能：拼音搜索、双向排序、组合标签、命名顺序、跨页多选、导出与服务器管理。
2. 加入同区域原生视频混合放映，以及原生网格分组、独立/统一控制；大播放队列仅向 Media3 交付附近 21 项。
3. 加入虚拟图片条带、长图分段、迷你地图、小说章节速览、主题排版和账号隔离的进度记忆。
4. 加入只在可见时读取的长任务状态；暂存/恢复即时刷新，旧请求不能复活已删除项目，写入失败不自动重放。
5. 原生播放器的音轨、字幕、自动选择及播放控制有对应脚本接口，支持读取实际轨道和设备支持情况。
6. 大清单直接流向搜索 Worker，不经界面桥接全量拆包；元数据和缩略图缓存有界，切换账号清空；修复媒体库返回栈。
7. 修复 WebView 冷启动中已超时的信息回调导致的崩溃；补充压缩发行 APK、实际原生帧、全部管理页面和导出边界验收。

## English

1. Expanded RHVideo video, picture, screenshot, novel and favorite tools with pinyin search, bidirectional sorting, nested tags, named ordering, selection/export and server management.
2. Added in-place native mixed slideshows and paged native video grids; large queues deliver only a bounded 21-item window to Media3.
3. Added virtual image strips, long-image slicing, a minimap, chapter previews, reader themes/layout and account-scoped progress.
4. Refresh running task status only while visible. Staging/restoring invalidates stale catalogs; committed writes are never automatically replayed.
5. Native audio/subtitle tracks and playback controls have scriptable APIs, including actual selection/support state.
6. Stream catalogs directly to the search worker, with bounded metadata/cover reuse and account-switch cleanup. Corrected media-library back navigation.
7. Fixed late WebView informational replies during cold startup and extended minified release-APK, native-frame, server-control and export-boundary tests.
