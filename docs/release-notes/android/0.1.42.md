# RHFiles Android 0.1.42

发布日 / Release date: 2026-11-03

## 中文

1. 与 Windows 0.1.98 共用 WebDAV 配置文件及 v1/v2 格式，完善多协议网络位置、中文收藏名称与顺序、RHVideo 地址的跨端兼容；密码、令牌和设备组授权仍不参与同步。
2. 保留电脑端同步来的 SFTP 连接信息，并明确标注此 Android 版本暂不支持访问 SFTP，避免拒绝整份同步配置或误删其他设备的信息。此项不是新增 Android SFTP 驱动。
3. 统一 SFTP 默认端口的连接身份判断，改进格式不兼容提示，明确需要更新两端客户端；失败时不清空云端文件。
4. 增加 Windows 与 Android 共用配置样例的校验和实际 WebDAV 合并回归测试，验证名称、顺序、RHVideo 信息与本机密码隔离。
5. 抽屉“存储位置”旁增加刷新入口；设备组设置也可刷新。修复旧会话导致新共享设备记录不更新的问题，主动交换签名信息并显示连接数量、新设备及失败原因；最多 30 秒、32 个已知成员，不持续扫描、不改变授权。

## English

1. Shares the WebDAV settings document and v1/v2 formats with Windows 0.1.98, improving cross-platform protocol metadata, Unicode bookmark labels/order and RHVideo connection compatibility. Passwords, tokens and device-group trust remain local.
2. Retains SFTP profiles synchronized from PC and explicitly labels the missing Android adapter, rather than rejecting the whole document or erasing another device's records. This does not add Android SFTP filesystem access.
3. Aligned SFTP default-port identity checks and clarified unsupported-format errors. Update both clients; failures do not clear the cloud file.
4. Added common Windows/Android contract validation and actual conditional WebDAV merge/application tests, including local credential isolation.
5. Added visible device refresh beside Storage locations in the drawer and in group settings. Explicit refresh exchanges fresh signed records even with a cached session, displaying connection counts, discoveries and failures. Bounded to 30 seconds / 32 known members, without polling or changing trust/permissions.
