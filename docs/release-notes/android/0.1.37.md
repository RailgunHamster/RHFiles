# RHFiles Android 0.1.37

## 中文

1. “从电脑访问”改用设备组 HTTPS／WebDAV 文件服务，复用 Android Keystore 的现有身份和本机组权限，不再启用旧的独立 HTTP 密码服务。明确选择本地共享目录，启动后在通知栏管理，停止或退出进程即结束，不自动重启。
2. 可从电脑 RHFiles 的设备组位置浏览手机共享；本机移除成员或删除组会拒绝后续读取，重新加入不能复活旧授权。传统 FTP 功能仍需单独显式启动。
3. 补充 RHVideo 任意跳页、章节摘录搜索、目录与收藏、图片放大／截图定位和主音量；继续使用 Media3 原生视频引擎，而非嵌套网页播放器。
4. 所有新增控件有同源的可枚举 API。自动化使用有界的本机端口分配，不覆盖其他调试连接。

## English

1. Computer access now uses the shared device-group HTTPS/WebDAV service with the existing Android Keystore identity and local grants. Explicitly select local roots and start/stop through the app or notification. The legacy independent HTTP password service is retired; no silent restart.
2. Browse phone shares from desktop RHFiles. Local removal/forget denies subsequent access and rejoining cannot revive old authorization. Traditional FTP remains a separately opt-in service.
3. Add audited RHVideo page jumps, chapter excerpt search, reader TOC/favorites, enlarged images/screenshot reveal and master gain, retaining native Media3 playback.
4. New controls share enumerable UI/script APIs. Bounded local debug-port allocation never replaces another forwarding rule.
