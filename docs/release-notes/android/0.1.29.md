RHFiles Android 0.1.29

1. 修正握手阶段耗尽时间额度时被误判为“授权失效”的边界情况。现在记录为超时，仍可在总预算内尝试其他地址；不会重置总时限或增加尝试次数。
2. 将无效响应、设备签名证明失败、本机撤权、HTTP 权限拒绝和网络超时分别记录；失败冷却从整轮结束时开始，防止长时间失败后立即重复扫描。
3. 新增可复现该问题的真实 TLS 回归测试；保留 0.1.28 的按需发现、地址恢复、取消、诊断和不重复执行文件修改等功能。原签名保留数据覆盖更新；配套 Windows 0.1.80。

1. Treat an exhausted handshake-stage allowance as a timeout, not revoked authorization. Other addresses may still be tried within the unchanged total time/attempt budget.
2. Distinguish malformed responses, invalid identity proofs, local revocation, HTTP denial and transport timeout. Start cooldown after a failed run finishes, preventing immediate repeat scans after long failures.
3. Add a real TLS reproducer/regression. Retain 0.1.28 on-demand discovery, recovery, cancellation, diagnostics and non-replayed file mutations. Same signing key for in-place updates; companion Windows 0.1.80.
