2. 每轮连接最多 15 秒、6 次尝试；地址去重、并发合并、失败冷却，可主动取消。仅按需发现，及时释放网络请求、系统发现回调和多播锁，不持续 ping、广播或扫描子网。
3. 区分本机网络变化、慢响应、当前不可达和验证成功的地址变化。网络变化最多短暂等待一次，不重置预算；没有互联网不阻止局域网访问，超时不等于设备离线。
4. 设置 → 存储与权限 → 设备组新增连接诊断及手动恢复地址。保留最近 20 轮，成功/失败/跳过原因与耗时均可查看或复制，读取诊断不会重试；慢响应和服务器错误也有记录。
5. 文件读取可安全恢复一次；移动、删除、写入结果不明确时明确提示核对，不自动重放。继续保留上传偏移核验，避免重复写入。未绑定设备组的旧独立连接不参与自动换址。
6. 修正电脑扫码时名称建议；主页返回先取消待粘贴内容，实际进行中的复制/移动需确认取消，不直接退出。补充真实 TLS、网络切换、取消、权限拒绝、慢响应、服务器错误和不重复重命名测试。原签名覆盖更新，保留数据；配套 Windows 0.1.80。
