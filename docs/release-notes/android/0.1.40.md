# RHFiles Android 0.1.40

1. 更新默认来源改为 CNB，保留 GitHub；移除 Gitee 和家庭服务器更新设置，迁移旧设置时保留关闭自动检查的选择。安装包使用版本固定地址与完整性校验，不复用旧 APK。
2. WebDAV 配置同步加入 RHVideo 服务器地址和用户名；密码、令牌、登录会话不上传，不会让另一台设备自动登录或覆盖当前登录。两端同时修改连接时显示冲突；含 RHVideo 信息的同步格式需要新版客户端。
3. 更新设备组邀请处理和原生文件服务：条件移动/替换、上传提交版本证明、目录合并及授权撤销检查。文件夹不会整体覆盖，写入失败不会自动重放。
4. 本版基于 0.1.38 稳定播放器回补更新与同步功能，不包含尚未通过实测的播放器交互改写。通过完整 JVM 业务测试后构建，使用原签名覆盖安装、保留数据。

## English

1. Default updates to CNB with GitHub retained. Retire Gitee/home-server update settings without enabling previously disabled automatic checks. APK URLs are version-pinned and integrity-checked.
2. Sync RHVideo server addresses and usernames over WebDAV. Passwords, tokens and sessions remain device-local; concurrent connection edits require a conflict choice. Documents containing RHVideo metadata require upgraded sync clients.
3. Update group invitations and the native file service with checked mutations, upload commit identities and live revocation. Directories merge rather than replace; writes are never automatically replayed.
4. Backported onto the stable 0.1.38 player rather than including unaccepted player interaction changes. Builds retain the existing signing identity for data-preserving upgrades.
