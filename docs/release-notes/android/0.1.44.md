# RHFiles Android 0.1.44

发布日 / Release date: 2026-11-05

## 中文

1. 在连接并浏览 RHFiles 电脑设备时，顶部新增专用**电脑路径跳转栏**（同时在连接更多菜单中提供“跳转电脑路径”入口）：可直接粘贴或输入 `C:\Users\40608\Documents\A\B\C`（支持反斜杠或正斜杠），自动检测该设备是否共享了对应的 `C` 盘、`D` 盘等整盘并直接跳转到目标目录或选中目标文件。
2. 支持 RHFiles 设备**自定义显示名称（描述）**并随 WebDAV 配置同步（v2 `deviceAliases`）在 Windows 与 Android 之间双向同步。

## English

1. Added a dedicated **PC Path Jump Bar** when browsing a connected RHFiles PC (plus a “Jump to PC path” action in the connection menu): enter or paste paths like `C:\Users\40608\Documents\A\B\C` (with backslashes or forward slashes) to verify whether the corresponding drive (`C`, `D`, etc.) is shared on that PC and jump directly to the folder or file.
2. Added support for **custom device display names (aliases)** that sync across Windows and Android via WebDAV configuration sync (v2 `deviceAliases`).
