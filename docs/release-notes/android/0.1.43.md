# RHFiles Android 0.1.43

发布日 / Release date: 2026-11-03

## 中文

1. 首页升级为三段式 Bento 阶梯布局：顶部跨列展示本机存储与 SD 卡容量大卡并附带实时容量进度条；中部 9 个文件分类（下载、图片、音频、视频、文档、压缩包、安装包、最近修改、收藏夹）改为紧凑横向胶囊，减少首屏纵向滚动；底部规整排列局域网传输、网络位置与系统工具卡片。
2. 保持所有分类、存储根、更新提示卡与文件索引卡片的原有触控目标与自动化标识兼容。

## English

1. Redesigned the Home screen into a three-tier Bento layout: wide hero storage cards with live capacity meters at the top, compact horizontal capsules for the 9 media/file categories in the middle, and structured network/utility cards at the bottom.
2. Preserved all existing touch targets, storage root bindings, update banner behavior, and index maintenance controls.
