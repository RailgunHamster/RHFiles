# RHFiles Android 0.1.27

## 中文

1. 设备组新增“删除本机设备组”：确认后从本机界面移除，不保留恢复入口；同时清理该组生成的网络位置和对应快捷访问，不删除实际文件，不影响其他客户端或独立连接。
2. 重启、刷新和旧证明不能自动加回；以后重新生成入组请求，让仍保留该组且有邀请权限的客户端批准，并在本机确认。原创建者也可重新加入，已移除的其他设备不会因此恢复。
3. 防止正在刷新时重新生成已删除组的网络位置；清理失败会说明原因，可点“刷新组设备”重试。新增本机自动化操作 `groups.forget`，需明确确认。
4. 设备名称默认读取 Android 系统设备名称，无法读取时使用厂商/型号；创建组或申请入组前仍可手动修改，不重命名已有成员。
5. 补充删除确认、重启、保存失败、连接清理中断恢复、其他组和独立连接保留等测试。安装包继续使用原签名，支持保留数据覆盖更新。

配套 Windows 版本为 0.1.79；已有设备组协议兼容。

## English

1. Add confirmed local group deletion without a restore stub. Generated network locations and their favorites are removed; actual files, other clients and independent connections remain untouched.
2. Restart, refresh and old proofs cannot re-add a forgotten group. Rejoin using a fresh request, approval by a remaining invite-capable member and explicit local confirmation. This also works for the original creator without restoring other removed devices.
3. Prevent in-flight refreshes from recreating forgotten-group locations. Cleanup errors explain how to retry via Refresh group devices. Add the explicitly confirmed local `groups.forget` automation action.
4. Default device names to Android's configured device name, falling back to manufacturer/model. Names remain editable and existing members are not renamed.
5. Add confirmation, persistence/restart, interrupted cleanup, other-group and independent-connection regressions. Keep the existing APK signing identity for in-place updates without uninstalling or clearing data.

Companion Windows version: 0.1.79. Existing group protocol compatibility is preserved.
