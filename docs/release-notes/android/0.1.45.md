# RHFiles Android 0.1.45

发布日 / Release date: 2026-11-06

## 中文

1. 全面统一 APK 中 RHFiles 设备与网络位置的路径展示格式：**首页收藏夹列表副标题**、**侧栏快捷访问菜单**、**文件/多选属性详情**、**复制路径**、**空间分析**以及**顶部路径面包屑**均显示简短可读的 `rh://设备名/...` 地址（或网络位置名称），不再暴露 `remote://<UUID>/...` 内部长 ID。
2. 修复收藏设备根目录或一级共享目录时父路径计算截断 `remote://`、以及收藏默认名称误用内部 UUID 的问题，并支持在电脑路径跳转栏直接粘贴 `rh://设备名/C/Users/...` 格式路径。

## English

1. Unified path formatting across the Android APK so **Favorites list subtitles**, **drawer favorite menus**, **Properties sheets**, **Copy Path**, **Storage Analysis**, and **path breadcrumbs** display readable `rh://device/...` short addresses (or network location names) instead of internal `remote://<UUID>/...` identifiers.
2. Fixed `parentOf` truncation on root URIs and default favorite naming on device roots, and added support for pasting `rh://device/C/Users/...` addresses directly into the PC path jump bar.
