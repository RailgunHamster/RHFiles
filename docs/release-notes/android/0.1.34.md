# RHFiles Android 0.1.34

1. 新增 RHVideo 媒体库：从侧栏连接现有服务器，浏览和搜索视频、图片、小说及收藏，支持文件夹筛选与分页。
2. 视频使用原生 Media3 播放器，支持播放列表、上一集/下一集、时间轴定位、暂停、跳转和速度，无需外部播放器。
3. 图片支持切换与缩放，小说支持章节、字号和服务端阅读进度；收藏与 RHVideo 共用。
4. 适配手机和平板布局，返回先关闭查看器；移除多余宣传文案。登录密码不保存，令牌仅在原生内存中保留。

## English

1. Added a built-in RHVideo client with search, folder filters, pagination and shared favorites.
2. Native Media3 playback supports queues, next/previous, timeline seeking, pause and speed controls.
3. Image viewing and chapter reading include server-side favorites and reading progress.
4. Responsive phone/tablet layout, layered Back navigation and no unnecessary promotional copy. Passwords are not saved; tokens stay in native memory.
