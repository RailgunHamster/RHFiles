# RHFiles Android 0.1.41

发布日 / Release date: 2026-11-02

## 中文

1. 设备组文件下载增加有界分块并发、SHA-256 校验及当前任务内的有限补传；默认 2 路，可在设置中选择 1–4 路和单文件限速。配置纳入完整备份，不同步设备组信任。
2. 网络读取中断时标记旧连接失效，让后续有限补传通过按需连接恢复寻找可用地址。权限撤销、文件变化和格式不符直接失败，不重放移动或删除。
3. 上传合并小数据帧；新建目录树中的独立小文件两份并发，等待所有子任务结束后再处理移动源清理，进度统一汇总。
4. 图片、音视频查看仍使用按需流式读取，不先完整下载。包含此前未公开版本的图片工具栏、收藏错误详情和设备组邀请文本改进。RHVideo 的全部功能与性能对齐仍在进行，不宣称完整 1:1 验收。

## English

1. Added bounded range downloads, SHA-256 verification and finite in-task segment repair. Configure 1–4 streams (default two) and a per-file limit. Full backups retain settings without synchronizing device trust.
2. Interrupted reads invalidate stale route hints so bounded repairs use on-demand connection recovery. Revoked access, changed sources and invalid responses fail immediately; moves and deletes are never replayed.
3. Coalesced upload frames and added two-file concurrency inside newly created trees, with joined workers before move cleanup and synchronized progress.
4. Image/audio/video viewing keeps on-demand streaming instead of whole-file download. Includes previously unpublished image tools, favorite error details and invitation text improvements. Full RHVideo functional/performance parity remains in progress.
