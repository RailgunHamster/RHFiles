# RHFiles Android 0.1.25

1. 新增 RHFiles 电脑文件服务连接：不依赖 SMB，直接通过固定证书身份的 HTTPS 浏览、查看图片、播放视频和后台复制文件。需要 Windows 0.1.76 或更新版本。
2. 添加网络位置时可离线扫描电脑配对二维码，不依赖 Google 服务，不上传相机画面；保留粘贴配对信息入口。扫码后明确确认并保存连接，不自动授权。
3. 可通过 mDNS 发现同一局域网的 RHFiles 电脑，核对电脑端身份后输入 10 位配对码。发现限时运行、可取消，不扫描公网、不自动登录或保存设备。
4. 上传采用 tus 分块确认与偏移恢复；已有目标不会被覆盖。设备密码由 Android Keystore 加密保存，写入和永久删除由电脑分别授权，配置同步仍不携带密码。
5. 增加配对数据校验、证书不匹配、重定向拒绝、无覆盖、离线二维码解码及实际 HTTPS 后台传输测试。

1. Add a paired native HTTPS desktop connection, independent of SMB, for browsing, images, video ranges and background file transfers. Requires Windows 0.1.76+.
2. Pair using an offline camera QR scanner with no Google services, uploads or analytics; manual paste remains available. Scanning does not automatically pair.
3. Discover RHFiles computers with bounded, cancelable mDNS discovery. Verify the computer identity before entering its ten-digit pairing code. No public network scan or automatic login.
4. Use acknowledged tus chunks and offset recovery, never overwrite existing destinations, and protect device credentials using Android Keystore. Write/delete grants remain separate; configuration sync excludes passwords.
5. Add pairing validation, certificate/redirect protection, no-overwrite, native QR decoder and real HTTPS background-transfer regressions.
