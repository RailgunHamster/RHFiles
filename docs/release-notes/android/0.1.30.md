# RHFiles Android 0.1.30

1. 修复 WebDAV 配置同步丢失 RHFiles 电脑连接的公开证书 SHA-256 指纹、继而报“需要电脑端证书指纹”的问题。保留已有指纹，不要求在配置同步中手填，不上传登录密码或私钥。
2. 同步普通网络位置时保留本机设备组连接、授权和对应收藏，不再因替换同步子集而删除它们；拒绝云端网络位置与本机设备组连接 ID 冲突。
3. 证书身份改变时仍清除对应本机旧密码；缺失或错误指纹明确指出出问题的网络位置，不自动信任网络返回的新证书。原签名覆盖更新，保留数据；Windows 继续使用 0.1.80。

1. Preserve RHFiles computer profiles' public SHA-256 certificate fingerprints during WebDAV configuration sync. Fix the misleading missing-fingerprint error without requiring a manual sync field or uploading passwords/private keys.
2. Preserve local group connections, authorizations and bookmarks when replacing the portable configuration subset. Reject cloud profile IDs that collide with local device-group connections.
3. Clear local credentials when the certificate identity changes. Identify missing/invalid pins without learning trust from the network. Same signing identity for in-place updates; Windows remains 0.1.80.
