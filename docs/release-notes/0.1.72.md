# RHFiles 0.1.72

## 中文

- 新增 Windows / Android 同网“附近互传”第一版：主动开启后发现设备，支持手动 IP:端口；文件与文件夹发送前核对接收码，接收端逐次确认位置。
- TLS 加密、固定对端证书指纹、逐文件 SHA-256 校验；保留子目录与空文件。接收批次写入独立新文件夹，不覆盖已有数据，不删除来源。
- 支持进度、平均速度、拒绝、取消和错误原因。默认不开启网络监听，不自动共享磁盘，不经过云服务器或 HTTP 代理。
- 首版限制本机文件，最多 10,000 条目、64 层路径、1 TB；不发送符号链接、SAF 或 SMB。中断不自动重传，异常退出留下的未完成目录会明确显示。

## English

- First Windows / Android Nearby Transfer: opt-in LAN discovery, manual IP:port fallback, receiver-code confirmation, and explicit approval for every incoming batch.
- TLS with certificate pinning and per-file SHA-256; preserves directories and empty files. Receives into a separate new batch folder, never overwrites existing data or deletes source files.
- Progress, average speed, rejection, cancellation and actionable errors. No listener at startup, disk sharing, cloud relay or HTTP proxy.
- Initial limits: local files only, 10,000 entries, 64 levels, 1 TB. No symlinks, SMB or SAF sources. Interrupted transfers are not automatically replayed.
