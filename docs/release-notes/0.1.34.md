# RHFiles 0.1.34

## 中文

- 修复鼠标框选后选区被立即清空的问题：框选结束时会吞掉紧随其后的那次点击，不再误触发"点击空白清除选择"。
- 修复重命名后选中状态丢失：重命名完成后会自动选中新名字对应的文件 / 文件夹。
- 标签页悬停只保留预览卡片：移除了与原生 title 气泡叠加的第二个提示，预览弹出延迟缩短到约 300ms。
- 修复隐藏项目默认显示：地址栏建议与面包屑下拉现在遵循"显示隐藏项目"开关，关闭时不再列出隐藏文件夹。
- 打字搜索（文件列表直接敲字）停留时间可配置：默认延长到 10 秒，可选 3 / 10 / 30 秒或"一直保留"，后者只在按 Esc 或切换目录时消失。设置位置：设置 → 常规。
- 修复 Windows 分享报"Windows did not request the share data: timed out waiting on channel"：分享流程改在专用 STA 线程上运行并派发消息，系统分享事件可以正常送达。
- 删除改用现代 IFileOperation 接口：对用户资料目录这类包含连接点 / 长路径 / 被占用文件的文件夹更可靠，失败时给出可读原因（占用、拒绝访问、路径过长等），不再只是错误码。
- 支持跨远程桌面粘贴：远程桌面剪贴板以 FileGroupDescriptorW + FileContents 虚拟文件传输，现在 RHFiles 可以直接把本机复制的内容流式粘贴到远程目录，重名自动加" (1)"。

## English

- Fixed rubber-band selection being cleared immediately after release: the click that follows a finished drag is now swallowed instead of triggering "click empty space to clear".
- Renaming now keeps the item selected: the file or folder is re-selected under its new name once the rename completes.
- Tab hover now shows a single tooltip: the native title bubble that stacked on top of the preview card is gone, and the preview opens after ~300ms.
- Fixed hidden items showing by default: address-bar suggestions and breadcrumb dropdowns now follow the "show hidden items" toggle instead of always listing hidden folders.
- The type-ahead search highlight duration is configurable: default raised to 10 seconds, with 3 / 10 / 30 second and "keep until Esc or navigation" options under Settings → General.
- Fixed Windows sharing failing with "Windows did not request the share data: timed out waiting on channel": the share flow now runs on a dedicated STA thread with a pumped message loop so system share events are delivered.
- Deletion now uses the modern IFileOperation API: more reliable for profile-style folders containing junction points, long paths, or locked files, and failures now carry readable reasons (in use, access denied, path too long) instead of a bare code.
- Remote Desktop paste support: RDP clipboards transfer files as FileGroupDescriptorW + FileContents virtual streams; RHFiles now streams them straight into the remote folder, numbering duplicates like " (1)".
