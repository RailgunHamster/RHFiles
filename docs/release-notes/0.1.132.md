# RHFiles Windows 0.1.132

- RHFiles 设备支持同一共享内的符号链接。通过文件链接保存修改会更新目标文件，在目录链接内新建、粘贴、改名或删除会作用于目标目录。直接改名或删除链接时只操作链接本身。权限仍由设备组控制。

- RHFiles Devices supports symbolic links within the same share. Saving through a file link updates its target, and operations inside a directory link apply to the target directory. Renaming or deleting the link itself acts on the link. Device group permissions still apply.
