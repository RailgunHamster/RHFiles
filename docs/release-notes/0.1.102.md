# RHFiles Windows 0.1.102
1. 修复进入 Git 仓库子目录浏览时，文件列表的 Git 修改状态角标丢失的问题。现在自动按当前目录相对于仓库根目录的路径前缀映射状态，并在子文件夹行汇总显示其内部未提交修改。
2. 新增与 Verso 版本管理工具的联动：自动识别本机已登记的 Verso 客户端（`%LOCALAPPDATA%\Verso\Desktop\installation.json`），在 `.verso` 工作区中直接展示文件修改状态，底部状态栏显示当前分支及 Git 领先/落后提交计数（`↑/↓`）。
3. 右键“打开方式”菜单新增 `Verso`、`Verso Diff`（直接定位到修改差异页）和 `Verso History`（直接定位到版本历史页），并补齐 `git_pull`、`git_push`、`git_commit`、`git_revert`、`git_log` 与对应桌面自动化接口（`vcs.*`）。
4. 包含 Windows 与 Android 共用的 RHVideo 前端预览页支持。
## English
1. Fixed missing Git status indicators when browsing inside subdirectories of a Git repository. Status entries are now mapped relative to the active directory, and child folders summarize descendant modifications.
2. Added integration with the Verso version control client: detects registered Verso installations (`%LOCALAPPDATA%\Verso\Desktop\installation.json`), displays `.verso` workspace file states in the file list, and shows the active branch and Git ahead/behind counts (`↑/↓`) in the status bar.
3. Added `Verso`, `Verso Diff` and `Verso History` to the Open With context menu, along with `git_pull`, `git_push`, `git_commit`, `git_revert`, `git_log` and desktop automation commands (`vcs.*`).
4. Includes the shared RHVideo frontend preview across Windows and Android.
