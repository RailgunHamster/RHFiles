# RHFiles 0.1.26

## 中文

- 系统托盘图标现在有明确用途：左键单击会恢复并聚焦 RHFiles；右键菜单提供“打开 RHFiles”和“退出 RHFiles”。菜单会跟随软件当前选择的中文或英文界面，初始化完成前也会显示中英双语文本。
- 修复关闭主窗口后托盘图标仍然存在、但无法再次打开软件的问题。关闭最后一个主窗口现在会隐藏到托盘；若旧状态已经销毁了窗口，托盘和再次启动 RHFiles 也可以重新创建主窗口。右键“退出 RHFiles”会真正结束后台进程。

## English

- The system tray icon now has a clear purpose: left-click restores and focuses RHFiles, while its right-click menu provides **Open RHFiles** and **Exit RHFiles**. Menu labels follow the language selected in the application, with bilingual labels available before localization finishes.
- Fixed the tray process remaining alive with no usable window after the main window was closed. Closing the last main window now hides it to the tray; if an older state already destroyed the window, the tray icon or launching RHFiles again can recreate it. **Exit RHFiles** terminates the background process.
