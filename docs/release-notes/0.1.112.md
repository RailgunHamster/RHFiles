# RHFiles Windows 0.1.112

1. 版本记录分为“最近更新记录”和“历史记录”。最近仅显示 10 条，历史记录每页 10 条，提供页码与上一页、下一页。
2. 翻页使用本地已加载记录，不重新请求网络，也不折叠或重开最近版本。正文按展开加载，避免一次创建全部历史正文。
3. 补充版本记录读取和翻页的命令行 API。修复 GitHub 下载网关异常导致依赖准备和已发布版本校验失败的问题，改用带长度与 SHA-256 校验的官方资产 API。

## English

1. Release history now separates the 10 most recent releases from older records, with 10 older releases per page and previous/next controls.
2. Paging uses loaded history without new network requests or resetting recent release expansion. Note bodies are rendered on demand.
3. Added history state and pagination automation actions. GitHub asset API downloads with size and SHA-256 verification avoid gateway failures in dependency preparation and published-release checks.
