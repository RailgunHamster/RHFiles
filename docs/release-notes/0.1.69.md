# RHFiles 0.1.69

## 中文

- Shift＋↑/↓以当前焦点为起点扩展连续多选，反向移动收缩选择；卡片/缩略图也支持 Shift＋方向键，并且左右窗格的选择互不影响。
- Ctrl＋Shift＋方向键可保留原有离散选择；鼠标选中、排序或切换目录后不会沿用旧的键盘多选起点。
- 修复解压到非空文件夹时误报“文件冲突”的问题。现在先读取压缩包内文件并检查实际输出路径，只有真正重名的文件才提示；分卷本身或其他无关文件不会触发。
- 冲突弹窗显示压缩包内的具体文件及完整目标路径，多项冲突可以展开查看清单。处理方式明确应用于本次解压的全部同名文件，不再显示无效的“应用于所有”勾选框。
- 已有文件夹正常合并。文件与文件夹类型不一致或路径经过链接时，在写入前报告具体路径；后端在开始解压时再次检查，防止替换整个目录或覆盖正在读取的压缩包分卷。
- 加密文件列表先询问密码，再检查冲突；单个压缩包成员的解压只检查该成员的输出路径。
- 新增非空目录无冲突、嵌套重名、覆盖/跳过/保留两者/取消、成员解压、加密头及目录保护的业务回归测试。

## English

- Shift+Up/Down extends a continuous selection from the focused item and shrinks it when reversing direction. Shift+arrow also follows the visual grid in Cards/Thumbnails, independently in each pane.
- Ctrl+Shift+arrow retains existing disjoint selections. Mouse selection, sorting or folder navigation resets stale keyboard range anchors.
- Fixed false conflict dialogs when extracting into a nonempty folder. RHFiles now compares archive members with their actual output paths. Unrelated files, including the archive's own volumes, do not trigger the dialog.
- Conflict dialogs show concrete archive members and complete destination paths, with an expandable list for multiple conflicts. Choices explicitly apply to all matching files in this extraction; the ineffective Apply to All checkbox is removed.
- Existing folders merge normally. File/directory type mismatches and linked paths are reported before writing. The backend checks again before extraction to protect existing directories and input archive volumes.
- Encrypted file lists request a password before inspection. Single-member extraction checks only that member's output paths.
- Added business regression coverage for unrelated destination files, nested conflicts, Replace/Skip/Keep Both/Cancel, member extraction, encrypted headers and directory protection.
