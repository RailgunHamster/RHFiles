# RHFiles Windows 0.1.85

## 中文

1. 扩展 RHVideo 媒体库：拼音/首字母搜索、八种双向排序、嵌套标签规则、命名顺序、多选及 UTF-8 有界导出。
2. 加入完整截图浏览、横竖虚拟条带、长图分段、迷你地图和图片/视频混合放映；原生多视频网格支持前后分组和独立控制。
3. 扩展原生连播、真实下一项预加载、分段/全长、低带宽版本、断点记忆；修复延迟自动下一项和手动切换间的竞态。
4. 加入小说目录搜索、主题/排版、章节速览与分页试读；阅读进度按账号隔离、串行保存。
5. 加入服务器监控、处理队列、原片替换、暂存恢复、占用统计、清理及服务管理。长任务只在可见时读取，失败不自动重放写入。
6. 所有新增界面操作均有可枚举的命令行接口和参数定义；补充按钮覆盖、实际服务端、原生帧及大库测试。
7. 大清单通过只读临时通道直接交给搜索 Worker；复用有界元数据及缩略图，修复写入后旧清单回写、账号隔离和返回栈。

Windows 视频播放需要已安装的 64 位 VLC 3.x，或程序旁的 vlc/ 目录；浏览、图片及阅读不需要 VLC。未在所有真实设备/网络上完成全面性能比较，不据此保证每种媒体都可硬件解码。

## English

1. Expanded RHVideo with pinyin/initial search, eight sorting directions, nested tag rules, named ordering, selection and bounded UTF-8 export.
2. Added screenshot browsing, virtual horizontal/vertical strips, long-image slices, a minimap, mixed native slideshows and paged multi-video grids.
3. Expanded native queues, actual bounded next-item preloading, segments/full-length playback, low-bandwidth variants and account-scoped resume; guarded delayed automatic next operations.
4. Added chapter search, reading themes/layout, paged chapter previews and serialized account-scoped progress.
5. Added server watch folders, tasks, source replacement, staging/restoration, storage, cleanup and service tools, with visible-only reads and no automatic write replay.
6. Added enumerable CLI actions and schemas for the UI, plus real-server, native-frame, control-coverage and large-library regression tests.
7. Catalogs reach the worker through revocable read-only capabilities. Bounded metadata/cover reuse avoids full-library UI-thread copies and stale post-write responses.

Windows native video requires 64-bit VLC 3.x installed or available beside RHFiles. Device/network-wide comparative performance and universal hardware-codec support are not claimed.
