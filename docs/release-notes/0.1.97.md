# RHFiles Windows 0.1.97

1. 设备组文件下载支持有界并行分块读取，默认 2 路，可在“局域网文件服务”设置中选择 1–4 路及单文件下载限速；设置与脚本接口共用校验并纳入完整配置备份。
2. 每块绑定源文件读取版本并校验 SHA-256；当前任务只对网络中断或校验失败的块有限补传。文件变化、权限撤销或设备移除后立即失败，不复活已结束任务、不自动重放写操作。
3. 上传合并小数据帧并重叠源文件读取与发送；减少重复签名校验，保留实时权限检查，以及文件和日志落盘后才确认偏移的安全保证。
4. 小文件采用两份有限并发，目录创建、冲突处理、移动源清理与撤销保持有序。连接诊断显示分块读取和补传原因。旧设备保留连续流式传输，媒体预览不等待整块下载。

## English

1. Added bounded parallel range downloads, defaulting to two streams. Configure 1–4 streams and a per-file download rate in LAN File Service settings, through the same validated scripting API. Full backups retain these local preferences.
2. Every segment is bound to a source read generation and verified with SHA-256. Only active same-version reads receive finite repair attempts for transport or checksum failures. Source changes and revoked access are terminal; completed jobs and mutations are never replayed.
3. Coalesced upload frames and pipelined source reading with sending. Cached immutable membership verification while keeping live authorization and durable file/journal acknowledgements.
4. Added two-file bounded concurrency for new small files while preserving ordered directory/conflict handling, move cleanup and undo. Diagnostics expose range repairs. Older devices retain continuous streaming; media previews do not wait for whole download segments.
