# RHFiles Windows 0.1.99

1. 顶部标签栏、地址栏与命令栏视觉收敛：标签采用悬浮胶囊样式，地址栏搜索框内嵌搜索范围徽章（`⚡ 当前目录` / `⚡ Everything`）；未选中文件时弱化剪切、复制、重命名与删除按钮，选中文件后显示选中数量胶囊并高亮上下文操作。
2. 左侧边栏新增“★ 导航与磁盘 / 🌲 完整目录树”双模分段切换：切换到完整目录树时占满侧栏可视高度，消除局促的内嵌双滚动条；磁盘条目增加 4px 容量进度条与使用率百分比胶囊（75% 预警、90% 告警）。
3. 右侧预览检查器底部新增文件摘要卡与快捷操作晶片：实时展示文件类型、大小、文本编码、行尾序列（CRLF / LF）、行数与 Git 状态，并为媒体文件与压缩包提供一键 `⚡ FFmpeg 转换`、`📦 解压到当前`、`📋 复制路径` 和 `🔍 属性` 入口。
4. 调校默认浅色主题与暖沙（Sand）主题表面色阶：默认浅色采用纯净冷白卡片（`#FFFFFF`）配柔和浅灰侧栏（`#F3F5F8`），暖沙主题采用低饱和象牙白（`#FCFBF9`），消除过强的黄色滤镜感并同步更新外置升级过渡窗配色。

## English

1. Refined top tab bar, address bar and command bar hierarchy: pill-shaped tabs, an inline search-engine scope badge (`⚡ Current folder` / `⚡ Everything`), and context-aware selection action highlighting with a live selection count pill.
2. Added a dual-mode segmented switch (`★ Navigation & Disks` / `🌲 Full Directory Tree`) in the left sidebar so the directory tree can expand to the full sidebar height, alongside 4px drive capacity bars and usage percentage badges.
3. Added a bottom file summary card and quick-action chips in the right inspector pane, displaying file format, size, encoding, line endings (`CRLF` / `LF`), line count, Git status, and one-click `⚡ FFmpeg Convert`, `📦 Extract Here`, `📋 Copy Path`, and `🔍 Properties` actions.
4. Tuned the default Light theme to a crisp neutral white (`#FFFFFF` cards, `#F3F5F8` sidebar) and softened the Warm Sand (`sand`) theme to a low-saturation ivory palette (`#FCFBF9`), synchronized with the external update transition splash.
