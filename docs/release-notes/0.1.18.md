# RHFiles 0.1.18

- 设置的更新区域现在会在“立即检查”按钮旁显示具体失败原因，不再只给出“无法连接更新源”之类的笼统状态。
- RHFiles 会读取最近一次 Velopack 安装会话，并区分文件占用、权限不足、磁盘空间不足、更新包损坏、网络错误和未知错误。
- 文件占用导致安装失败时，会显示应在 Windows 资源监视器“关联的句柄”中搜索的完整安装路径。
- 失败提示提供“打开更新日志”入口，方便查看 Velopack 返回的原始错误；即时检查和下载错误也会显示系统细节。
- 成功安装、后续成功会话或当前版本已经达到目标版本后，旧失败提示会自动失效，不会长期误报。
