# RHFiles Windows 0.1.105
1. 主页（`home://`）新增 **RHFiles 设备** 与 **网络位置** 两个分区，与本地驱动器采用统一的卡片布局（支持点击进入、Ctrl/中键在新标签页打开）。
2. 当 RHFiles 设备共享了盘符或磁盘目录（如 `C`、`D`、`E`、`F` 盘）时，服务端在共享挂载点元数据中返回真实磁盘总容量与可用空间（`totalBytes` / `freeBytes`），主页直接展示与本地驱动器一致的容量占用进度条和剩余 GB 数。
## English
1. Added **RHFiles Devices** and **Network Locations** sections to the Home page (`home://`) using the same card layout as local drives (supporting click to open and Ctrl/middle-click for a new tab).
2. When an RHFiles device shares drive mounts (such as `C`, `D`, `E`, `F`), the service includes volume capacity metadata (`totalBytes` / `freeBytes`) on share roots so the Home page renders a capacity usage bar and free-space summary matching local drives.
