# RHFiles Windows 0.1.115

1. 左侧导航支持按整组拖动排序，包括 RHFiles 设备、收藏夹、快速访问、回收站等；组内项目和操作一起移动，顺序自动保存。
2. 设置 → 外观增加“侧栏分组顺序”，支持上移、下移和恢复默认；侧栏手柄也支持上下方向键。提供相同的脚本接口，配置备份包含此顺序。
3. 修复 GitHub Windows 业务测试误点设备改名按钮的问题：改为按稳定操作标识点击移除/恢复，并校验对应确认内容。

## English

1. Reorder entire sidebar groups using their drag grips, including RHFiles devices, Favorites, Quick access and Recycle Bin. Children stay together and the order is saved automatically.
2. Appearance settings provide move-up/down controls and a reset option. Focused sidebar grips support arrow keys; equivalent automation APIs and configuration backups retain the order.
3. Fix the GitHub Windows workflow's device-group UI test: select Remove/Restore using stable action IDs and verify the matching confirmation instead of clicking Rename by position.
