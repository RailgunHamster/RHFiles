# RHFiles 0.1.22

## 中文

- 新增实验性的 Windows 文件对话框集成，可在设置中单独开启。标准 Windows 打开 / 保存对话框或资源管理器处于前台时，按下快速跳转快捷键即可进入 RHFiles 当前活动窗格所在的文件夹。
- 默认快捷键为 `Ctrl+G`，可在快捷键设置中修改。快捷键只会在识别出的 Windows 文件界面中拦截；路径通过 Unicode 键盘输入发送，不会覆盖用户剪贴板。
- 支持本地磁盘与 UNC/SMB 文件夹，并会跟随标签页、双窗格焦点和文件夹导航更新目标路径。自定义文件选择器和管理员权限窗口暂时可能无法接管。
- 修复任务中心展开状态的界面测试时序，并增加真实低级键盘钩子安装测试与家庭服务器更新源版本选择验证。

## English

- Added an opt-in experimental Windows integration. From a standard Open/Save dialog or File Explorer, the quick-switch shortcut navigates to the folder in the active RHFiles pane.
- The default shortcut is `Ctrl+G` and can be changed in Shortcut settings. It is intercepted only in recognized Windows file surfaces, and the path is entered as Unicode keyboard input without replacing the clipboard.
- Local drives and UNC/SMB folders are supported, with the target following tab navigation and the active dual pane. Custom file pickers and elevated windows may not accept navigation yet.
- Stabilized the task-center UI test and added real low-level hook installation coverage plus home-server update-feed selection verification.
