# RHFiles 0.1.55

## 中文

- **弹窗回到屏幕正中间**。`base.css` 开头的全局重置 `* { margin:0; padding:0 }` 把浏览器给模态 `<dialog>` 的居中样式（`margin:auto`）一并抹掉了，所以所有用 `showModal()` 自建的原生对话框都贴在窗口左上角——解压密码框、Git 克隆、磁盘格式化、FTP、备用数据流和权限对话框都受影响。现在为这些对话框恢复居中定位，设置窗口（自绘为桌面式工作区）保持原样。
- 无头校验脚本新增 3 项断言（水平居中、垂直居中、尺寸不被破坏），共 29 项：`node scripts/verify-ui-fixes.mjs`。

## English

- **Prompts are centred again.** The global reset at the top of `base.css` (`* { margin:0; padding:0 }`) also wiped the user-agent `margin:auto` that centres a modal `<dialog>`, so every prompt built with `showModal()` sat in the window's top-left corner — the archive password prompt, git clone, disk format, FTP, streams and permissions dialogs alike. Those dialogs now get centred positioning back, while the Settings window (a self-positioned workspace) is left untouched.
- The headless verification script gained three assertions (horizontal centre, vertical centre, content size intact), 29 in total: `node scripts/verify-ui-fixes.mjs`.
