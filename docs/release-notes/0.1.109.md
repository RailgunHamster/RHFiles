# RHFiles Windows 0.1.109
1. 修复侧栏**收藏夹（快捷访问）**、**最近访问**悬停提示及**文件属性对话框**中对 RHFiles 设备路径显示内部长 ID（`rhfiles-device://...`）或对网络位置显示 `remote://...` UUID 的问题，统一显示可读的 `rh://设备名/...` 短地址。
2. 修复在 RHFiles 设备根目录或含中文编码路径下点击收藏按钮时默认收藏名称截取了设备 ID 或未解码字符串的缺陷。
## English
1. Fixed Favorites, Recent items tooltips, and Properties dialogs displaying raw `rhfiles-device://...` or `remote://...` UUIDs instead of readable `rh://device/...` short addresses.
2. Fixed default favorite naming when pinning an RHFiles device root or percent-encoded subfolder.
