# RHFiles 0.1.37

## 中文

- 多选拖动时，跟随鼠标的拖拽虚影现在列出**所有**被拖动的项目（最多显示 4 个名字加剩余数量），不再只显示鼠标按下的那一个文件或文件夹。
- 选中的项目会在图标区显示拖动提示：半透明高亮块加抓手图标，悬停时更明显，提示"从这里可以拖动"；未选中时保持原来的清爽外观。
- 目录树里的文件夹图标换成与文件列表一致的立体文件夹图标（跟随"图标样式"设置），替换掉之前那个扁平的黄色线框图标。

## English

- The drag image now lists **every** dragged item (up to four names plus a remaining count) instead of showing only the file or folder the pointer grabbed.
- Selected items advertise their drag surface: the icon area shows a translucent plate with a grip glyph, stronger on hover, so it is obvious where dragging starts. Unselected rows stay unchanged.
- The directory tree now uses the same rich folder icon as the file list (following the icon-style setting), replacing the old flat yellow outline icon.
