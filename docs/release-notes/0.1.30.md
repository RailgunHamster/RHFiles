# RHFiles 0.1.30

## 中文

- 再次修复文件和文件夹拖到其他标签页时中途失效的问题：切换标签页期间不再移动、克隆或移除浏览器正在使用的原生拖拽源及其父节点，而是在原位置保留整棵源节点树，目标标签页内容绘制到旁边；松手后会统一询问复制、移动或取消。
- CMD、PowerShell、Windows Terminal 与 Git Bash 在目标是文件时统一打开其所在目录，文件夹则打开文件夹本身；CMD 使用 `pushd` 兼容 UNC 路径，PowerShell 使用 `Set-Location -LiteralPath`，并修复 Git Bash 把 `--cd=` 与路径错误拆成两个参数的问题。
- “共享”改为真正的 Windows 系统分享面板，并将所有选中文件或文件夹作为存储项交给系统。QQ、微信、飞书等应用只有在自身注册为 Windows 分享目标时才会出现在面板中，不再提供仅启动应用却没有发送文件的伪分享入口。
- 改进 7-Zip、Bandizip 与 WinRAR 的程序发现，支持标准安装目录、Windows App Paths、PATH 和用户指定路径；Bandizip 同时识别 `bz.exe` 与 `Bandizip.exe`，失败时会显示工具的实际输出。
- 在“设置 → 文件与布局 → 外部压缩工具”中加入免编译配置：可为每个工具指定可执行文件，并以“每行一个完整参数”的方式编辑命令模板。`{dest}` 代表输出压缩包，`{sources}` 独占一行并展开为全部选中项。
- 新增外部压缩、Windows 分享路径、文件目标终端目录以及标签页拖放完整链路的回归测试；本机 Bandizip 7.43 已通过真实创建 ZIP 的烟雾测试。

## English

- Fixed file and folder drags being cancelled during a tab switch again. RHFiles no longer moves, clones, or removes the native drag source or its parent while the browser owns the drag; it retains the entire source tree in place and renders the destination tab beside it. Every completed internal drop now asks whether to copy, move, or cancel.
- CMD, PowerShell, Windows Terminal, and Git Bash now consistently open the containing folder for a file and the folder itself for a directory. CMD uses `pushd` for UNC support, PowerShell uses `Set-Location -LiteralPath`, and Git Bash now receives `--cd=<directory>` as the required single argument.
- Replaced the non-functional per-app share launchers with the real Windows share sheet and passes every selected file or folder as a storage item. QQ, WeChat, Feishu, and other apps appear only when their installed version registers as a Windows share target.
- Improved 7-Zip, Bandizip, and WinRAR discovery across standard install folders, Windows App Paths, PATH, and a user-configured executable. Bandizip recognizes both `bz.exe` and `Bandizip.exe`, and command failures now include the tool's actual output.
- Added no-recompile configuration under **Settings → Files & layout → External compression tools**. Each tool can override its executable and edit a one-argument-per-line template; `{dest}` is the output archive and a standalone `{sources}` line expands to all selected items.
- Added regressions for external compression, Windows share paths, file-target terminal directories, and the full tab-drop path. An installed Bandizip 7.43 build also passed a real ZIP creation smoke test.
