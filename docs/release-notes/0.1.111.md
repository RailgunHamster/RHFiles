# RHFiles Windows 0.1.111

1. 修复 RHFiles 设备的大文件夹移入回收站已经完成，客户端却因 30 秒超时报删除失败的问题。远端写入采用后台任务和独立回执，客户端查询实际结果，不重复发送删除、还原或其他文件修改请求。
2. 操作回执绑定设备身份、请求参数和文件版本，完成后仍保留原始结果及撤销凭据。服务重启、断网或回执无法确认时明确提示结果未确认，不按路径猜测成功，也不重放写入。
3. 大文件夹的普通删除仍进入目标电脑的 Windows 回收站；Shift+Delete 仍彻底删除。客户端和目标电脑均需升级才能使用后台任务回执。

## English

1. Fixed remote folder recycling completing successfully while the client reported a 30-second timeout. Remote mutations now run independently of HTTP connections, with owner-bound receipts queried by the client without replaying writes.
2. Receipts retain the original result and undo token, and bind to device identity and request arguments. Missing receipts or server restarts report an unconfirmed outcome instead of guessing by path or repeating a mutation.
3. Ordinary deletion continues to use the host computer's Windows Recycle Bin; Shift+Delete remains permanent. Update both the client and the host for background operation receipts.
