# RHFiles Windows 0.1.98

1. 侧栏“管理设备组”“缓存与工作副本”改为 RHFiles 设备下的子操作，增加图标、缩进和交互状态；没有 USB/MTP 设备时隐藏空分组。
2. 统一网络位置管理，支持保存 SMB、SFTP、FTP、FTPS 和 WebDAV 连接。密码与 SFTP 主机指纹仅加密保存在本机；网络位置的名称、地址和账号可参与 WebDAV 配置同步。
3. 完善 Windows 与 Android 的同文件配置同步：导入非 SMB 收藏，保留中文名称、标签、顺序和 RHVideo 地址；不再用 Windows 本地文件名规则误拒绝合法 WebDAV 路径。旧版未显示的收藏不会被误判为删除。
4. 接入 Windows 原生文件拖出；远端文件可先“准备拖到其他应用”，再拖动保留的本机副本。副本不会随拖拽结束删除，也不会因外部应用返回移动标志而删除原件。微信、QQ 的真实鼠标拖拽仍待实机验收。
5. 设置中增加独立的 Win+E 与普通文件夹默认打开开关，默认关闭；支持新标签页或新窗口，保留 Windows 资源管理器入口。仅修改当前用户注册项，提供恢复日志和程序路径修复，不替换桌面、任务栏或打开/保存对话框；实际 Win+E 接管仍待实机验收。
6. 增加跨端同步、真实协议服务器、二进制传输、冲突保护和自动化接口回归测试。新网络位置暂不提供不带版本校验的跨位置移动，请复制核对后手动删除；已有设备组移动不受影响。
7. 设备区刷新改为连接已知组成员、交换签名服务记录，能发现后来加入或启动共享的设备；启动共享或修改开放设置时也进行一次有界交换。显示发现数量和失败原因，连接诊断保留尝试过程。每次最多 30 秒、32 个已知成员，不持续扫描、不修改权限、不恢复本机已移除的设备。
8. 修复 CI 的失效 FFmpeg 历史下载地址，改从当前保留的 Windows 包恢复并校验固定二进制；修正 macOS 隔离测试目录的系统符号链接处理，不放宽文件安全检查。
9. 更新退出替换阶段接入独立轻量过渡窗，跟随当前主题、自定义主题颜色及中英文，显示解压、应用、恢复窗口三个阶段。它运行在安装目录外，不占用待替换文件；只有窗口就绪才隐藏原生更新框。启动失败自动保留原生提示，安装失败或长时间没有新窗口会明确提示，不伪造下载百分比。

## English

1. Nested device-group management and cache/work-copy actions under RHFiles devices, with icons and interaction states. Hide empty USB/MTP sections.
2. Unified saved network locations for SMB, SFTP, FTP, FTPS and WebDAV. Passwords and SSH host-key trust stay encrypted on this device; connection metadata can participate in WebDAV settings sync.
3. Improved the shared Windows/Android settings file: import non-SMB bookmarks and retain Unicode labels, order and RHVideo metadata. Portable WebDAV paths no longer inherit Windows filename restrictions. Migration preserves bookmarks an older PC client never displayed.
4. Added native Windows outbound dragging and explicit retained local preparation for remote files. Drops never automatically delete cached files or remote originals. Physical WeChat/QQ drag acceptance remains pending.
5. Added separate opt-in Win+E and ordinary-folder integration controls, tab/window routing, Explorer bypass and a recovery journal/path repair. Both controls default off. The desktop, taskbar and Open/Save dialogs are not replaced; real Win+E acceptance remains pending.
6. Added shared-contract, real protocol-server, binary-transfer, conflict and scripting tests. New saved protocols reject cross-location moves without version-checked source cleanup; copy and verify before deleting manually. Existing device-group moves are unchanged.
7. Device refresh now exchanges signed service records with known members to learn later-added or newly shared devices. Starting sharing or changing access settings also triggers one bounded exchange. Results show discovery counts and failures, with route evidence in Connection diagnostics. Each run is limited to 30 seconds / 32 known members; no polling, grant changes or restoration of locally removed devices.
8. Repaired the expired CI FFmpeg recovery URL using the currently retained Windows package and an independently pinned binary hash. Canonicalized the private macOS test directory without weakening production symlink protection.
9. Added a lightweight external transition window during update replacement, matching the active theme, custom colors and language. It runs outside the installation and shows phases rather than invented byte percentages. Native progress is hidden only after readiness; launch failures retain native progress, and installer failures or missing new windows remain explicit.
