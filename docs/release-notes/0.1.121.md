# RHFiles Windows 0.1.121

发布日期 / Release date: 2026-11-10

## 中文

1. 连续图片自动滚动速度上限提高到 6000 像素／秒，支持滑块和精确数值输入；空格切换开始和暂停，输入框内及长按重复不会误触。
2. 图片查看器和设置中的逐张翻页／连续滚动改为双按钮切换，直接显示当前模式。
3. 左上角标题显示鼠标实际指向的图片；鼠标位于空白区域或移开后，恢复显示当前位置的图片，浏览进度不随悬停改变。
4. 右键图片时暂停滚动并高亮整张图片边框，提供另存为、复制文件路径、使用系统应用打开，菜单始终操作实际右键选中的图片。
5. 本地和 RHFiles 设备图片均可另存到本地，显示保存进度并接入主窗口任务中心；默认不覆盖已有文件，校验源和目标版本后原子提交，不修改源文件。
6. 新增对应的图片菜单、保存、复制路径和自动滚动切换脚本接口，补充真实文件保存、覆盖保护、鼠标命中及键盘交互测试。

## English

1. Raise continuous-image auto-scroll speed to 6000 pixels/second with a slider and precise numeric input. Space starts or pauses scrolling, excluding editable fields and repeated key events.
2. Replace browsing-mode lists with a two-button paged/continuous switch in the viewer and settings.
3. Show the image under the pointer in the upper-left title. Empty space or leaving the canvas restores the current-position title without changing navigation.
4. Right-click pauses scrolling, outlines the whole target image, and offers Save As, Copy File Path, and Open in System App. Actions remain pinned to the actual target.
5. Save local or RHFiles device images to the local filesystem with viewer/task-center progress, explicit overwrite confirmation, revision checks and atomic commit, preserving the source.
6. Expose image-menu, save, copy-path and auto-scroll toggle APIs, with real-file, overwrite, hit-testing and keyboard regression coverage.
