# RHFiles Windows 0.1.110

1. RHFiles 设备上的普通删除现在进入目标电脑的 Windows 回收站，保留原名、位置和完整文件夹内容。Shift+Delete 保留双重确认并彻底删除。
2. Ctrl+Z 可撤销本次远端回收站删除，Ctrl+Y 可重做。还原使用绑定设备权限的操作记录，原位置已有新项目时会停止并保留数据。客户端和目标电脑都需更新。
3. 修复复制、剪切已经成功，却因可选的 Windows WebDAV 接入不可用而显示错误提示的问题。
4. 设置中的“自动下载更新并重启”默认关闭。开启后自动检查发现新版本会下载并重启更新，文件任务运行时等待空闲；关闭自动检查后此选项不生效。手动检查仍可查看日志并确认更新。

## English

1. Ordinary deletion on RHFiles devices now uses the host computer's Windows Recycle Bin, preserving original names, locations and complete folders. Shift+Delete remains permanent and requires two confirmations.
2. Ctrl+Z restores the exact remote deletion and Ctrl+Y repeats it. Device-bound receipts and version checks protect newer files at the original location. Update both the client and the host computer.
3. Successful copy and cut operations no longer report an error when optional Windows WebDAV compatibility is unavailable.
4. Added an opt-in automatic download and restart setting. Automatic checks install new versions when file tasks are idle. Disabling automatic checks also disables automatic installation. Manual checks retain the update confirmation and release notes.
