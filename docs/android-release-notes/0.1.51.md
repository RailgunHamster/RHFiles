# RHFiles Android 0.1.51

发布日期 / Release date: 2026-11-09

## 中文

1. 逐张和连续图片都可首尾循环，保持文件列表的当前顺序；连续自动滚动同样可以循环。
2. 图片查看器下方增加总进度条，拖动时预览目标序号和名称，松手跳转，支持脚本定位。
3. 在更多菜单补充新建入口，复制／移动待粘贴时也能创建目标文件夹；实际分类文件夹同样可用。
4. 新建文件夹统一使用当前本机、系统授权或网络连接。远程目录直接使用 SMB、FTP/FTPS、WebDAV 或 RHFiles 设备创建接口，不再为创建目录扫描整个父目录；保留服务器权限校验和同名拒绝，不覆盖已有目录。错误会明确返回，失败后解除界面任务状态。
5. 新建文件和文件夹提供对应脚本接口，创建后保留当前浏览位置。

## English

1. Paged and continuous pictures wrap in the existing file order, including automatic continuous scrolling.
2. Add an overall picture progress bar with target preview, release-to-seek and a matching automation action.
3. Add New to the overflow menu, including while a copy/move is pending, and support real folders behind category views.
4. Use the current storage adapter for folder creation: SMB, FTP/FTPS, WebDAV and RHFiles devices enforce their own permissions and reject existing folders. Creating remote directories no longer enumerates the entire parent. Errors propagate clearly and release the UI task lock.
5. Add file/folder creation APIs and preserve the browser position after creation.
