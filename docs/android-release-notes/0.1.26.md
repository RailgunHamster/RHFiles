# RHFiles Android 0.1.26

1. 新增设备组：设置 → 存储与权限。生成本机入组请求，让已有邀请权的成员扫码/粘贴批准，再在本机确认加入。支持扫码与复制公开证明；证明过长时改用完整文本。
2. 无中心服务器、没有共享私钥。手机身份私钥留在 Android Keystore；连接组成员电脑时交换签名证明，刷新组设备即可学习其他成员电脑的网络位置。
3. 本机移除留下持久拒绝记录，覆盖本机全部组；重启、刷新、同步和更新均不能自动加回，需手动确认恢复。删除组生成的网络位置也会在本机移除该设备。
4. 文件会话只保留在内存，电脑端移除后已有凭据也不能继续访问。组身份、拒绝记录和自动生成的连接不进入配置备份或 WebDAV 同步，避免复制设备身份和误恢复权限。
5. 继续支持原有扫码配对与第三方 WebDAV 账号。设备组需要 Windows 0.1.77 或更新版本；电脑仍需自行开启文件服务和共享范围。

1. Decentralized device groups under Settings → Storage & permissions, using signed request/approval QR or text exchange.
2. Independent Android Keystore identities; signed membership/server information propagates when connecting to known computers. No central service or shared private key.
3. Persistent local removal across local groups, including removal of generated network locations. Only explicit local confirmation restores access.
4. Short-lived credentials remain in memory. Device identity, refusal records and generated connections are excluded from configuration backup/WebDAV sync.
5. Existing direct pairing and WebDAV app credentials remain supported. Groups require Windows 0.1.77+ with explicitly configured file sharing.
