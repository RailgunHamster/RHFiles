# RHFiles Android 0.1.54

发布日期 / Release date: 2026-11-10

## 中文

1. 新增内置 PDF 阅读器，可直接打开本地文件、授权的文档路径、SMB、FTP/FTPS、WebDAV 和 RHFiles 设备中的 PDF。
2. 网络 PDF 使用现有认证连接进行分段读取，不创建下载任务或完整工作副本；关闭阅读会结束读取授权。
3. 支持连续阅读、跳页、缩放、旋转、全文搜索、文本选择、目录和加密 PDF 密码输入。
4. 阅读内核、中文 CMap、字体及解码器均随应用离线提供；手机和大屏复用同一套自适应阅读界面。
5. 补充真实渲染、500 页文档、按需读取、错误密码、WebDAV 认证与关闭后失效测试；阅读界面操作均有自动化接口。

## English

1. Add a built-in PDF reader for local files, granted document URIs, SMB, FTP/FTPS, WebDAV and RHFiles devices.
2. Read network PDFs in bounded ranges using existing credentials, without a download task or complete working copy. Closing the reader releases its read capability.
3. Support continuous reading, page jumps, zoom, rotation, full-text search, selectable text, outlines and encrypted PDF passwords.
4. Bundle the renderer, CMaps, fonts and decoders for offline use, with a shared responsive layout for phones and larger screens.
5. Cover actual rendering, 500-page files, partial reads, wrong passwords, authenticated WebDAV and closed-source rejection. Reader controls have automation APIs.
