# RHFiles Android 0.1.59

发布日期 / Release date: 2026-11-22

## 中文

1. 优化侧滑返回与返回键逻辑：关闭临时弹窗/抽屉/多选后，优先按当前窗格的导航历史栈返回上一页（保留滚动位置，支持从收藏夹、历史记录、搜索、空间分析、抽屉、面包屑及路径栏向上按钮跳转后一键返回原页面）；当历史栈为空时，再按物理父目录/分类上一级逐级回退至首页。
2. 导航历史栈新增重复/成环路径折叠（上限 128 步，自动归一化路径末尾斜杠并保留快捷入口边界），避免反复切换目录或工具页后堆积多余返回步骤；路径栏 `↑` 按钮保持明确的向上一级目录语义，并修复抽屉关闭动画期间误拦截侧滑返回的问题。

## English

1. Updated system swipe-back navigation to follow the pane's in-app history stack first (restoring scroll positions across Favorites, History, Search, Storage Analysis, drawer switches, breadcrumbs, and Up-button navigation) after dismissing temporary overlays, falling back to physical parent folders or category roots only when the history stack is empty.
2. Added cycle-folding deduplication to the navigation stack (bounded to 128 unique routes with trailing-slash normalization and shortcut boundary preservation), kept the pathbar Up button strictly for parent-directory navigation, and prevented closing drawer animations from swallowing immediate back gestures.
