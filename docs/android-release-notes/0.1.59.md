# RHFiles Android 0.1.59

发布日期 / Release date: 2026-11-22

## 中文

1. 优化侧滑返回与返回键逻辑：关闭临时弹窗/抽屉/多选后，优先按当前窗格的导航历史栈返回上一页（保留滚动位置，支持从收藏夹、历史记录、搜索、空间分析、抽屉、面包屑及路径栏向上按钮跳转后一键返回原页面）；当历史栈为空时，再按物理父目录/分类上一级逐级回退至首页，并对重复/成环路径做折叠（上限 128 步），路径栏 `↑` 按钮保持明确的向上一级目录语义。
2. 新增 HTML 文件预览（支持 `.html` / `.htm` / `.xhtml`）：默认以沙箱隔离模式渲染网页排版与样式（屏蔽脚本、外部请求与危险跳转），支持在「预览 / 源码」之间自由切换并复制源码，同时支持本地、授权目录与远端设备文件。
3. 为各类内置预览增加「全屏」选项（覆盖 HTML、Markdown、JSON、纯文本/代码、PDF、图片翻页/连续浏览、文本编辑与压缩包内容预览）：全屏时隐藏系统状态栏/导航栏与冗余工具栏，在分屏双窗格下自动展开至整屏，支持右上角悬浮「退出全屏」按钮或侧滑返回先退出全屏再关闭预览。

## English

1. Updated system swipe-back navigation to follow the pane's cycle-folding history stack first (restoring scroll positions across Favorites, History, Search, Storage Analysis, drawer switches, breadcrumbs, and Up-button navigation, bounded to 128 unique routes) after dismissing temporary overlays, falling back to physical parent folders or category roots only when the history stack is empty, while keeping the pathbar Up button dedicated to parent-directory navigation.
2. Added rendered HTML preview for `.html`, `.htm`, and `.xhtml` files inside a strict sandboxed frame with a Preview / Source toggle and source copy across local, SAF, and remote files.
3. Added a fullscreen option across in-app previews (HTML, Markdown, JSON, plain text/code, PDF, paged/continuous image gallery, text editor, and archive preview) that hides Android system bars, expands over dual-pane split views, hides chrome for maximum canvas, and exits fullscreen on first Back or via the floating exit button.
