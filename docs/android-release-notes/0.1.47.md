# RHFiles Android 0.1.47

发布日期 / Release date: 2026-11-08

## 中文

1. 更新记录仅将最新一条单独展示，其余记录统一放入历史记录，每页 10 条。
2. 历史记录显示页码、上一页和下一页；翻页不影响最新记录，也不重复检查更新。

## English

1. Only the latest release is featured separately; all earlier releases share a single history list with 10 records per page.
2. History pagination shows a page counter and previous/next controls, preserving the latest release and making no update requests.
