# RHFiles Android 0.1.52

发布日期 / Release date: 2026-11-09

## 中文

1. 连续图片浏览在末张与首张的接缝显示细分隔线和循环标签，跟随图片滑动，不增加图片间距；自动滚动同样可见。
2. 跨过首尾时短暂提示“已回到第一张／最后一张”，支持正反方向和逐张模式；放大时隐藏接缝，单张图片不显示循环提示。
3. 图片浏览状态接口提供接缝可见状态和循环提示，关闭查看器后清理相关节点和计时器。

## English

1. Show a subtle divider and loop badge at the last-to-first image joint, including during automatic continuous scrolling, without adding any gap between images.
2. Briefly announce returning to the first or last image in either direction, including paged navigation. Hide the divider while zoomed; single images have no loop indicator.
3. Expose the boundary and wrap notice through the gallery state API, and clean up its elements and timer on close.
