# RHFiles Android 0.1.50

发布日期 / Release date: 2026-11-09

## 中文

1. 文件列表右侧新增大触控滑动条，可直接拖动快速定位大量文件；单屏内容自动隐藏，保持列表虚拟化，避免误触多选和文件菜单。
2. 连续图片按实际缩放宽度无间隔衔接，完整保留图片，不再把每张图片两侧的黑边拼接到一起。
3. 连续图片新增自动滚动、速度调节、暂停和继续；手动拖动或缩放时暂停，到末尾停止，不循环。轻触图片可隐藏控制条。
4. 文件列表滚动、图片自动滚动均提供对应脚本接口，并补充触摸、几何和后台取消测试。

## English

1. Add a finger-sized draggable fast-scroll handle for long file lists. It hides for non-scrollable content and preserves virtualization without accidental file selection.
2. Join actual fitted image edges in continuous browsing without inter-image black padding or cropping.
3. Add adjustable automatic image scrolling, pause and resume. Manual dragging or zooming pauses it; the end stops it without looping. Tap pictures to hide controls.
4. Add matching automation APIs and touch, geometry and cancellation coverage.
