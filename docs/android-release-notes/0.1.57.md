# RHFiles Android 0.1.57

发布日期 / Release date: 2026-11-15

## 中文

1. 在「设置 → 存储与权限 → 文件服务」新增「启动 RHFiles 时自动共享」。默认关闭，开启后下次启动应用时，有已保存的共享目录才会启动文件服务。
2. 自动启动沿用已有设备组权限。手动停止后，本次运行期间保持停止。目录不可用时，可以在「从电脑访问」查看原因。

## English

1. Added “Start sharing when RHFiles opens” under Settings → Storage and permissions → File service. Enable it to start sharing saved folders on the next app launch.
2. Automatic startup uses existing device group permissions. A manual stop lasts for the current app session. Startup errors are available under Access from a computer.
