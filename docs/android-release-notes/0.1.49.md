# RHFiles Android 0.1.49

发布日期 / Release date: 2026-11-09

## 中文

1. 网络位置与 RHFiles 设备中的 JSON、Markdown、文本、日志、CSV、XML、YAML、INI 和常见代码文件可直接预览，不创建下载任务。支持 UTF-8、带 BOM 的 UTF-16、GB18030 中文编码及二进制内容检测。
2. 文本默认只读取前 256 KB，可手动增加至 1 MB；长文本分段显示。Markdown 支持排版／源码切换，JSON 支持格式化／原文切换；排版在后台执行，关闭预览会取消读取。
3. 网络中的单个 APK 可缓存后调用系统安装器；缓存具有后台任务与进度，失败保留原因，已完成任务可再次点击安装。缓存与用户下载目录分开管理。
4. 图片增加可切换的横向连续滚动模式：相邻画面衔接，短距离拖动后保留当前位置，不强制吸附。原有逐张翻页仍为默认，可在查看器或设置 → 浏览与显示切换，选择会保存并包含在配置备份中。
5. 为文本预览、图片模式／控制和 APK 缓存／安装补充对应自动化接口。
6. 修复 Android 平台 XML 解析选项不兼容导致的 WebDAV 目录读取与局域网发现失败；保留对 DTD、外部实体和异常编码的拒绝。

## English

1. Preview JSON, Markdown, text, logs, CSV, XML, YAML, INI and common source files directly from network locations and RHFiles devices. Reads support UTF-8, BOM-marked UTF-16 and GB18030, with binary-content detection and no download task.
2. Read up to 256 KB initially, or explicitly increase to 1 MB. Long text uses bounded parts. Markdown offers reading/source views and JSON offers formatted/original views; formatting runs off the UI thread and closing cancels the read.
3. Cache remote single APKs privately, report background progress, and invoke the Android system installer. Completed cache tasks offer Install; failures retain their cause.
4. Add optional continuous horizontal image browsing without forced page snapping. Paged browsing remains the default. Switch in the viewer or Display settings; configuration backups retain the preference.
5. Add matching automation APIs for text previews, gallery controls/modes and APK caching/installation.
6. Fix Android-incompatible XML parser options that prevented WebDAV directory listings and LAN discovery, while retaining strict rejection of DTDs, external entities and invalid encodings.
