# RHFiles Android 0.1.48

发布日期 / Release date: 2026-11-08

## 中文

1. 图片阅读改为短距离换页，不再要求拖动屏幕宽度的 20%；平板、折叠屏也采用有上限的换页距离。
2. 快速轻扫按最近一段移动判定，松手前的小停顿不再轻易抹掉速度；微小抖动、纵向滑动和已取消手势不会切图，放大后仍可拖动查看图片。
3. 视频左右滑动可切换上一个／下一个视频，保留进度条操作，并防止播放项变化后旧手势误操作。
4. 侧栏“设置”下方新增浏览历史，支持本机目录、系统授权目录、RHFiles 设备与各类网络位置；提供重新打开、移除及清空记录和对应命令接口。

## English

1. Shorter picture swipes now change pages, with a capped distance on tablets and foldable screens instead of requiring 20% of the viewport.
2. Flick recognition uses recent motion rather than one final event. Tap jitter, vertical movement, canceled gestures and zoomed panning do not change pictures.
3. Swipe horizontally to switch videos while retaining timeline controls and guarding against playback changes during a gesture.
4. Added device-local browsing history below Settings in the drawer for local folders, document providers, RHFiles devices and network locations, with matching command actions.
