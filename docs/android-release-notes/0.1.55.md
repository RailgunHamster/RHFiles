# RHFiles Android 0.1.55

发布日期 / Release date: 2026-11-11

## 中文

1. 优化 RHFiles 设备删除：支持回收站的电脑直接回收整个文件夹，不再先递归统计、再逐个删除子文件。新版电脑支持分批提交多个选中项。
2. 普通删除移入目标电脑的回收站；删除确认说明实际处理方式。网络中断时只核对原操作回执，不自动重新发送删除。
3. 图片浏览右上角新增“更多 → 删除”；本机图片使用 RHFiles 回收站，成功后继续浏览下一张，删除最后一张后返回列表。取消或失败保留当前图片。
4. 视频播放选项新增删除当前文件；先释放播放连接，再执行后台文件任务，成功后播放下一项。横竖屏切换保留正在等待的任务，不重复删除。
5. 修复连续看图缩小时的图片间黑色空档；图片和间距一起缩放，保留连续滚动、旋转、自动滚动和首尾循环。
6. 新增真实截图像素、删除取消/失败、批量请求数量、权限、回执以及视频队列切换测试；浏览操作提供自动化接口。

## English

1. Recycle whole folders on compatible RHFiles computers without recursively measuring and deleting every descendant. Updated hosts also accept batches of selected items.
2. Explain the actual deletion policy before confirmation. Connection failures query the original mutation receipt without replaying deletion.
3. Add More → Delete to image browsing. Continue with the next image only after success; cancellation and failure preserve the current image. Deleting the final image returns to the file list.
4. Add Delete current file to video options. Release the playback source before starting the background task, then play the next item. Rotation retains the pending task without resubmitting it.
5. Scale continuous image widths and spacing together, eliminating dark intervals after zooming out while preserving scrolling, rotation, automatic scrolling and wraparound.
6. Add screenshot-pixel, cancellation/failure, batch request-count, permissions, receipts and video queue tests, with matching automation actions.
