# RHFiles Android 0.1.61

发布日期 / Release date: 2026-11-26

## 中文

1. 长按进入多选，选择文件或文件夹后即可批量重命名。支持查找替换、正则表达式和区分大小写，确认前可以逐项对照原名和新名。
2. 本地目录和支持改名的网络位置共用这套操作。执行前检查来源和重名冲突，在文件任务中可以查看进度及失败原因。

## English

1. Long-press to select multiple files or folders and choose Batch rename. Preview each name before applying a replacement, with optional regular expressions and case matching.
2. Batch rename works in local folders and network locations that support renaming. RHFiles checks the sources and destination names before starting and reports progress and errors in File Tasks.
