# RHFiles Android 0.1.24

1. 修复 SMB 主机名查询被缓慢的 .local 查询拖住的问题：并行查询、合并并发请求，并限制查询总等待时间。
2. 同一服务器的共享目录复用只读登录连接，减少进入目录时重复登录；名称缓存按实际网络隔离，切换网络不会沿用旧连接。
3. 局域网 NAS 优先使用已连接的 Wi-Fi／以太网，即使系统默认网络是移动数据；不会绕过当前 VPN。
4. 增加名称解析、网络切换、连接复用和真实 SMB 浏览的回归测试。
5. 加入本机命令行自动化接口；设置中显式开启 ADB 自动化后可使用，不默认对局域网开放。

## English

1. SMB name resolution no longer waits behind slow .local queries: bounded parallel lookups, request coalescing and network-scoped positive caching.
2. Reuse read-only authentication across shares on the same server; stale connections and changed networks are handled separately without replaying writes or authentication denials.
3. Prefer connected LAN Wi-Fi/Ethernet for local NAS targets even when cellular is the default; respect the active VPN.
4. Add deterministic resolver/network regressions and minified-APK SMB browsing checks.
5. Add opt-in, local command-line automation; enable ADB automation explicitly in settings before using it.
