# RHFiles Android 0.1.56

发布日期 / Release date: 2026-11-15

## 中文

1. 在「从电脑访问」中选择多个本机共享目录，也可以从文件夹菜单直接添加。支持内部存储和可直接访问的已挂载 SD 卡、U 盘。
2. 启动后，同组设备可以在「RHFiles 设备」中刷新并访问手机。读写、重命名和删除由设备组及手机存储权限决定。
3. 运行中修改的共享目录在下次启动服务时应用。从最近任务中移除 RHFiles 会停止文件服务。

## English

1. Select multiple local folders under Access from a computer or add a share from a folder menu. Supports internal storage and directly accessible mounted SD cards and USB drives.
2. Refresh RHFiles Devices on another group member to access shared folders. Write, rename, and delete access follows the group and Android storage permissions.
3. Saved share changes apply the next time the service starts. Removing RHFiles from recent tasks stops sharing.
