# RHFiles Android 0.1.32

## 中文

1. 改进移动网络、Tailscale 及闲置后的设备组连接：冷连接最多验证 6 秒，传输故障可在原来的 15 秒、6 次预算内重试一次，无持续探测。
2. 按当前网络排序地址，避免把远端 127.0.0.1 当作优先路线。成功地址独立保存在本机，不同步登录会话或密钥。
3. 手动重试可受限地越过自动冷却；自动请求按需退避，连续点击合并、限速，不反复扫描耗电。
4. 无关 IMS/虚拟网络变化不再使正在进行的连接失效；服务重启丢失登录会话时重新验证一次，不需要重新入组。
5. 扩展连接诊断，显示尝试次数、剩余预算、冷却、成功路线与跳过原因。刷新失败保留当前目录并标明未刷新，刷新成功后才允许继续修改文件。
6. 维持证书固定和组签名验证；权限拒绝、身份不符停止尝试，结果不明的重命名、移动和删除不自动重放。

## English

1. Improve cold/idle and cellular/Tailscale group connections with up to six seconds for the preferred handshake and one transport retry within the original fifteen-second/six-attempt budget. No continuous probing.
2. Rank addresses for the current network and skip remote loopback hints. Remember successful addresses locally, separately from sessions and private keys.
3. Allow rate-limited manual retries during automatic cooldown; coalesce repeated demands without scan loops or background battery drain.
4. Ignore unrelated IMS/virtual network changes. Renew an expired server session once without requiring group rejoining.
5. Show attempt counts, budgets, cooldowns, successful routes and skip reasons. Preserve failed-refresh listings with a stale marker and require a successful refresh before file mutations.
6. Retain pinned certificates and group proofs. Identity/permission failures stop retries; ambiguous rename/move/delete outcomes are never automatically replayed.
