# RHFiles Android 0.1.53

发布日期 / Release date: 2026-11-10

## 中文

1. 连续图片自动滚动速度上限提高到 6000 像素／秒，同时提供滑块和精确数值输入。
2. 图片查看器和设置中的逐张翻页／连续滚动改为双按钮切换，清晰显示当前模式。
3. 使用外接键盘时，空格可暂停和继续自动滚动；编辑输入框和长按按键不会反复触发，暂停不会重置图片位置。
4. 使用鼠标时，连续浏览标题跟随指向的实际图片；移开或指向空白处时恢复当前位置的图片名称。
5. 新增自动滚动切换脚本接口，并补充模式切换、速度边界、硬件键盘及文件列表交互回归测试。

## English

1. Raise continuous-image auto-scroll speed to 6000 pixels/second, with a slider and precise numeric input.
2. Use a two-button paged/continuous mode switch in the image viewer and settings.
3. Space starts or pauses auto-scrolling with a hardware keyboard. Editable fields and held-key repeats do not trigger it; pausing preserves position.
4. With a mouse, the continuous-view title follows the actual image under the pointer, falling back to the current-position image over empty space or outside the canvas.
5. Add the auto-scroll toggle API and regression checks for mode switching, speed limits, hardware keys and list interaction.
