# RHFiles Android 0.1.31

## 中文

1. 修复从 RHFiles 电脑服务下载零字节文件时错误返回 HTTP 416、导致整批复制显示失败的问题。
2. 完整文件下载不再强制使用 HTTP Range；视频跳转、从非零偏移读取仍保留分段请求，并拒绝无效的负数偏移。
3. 补充空文件、完整下载和偏移读取回归测试。本版包含 0.1.30 的 WebDAV 同步保留本机设备组连接修复。

## English

1. Fix HTTP 416 errors when downloading empty files from a RHFiles computer, which incorrectly marked batch copies as failed.
2. Whole-file downloads no longer force HTTP Range. Nonzero-offset reads retain range requests, and negative offsets are rejected locally.
3. Add regressions for empty files, whole-file downloads, and offset reads. Includes the 0.1.30 fix preserving local device-group connections during WebDAV configuration sync.
