# RHFiles Android 0.1.60

发布日期 / Release date: 2026-11-22

## 中文

1. 网络位置与设备组（含 `rh://`、SMB、WebDAV、FTP）新增「下载到默认文件夹」一键下载：支持单个文件、文件夹、多选批量下载及网络图片预览内下载，直接后台下载到已配置的本机默认目录（默认 `内部存储/Download`，不存在时自动创建），无需每次手动挑选文件夹，也不离开当前远程目录。
2. 支持配置默认下载文件夹：可在「设置 → 存储与权限」或「设置 → 更新与网络 → 设备文件传输」中浏览本机/外置/授权目录（支持直接新建文件夹与一键恢复默认），也可在浏览任意本机目录时通过右上角菜单直接「设为默认下载文件夹」。
3. 优化「下载到本机」体验：现已同时支持远端文件、文件夹与多选项目，点击后不再停留原地或漂移到外置存储，而是直接导航到「内部存储」并展示待粘贴栏，方便快速进入目标目录完成下载（侧滑返回可直达原远端目录）。

## English

1. Added one-tap "Download to default folder" across network locations and device groups (`rh://`, SMB, WebDAV, FTP) for single files, folders, multi-select batches, and remote image viewer items—copying directly into the configured local folder (defaulting to `Internal Storage/Download`, auto-created when missing) without leaving the current remote directory.
2. Added configurable default download folder management in Settings (Storage & Permissions and Device File Transfer), supporting local, external, and SAF folders with folder creation, one-tap reset, and a "Set as default download folder" shortcut in local folder menus.
3. Improved "Download to device" to support remote files, folders, and multi-select batches, always navigating straight into Internal Storage with the paste bar ready (while keeping swipe-back returning to the remote folder).
