# RHFiles Android 0.1.46

发布日期 / Release date: 2026-11-08

## 中文

1. 更新记录分为“最近更新记录”和“历史记录”，最近展示 10 条；其余记录每页 10 条，显示页码并可前后翻页。
2. 翻页不重新加载最近记录，正文展开后才创建；完整历史仍可离线查看。
3. 更新记录读取、历史翻页同时提供自动化接口。

## English

1. Separated the 10 most recent release notes from older history, with 10 older records per page and a page counter.
2. Pagination preserves recent note expansion and loads note bodies on demand. The full bundled history remains available offline.
3. Added automation actions for history state and pagination.
