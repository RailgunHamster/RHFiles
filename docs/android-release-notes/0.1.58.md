# RHFiles Android 0.1.58

发布日期 / Release date: 2026-11-20

## 中文

1. 支持直接在手机端打开并阅读 RHFiles 远端电脑设备中的 EPUB（及 MOBI/AZW3/FB2/CBZ）电子书：主进程自动流式下载校验并缓存到私有目录，隔离的阅读进程保留阅读进度与书签且不接触网络凭据。
2. 修复通过 Android 客户端删除 RHFiles 远端符号链接目录或其下文件夹时返回 HTTP 403 的问题，补齐链接操作请求头并避免对符号链接目录递归删子项。

## English

1. Added direct reading for EPUB (and MOBI/AZW3/FB2/CBZ) ebooks stored on RHFiles remote devices, with verified private caching in the main process and persistent reading progress inside the isolated reader process.
2. Fixed HTTP 403 errors when deleting folders on RHFiles remote devices through links by sending `X-RHFiles-Link-Operations: 1` and preserving directory symlink deletion boundaries.
