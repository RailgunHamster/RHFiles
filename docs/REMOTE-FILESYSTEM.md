# RHFiles 设备文件操作

设备路径使用 `rhfiles-device://组ID/设备ID/共享/路径` 标识身份，而不是把易变的 IP 当成文件身份。普通菜单、快捷键和命令行 API 都走同一个分发层，不把这个地址直接交给 Windows 本地文件接口。

## 普通操作

- 浏览、排序、筛选、递归搜索、文本/图片/媒体预览、属性、大小统计、哈希和空间分析。
- 新建文件夹、模板文件、单个/批量重命名、剪切复制粘贴、拖放、本地与设备互传、设备之间互传、合并文件夹和删除。
- ZIP/7z 等压缩包浏览、密码验证、分卷读取、解压，以及使用已配置压缩器/媒体/PDF 转换器生成远端文件。
- Windows 本地程序接入使用受信任 HTTPS WebDAV。未启用兼容入口或缺少 WebClient 时，单个文件可以下载为受管理的工作副本；目录、终端不能用下载目录假冒远端工作目录。

原生复制、移动和删除报告当前项目、字节/项目进度、速度和错误，可取消。目录扫描设置深度/数量边界，不无限展开。操作不会因网络恢复自动重试一次危险的修改。

## 冲突和数据保护

文件夹永远不通过删除目标来替换；已有文件夹合并。文件替换需要明确选择，并绑定确认时的目标版本。源或目标被其他程序改动、移走后重建，即使同名同内容，也不会对新对象继续原请求。移动只在目标提交成功且源版本仍匹配后删除源；失败时保留已提交的目标，不回滚删除用户数据。

同一共享内移动使用服务端条件重命名。批量重命名先检查全体冲突，再通过唯一中间名称处理交换名字的情况；失败恢复不能覆盖后来出现的对象。未完成的批量操作记录保留在当前配置的 `device-operation-recovery` 中，不自动重放。

远端删除和 SMB 一样不是本机回收站操作；界面明确提示，不能承诺 Ctrl+Z 找回。重命名的撤销/重做绑定对象版本，不对后来同名的新文件执行。系统权限、备用数据流、重解析点等操作还受服务器和 Windows WebDAV 文件系统实际能力限制，不能用本地缓存的属性冒充服务器属性。

## 工作副本和临时文件

工作副本放在当前配置的 `device-working-copies/<随机ID>/content/`，记录原始地址及版本。编辑不会自动上传或在退出时丢弃；侧栏「远端工作副本」可以保存、另存、打开本地位置。保存检查远端原始版本；有修改的副本不能通过普通清理按钮删除。

压缩/转换使用限量、随机句柄的独立临时工作区。输入下载后验证版本，输出提交前再次验证真实冲突；不把调用方任意给出的本地目录当成可删除的临时目录。转换失败不会覆盖旧输出，任务结束后只释放自己的临时工作区。

## 脚本接口

`devices.*` 提供路径、重命名、新建、删除、大小/哈希、批量操作及工作副本接口；完整参数以 `RHFilesAPI.describe` / CLI 的操作枚举为准。已有 `files.*` UI 操作通过同一分发层支持设备路径。

`devices.windowsPath` 获取当前设备组成员的真实系统路径，要求服务器明确启用兼容授权。`devices.windowsDisconnect` 需要显式 `confirmed: true`，只断开当前配置创建且用户名匹配的连接，不清除其他应用的凭据或连接。

## 回归验证

`scripts/e2e/device-file-operations.test.mjs` 使用隔离配置、真实应用和合成文件，验证冲突、ABA、合并、工作副本、压缩解压、只读权限和删除。`scripts/e2e/windows-device-access.test.mjs` 是显式开启的真实 Windows WebClient 集成测试，不修改日常配置、系统安全策略或剪贴板。
