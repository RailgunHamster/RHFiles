RHFiles 便携版使用说明
=====================

1. 请先完整解压 ZIP，再运行 RHFiles.exe。不要直接在压缩软件里启动。
2. 首次运行这个 Velopack 便携版后，后续版本可以在 RHFiles 内自动下载、覆盖并重启。
3. 默认更新源是 GitHub Releases；也可在“设置 → 更新源”切换到家庭服务器。
4. 更新时会先征求确认，并显示下载进度；打开的标签页会保留。
5. Everything.exe / Everything64.dll 用于高速全局搜索，dust.exe 用于目录占用分析，请不要单独删除。
6. 如果网络中断，已安装的版本不会被破坏；稍后可在设置中重新检查更新。

旧式手工便携版没有更新引导程序，无法自行覆盖。只需手动换用本版本一次，后续即可自动更新。
