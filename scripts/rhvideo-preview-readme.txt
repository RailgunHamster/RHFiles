RHFiles · RHVideo 媒体库 Windows 体验版

请先解压，双击“启动体验版.cmd”，再点击 RHFiles 左侧的 RHVideo。
不要直接双击 RHFiles.exe：启动脚本会使用独立配置，避免唤起已经安装的旧版。
本包不安装、不覆盖正式版，也不进入正式版自动更新渠道。

点击“连接 RHVideo”，填写你已经在使用的服务器地址、用户名、密码。
数据仍由原来的 RHVideo 管理，本包不附带后端，不直接打开数据库。
地址、用户名保存在独立配置中；密码不保存，退出应用后需要重新登录。

视频原生播放需要本机已安装 64 位 VLC 3.x。
图片、小说和媒体浏览不要求 VLC。当前播放采用软件解码和兼容画布，
显示帧缓冲最大 1920×1080；4K/HDR、硬件加速仍需后续完善。

这是第一版功能验证，不是 RHVideo 所有功能的最终迁移版本。
配置目录：当前账号 LocalAppData 下的 RHFiles-RHVideo-Preview。
