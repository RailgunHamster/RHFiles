RHFiles Android 0.1.10

新增 Windows / Android 局域网“附近互传”第一版：首页或文件多选的更多菜单打开。两端主动开启后自动发现设备，也可输入 IP:端口；发送前核对接收端完整十二位接收码，接收端每批确认目标文件夹。
TLS 加密与完整证书指纹固定，逐文件 SHA-256 校验。文件夹、空目录、零字节文件保留层级；每批保存到独立新子文件夹，不覆盖已有内容，不删除来源。界面显示进度、平均速度、失败原因，支持拒绝和取消。
默认不开网络监听，不共享整块磁盘，不使用云服务器；Android 前台通知可停止互传，系统超时也会关闭监听。多网卡会显示所有可用局域网地址并尝试各接口发现；手动连接不会被后续发现覆盖。
首版支持本机普通文件，暂不直接发送 SMB、SAF、网盘或符号链接；最多 10,000 条目、64 层、1 TB。不做移动或断点续传；异常退出后列出未完成接收路径，不自动重做。

First Windows / Android Nearby Transfer: opt-in LAN discovery or manual IP:port, compare the receiver's 12-character code, and approve every incoming batch. TLS certificate pinning, per-file SHA-256, progress/speed/errors, rejection and cancellation. Preserves nested/empty folders and zero-byte files; receives into a new batch folder without overwriting or deleting sources. No cloud relay, disk sharing or listener at startup. Android foreground notification stops the listener. Local files only initially; no SMB/SAF/symlinks or automatic replay/resume.

此前版本改进 / Previous improvements (0.1.9):

新增大屏双窗格：左右或上下分屏，每边有独立主页、目录导航、选择与滚动位置。中间布局按钮可切换自动、左右、上下、单窗格；空间不足时安全退回可用布局。
无需拖拽：长按多选后点“复制到另一窗格”或“移动到另一窗格”，确认窗口显示完整目标路径。另一边是主页时会先提示打开目标文件夹。也可复制/移动后到另一边粘贴；文件夹继续合并，不会自动覆盖同名文件，任务有进度与失败信息。
新增电子书阅读器：未加密 EPUB、MOBI/AZW3、FB2、CBZ，支持目录、翻页/滚动、字号、明亮/护眼/夜间配色、书签与阅读位置恢复。基于固定版本的 foliate-js；书内脚本和联网资源禁用，阅读器不获得文件管理接口。
首版电子书限制：本机或已授权文件，最大 64 MB，单个 ZIP 资源 20 MB、章节文本 8 MB；网络书籍先下载，DRM 书籍请使用授权阅读器，PDF 继续由系统应用打开。
修正 Android 系统状态栏/手势导航栏避让，避免分屏底部文件操作被系统手势区遮挡。后台目录更新保留未改变的行和缩略图，减少打断长按选择。

Independent large-screen panes with automatic/side-by-side/stacked/single layouts. Select files and use Copy/Move to Other Pane, review the exact destination, or paste via the shared clipboard. Folder merging and non-overwrite protections remain in the native file-task engine.
Read unencrypted EPUB, MOBI/AZW3, FB2 and CBZ with contents, paging/scrolling, font size, three reading palettes, bookmarks and resume. The isolated reader has no file-manager IPC; book scripts/network resources are disabled. Initial limits: 64 MB book, 20 MB ZIP resource, 8 MB chapter text. Download remote books first; DRM and internal PDF rendering are not supported.

此前版本改进 / Previous improvements (0.1.8):

修复列表滚动/拖动时缩略图消失：保留可见行和已解码图片，合并重复请求，限制并发与缓存；不支持的文件保留类型图标。
首页抽屉开关的拖动吸附阈值都降至约五分之一，短距离拖动更容易完成。
首页“下载”有独立导航边界，下载根目录返回主页；从内部存储进入 Download 仍返回真实父目录。主页图标底框增加明暗主题细描边。
加入本机视频真实封面，使用 Android 系统缩略图接口，图片与视频都不把原文件整块加载到 WebView。
图片、视频、音频、文档等分类先按所在文件夹分组，再进入该类型的文件列表；图片文件夹使用最新图片作封面，视频文件夹使用最新视频帧作封面（按修改时间）。同名不同路径的文件夹分开。
设置分为浏览显示、搜索索引、存储权限、更新网络、关于诊断五类。
加入宽屏常驻导航、可用宽度网格和设置布局、窗口大小变化与折叠铰链避让；Android 因密度变化重建界面时恢复导航状态。模拟器和布局测试不替代折叠屏真机验证。
家庭服务器支持在更新页直接保存 SMB 账号密码，兼容 域\\用户名；增加 .local / 局域网短名称查询。失败显示具体异常与建议，可复制不含密码的诊断。手机实际故障仍需用具体错误确认，不能仅凭“更新失败”保证解决。

Stable thumbnails during scrolling, native video frame thumbnails, folder-grouped libraries with newest image/video covers, categorized Settings, adaptive wide/fold layouts and authenticated SMB update configuration with actionable diagnostics. Home Downloads now has its own navigation boundary, and Home icons have clearer outlines. Phone-specific SMB connectivity and physical foldable behavior still require device verification.

此前版本修复 / Previous fixes:

修复正式版家庭服务器 SMB 更新报错“the provided handler invocation did not specify the necessary constructor”：保留 SMB 事件组件反射调用的构造函数。更新目录读取和 APK 下载均使用开启混淆的正式 APK 回归验证。
旧版 SMB 通道已损坏时，请先切换 GitHub 更新或手动覆盖安装本版 APK；不需要卸载，原数据与签名保持不变。

Fix release-only SMB updater failure caused by stripped reflection constructors. Verified feed reads and full APK transfers using the minified signed release APK. If an older SMB updater cannot download this fix, update once via GitHub or install the APK over the existing app without uninstalling.

Finger-tracking drawer with animated settling; stable large-directory scrolling and canceled stale long-press timers.
Native Media3 video/audio playback, progress, fullscreen, speed, fit/fill, looping and actionable codec errors.
Immersive photo viewer and redesigned Home index card. Existing data and in-app update sources are preserved.
